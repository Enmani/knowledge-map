# 数域 · 互动理科知识空间

[![CI](https://github.com/Enmani/knowledge-map/actions/workflows/ci.yml/badge.svg)](https://github.com/Enmani/knowledge-map/actions/workflows/ci.yml)
[![Apache-2.0](https://img.shields.io/badge/code-Apache--2.0-blue.svg)](./LICENSE)
[![CC BY 4.0](https://img.shields.io/badge/content-CC%20BY%204.0-lightgrey.svg)](./LICENSE-CONTENT.md)

一个可缩放、可拖拽的开源知识地图。二维数学地图用前置关系展示知识如何逐层解锁，三维公共知识空间连接数学、物理、化学和生物，并允许用户从不同学科视角观察同一组知识。

## 已实现

- 46 个数学全景主节点，覆盖数学基础、代数、几何与拓扑、分析、离散数学、概率统计、应用数学
- 184 个三维公共知识节点，数学、物理、化学、生物各 46 个
- 487 条公共知识关系，其中 111 条跨主领域关系，121 个节点具有多领域归属
- 公共全景、数学、物理、化学、生物和跨域桥梁六个三维投影视角
- 三维公共全景使用同心知识球：严格前置深度决定半径，领域归属决定方向，关系与标签决定球壳内邻近
- 知识球体积由节点、关系和颜色场域共同显现，不绘制固定线框球壳
- 数学、物理、化学和生物位于正四面体方向，多领域知识位于对应领域的三维交界
- 临时领域筛选保持公共坐标，专业聚焦对可见子图重排球面方向并保留知识深度半径
- 三维缩放围绕鼠标指向的世界位置进行，旋转始终围绕知识球心，远景光点悬停显示固定屏幕尺寸的节点名称
- 三维微积分节点支持悬停滚轮下钻，6 个内部节点沿连续倍率逐步显现，缩小后连续返回公共知识球
- 行走模式使用 WASD 水平移动、Q 上升、E 下降，颜色场域可以独立淡入和淡出
- 三维节点卡片默认使用半透明面板，左下角可以切换浅色与 `rgb(24, 24, 24)` 深色界面
- 同一节点在透镜和筛选切换时连续移动和显隐，稳定 ID 与关系数据保持不变
- 三维视图支持左键拖动平移、滚轮平滑缩放、Alt 加左键或右键进行球心旋转
- 二维与三维相机均支持 10% 至 12800% 全局倍率，滚轮使用相同的对数缓冲响应
- 三维节点使用射线命中，选中后突出相邻关系并显示公共知识详情
- 二维与三维共用卡片关联聚焦：选中节点突出关系卡片，前沿雷达突出当前筛选命中的卡片并淡化其他卡片
- 四个学科领域和重复主题标签生成柔和彩色三维散点场，相邻场域使用有界屏幕混合形成叠加色
- 15 个主图可钻取子空间和 1 个嵌套子空间投影，包含 69 个子节点投影
- 每个知识点同时拥有共享场域标签与具体主题标签
- 共享标签通过确定性引力布局自动聚集，不依赖手绘区域
- 自动布局包含矩形防碰撞投影，节点之间始终保留安全间距
- 标签成员自动生成模糊气泡场；相邻场域使用颜料式混合形成新的叠加色
- 每个模糊场域先合并为一张低分辨率纹理，拖拽与缩放时只更新 WebGL 图层矩阵
- 无限画布式拖拽与滚轮缩放
- 单次按住空白或节点都可拖动画布；移动不足 5px 的节点操作识别为普通单击
- 点击节点高亮完整前置路径
- 显示“已掌握 / 可以学习 / 尚未解锁”三种学习状态
- 搜索、领域筛选、“下一站”推荐与小地图导航
- 学习进度保存在浏览器本地
- 自由浏览和迷雾探索两种模式，进度使用版本化格式保存
- 微积分、实分析、复分析、泛函分析、测度论、傅里叶分析、变分法、微分方程、数值分析等节点包含依赖推进式内部地图
- 根场景与全部子场景使用同一台相机，内部节点随缩放连续显现和消失
- 节点按屏幕投影尺寸切换 LOD，居中放大可钻取节点后自动进入内部地图
- 微积分卡片包含故事、来源和可操作的导数切线组件
- 前沿雷达收录 13 条经来源核验的跨学科开放问题与历史已解决问题，默认只显示开放讨论，支持类型、学科、概念和标签筛选
- 前沿雷达与知识详情复用可拖拽调宽的右侧工作台；筛选标签使用可换行的圆角矩形
- 二维关联节点显示前沿计数徽标，二维与三维知识卡片可以按当前概念打开雷达
- `菲尔兹奖`作为研究标签显示为 `🏅 菲尔兹奖`，不生成脱离研究内容的独立奖项卡
- 主画布使用 PixiJS WebGL 保留式渲染，相机、LOD 和父子场景过渡在连续帧中更新
- 三维公共空间使用 Three.js 保留式渲染，并通过动态导入与二维首屏分包
- 桌面与手机响应式布局

## 本地运行

需要 Node.js `^20.19.0` 或 `>=22.12.0`。

```bash
npm ci
npm run dev
```

Windows 下可以快速结束本项目占用 `4173` 端口的旧 Vite 进程并立即重新启动：

```bash
pnpm restart:quick
```

可通过 `DEV_PORT` 和 `DEV_HOST` 临时覆盖默认端口与地址。若端口由其他程序占用，脚本会拒绝结束该进程。

然后打开终端显示的本地地址。

生产构建：

```bash
npm run build
npm run test:smoke
```

## 扩展地图

二维主地图知识点集中在 `src/data/mathMap.ts`，分析学子地图内容集中在 `src/features/map/analysisSceneContent.ts`。三维领域目录位于 `src/knowledge/space3d/catalog`，`data.ts` 组合四个领域和跨域关系，公共透镜位于 `src/knowledge/space3d/lenses.ts`。三维数学目录直接投影二维的 46 个数学主节点。新增三维节点时填写稳定 ID、主领域、多领域归属、层级、标签和前置关系。三维坐标由投影公式生成。学科分类依据记录在 `docs/research/science-taxonomy-frameworks.md`。

这张图表达一条通用学习路径。不同专业和学习目标可以使用不同路线。

## 项目结构

- `src/domain`：概念、关系与校验规则
- `src/knowledge/space3d`：四领域公共节点、关系、透镜与确定性三维投影
- `src/engine`：场景、进度、LOD 与迷雾逻辑
- `src/renderers`：PixiJS 二维渲染器、Three.js 三维渲染器与渲染内核
- `src/features`：地图场景、导航与交互
- `src/content`、`src/frontier`：故事内容、来源与前沿条目
- `功能手册维基百科`：面向用户和开发者的产品手册
