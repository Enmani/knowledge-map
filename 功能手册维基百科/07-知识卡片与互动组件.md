# 知识卡片与互动组件

[返回首页](./README.md)

## 当前知识卡片

当前原型使用统一的右侧工作台显示选中节点详情或前沿雷达。单击地图节点、搜索结果、前置知识或后继知识都会更新同一个详情视图，并保持当前相机缩放和平移；打开前沿雷达时，工作台在原位切换内容而不是叠加第二个抽屉。雷达不会锁住地图，雷达展开期间选择二维或三维节点会直接以该节点详情替换雷达，同时保留当前相机。单击关闭按钮或在搜索框未聚焦时按 `Escape` 可以关闭当前视图。

桌面端可以拖拽工作台左边缘调整宽度，也可以聚焦分隔手柄后使用左右方向键调整。宽度限制在 340 至 720 像素，并至少为地图保留 360 像素；最后宽度保存在浏览器本地。900 像素及以下使用统一底部卡片并隐藏横向拖拽手柄，保存的桌面宽度不被覆盖。

二维地图和三维公共空间使用独立的详情数据。切换模式时，原模式的选中节点会保留。返回该模式后可以继续查看原详情。

卡片当前显示以下数据：

- 所属领域和学习层级；
- 中文名、英文名、简介和学习理由；
- 场域标签与具体标签；
- 直接前置及其掌握状态；
- 直接后继和建议投入时长；
- 与当前概念关联的前沿动态数量和前沿雷达入口；
- 当前学习状态对应的掌握操作。

微积分卡片还显示经过复核的长文介绍、概念图、公式、来源、复核日期和切线与斜率探索器。正文依次解释“什么是微积分”、形成历史、导数、积分、微积分基本定理和图像观察方法。二维与三维投影都按概念 ID 读取 `src/content/calculus.ts` 的同一份实际内容；二维卡片继续提供进入微积分内部地图的操作。

线性代数采用一张父级导览卡、十七张子域独有正式卡片和一张公共“向量与坐标”正式卡片。父卡按 `linear-algebra` 概念 ID 说明领域边界、实/复数域约定和五阶段下钻路线；详细历史、公式、矩阵类别、分解与应用按唯一内容宿主分散到相应概念。二维与三维子域复用相同的 `linear-algebra:` 投影 ID；其中 `linear-algebra:vectors-coordinates` 通过规范身份解析到公共 `vectors-coordinates`，所以跨域入口共享同一内容与玩家进度。其余十七个内部主题在两种视图中读取 `src/content/linearAlgebra.ts` 的同一内容记录。三维公共父节点继续使用现有线性代数动态图标作为主视觉，内部节点使用普通子域标记。

“矩阵世界”只归属“矩阵性质图谱”节点，不直接嵌入上游位图，而是以项目原生 SVG 重绘为“类型关系、分解条件、应用线索”三个可切换视图。协方差的完整解释归属“正规、对称与正（半）定矩阵”，最小二乘与 QR 归属“最小二乘与 QR 分解”，截断 SVD 与图像压缩归属“奇异值、SVD 与低秩近似”，伪逆与最小范数解归属“伪逆与最小范数解”；其他卡片只通过关系与短摘要指向这些主题。

场域标签以按钮显示。单击后，地图只显示包含该标签的节点、当前场域和双端匹配的关系。被排除的地图节点不接收画布点击。前置列表和后继列表中的项目可以继续打开新卡片。节点没有前置时显示起点说明，没有后继时显示当前地图的前沿终点说明。

自由浏览模式可以阅读公开卡片。探索模式只允许已经发现的节点显示完整详情。可以学习的节点可标记为已掌握，掌握状态通过重置操作恢复。当前概念存在已发布或已审核的前沿条目时，卡片显示“前沿动态”按钮和条目数量；单击后打开按当前概念收窄的前沿雷达。没有关联条目时不显示空区段。

三维公共知识卡片显示主领域、层级、中文名、英文名、简介、多领域归属、主题标签、可用的长文与互动内容、当前公共透镜和全部相邻公共关系。显示顺序为“主视觉 → 标题与英文名 → 标签 → 简介 → 正文、图解、来源与互动 → 前沿入口 → 当前公共视角或子域 → 公共关系或子域关系 → 知识记录”。三维正文不显示“内容状态”区段。七个已注册子域中的卡片显示对应作用域、内部节点信息和当前子域中的全部类型化关系。关系项标明方向、严格或建议前置、共享模型、类比、应用等关系语义，以及另一端的主领域。三维卡片暂不显示个人掌握、迷雾和投入时长。

三维画布只显示光点与中文气泡，不再显示节点标题卡或完整卡。远景光点以半尺寸白热亮核表达知识点的稳定语义重要性，以领域色宽光晕表达当前透镜相关性；选中节点保持普通气泡并把独立星点核心放大到两倍。全部屏幕内直接关联节点进入临时气泡层，无关名称隐藏；二维与三维仍共用 `primary / related / context` 聚焦身份和相同的上下文淡化系数。前沿雷达把当前筛选命中的概念作为 `related` 节点显示，不修改真实选中节点；关闭雷达后恢复原关系聚焦。

三维右侧卡片使用编辑型壳层。正文拥有独立滚动容器；46 CSS 像素高的透明顶栏常驻顶部，滚动进度从 0 到 176 CSS 像素时，大号主视觉与标题缩小淡出，紧凑图标与标题同步淡入并停在顶栏中。关闭按钮位于顶栏最右并纵向居中。38 CSS 像素高的页脚常驻底部，以细横线和主领域、学习层级角标结束卡片；正文在横线上方最后 5 CSS 像素渐隐。切换节点时正文回到顶部。当前“线性代数”把正交三平面图标放在主视觉位置，打开详情时以 2 秒周期单次播放，关闭后重新打开才重播；其他节点使用领域符号作为主视觉回退。

## 卡片结构

知识卡片以稳定概念 ID 读取结构化内容。概念出现在多个空间投影中时，先通过规范身份解析，再共享内容和玩家进度；投影 ID 仍保留当前场景上下文。卡片关闭后不改变相机、筛选、面包屑或进度。

卡片按已有内容显示区段。概念摘要和关系信息是基础区段。长文内容由带稳定 ID 的标题、段落、公式和图解组成；图解声明标题、说明和图注，互动继续通过登记式组件 ID 引用。微积分与线性代数是当前正式内容案例：前者接入完整文章、概念图、来源和互动组件；后者接入一张父级导览卡、十七张子域独有主题卡、一张公共向量卡、矩阵世界三视图、来源和许可说明。前沿入口通过概念 ID 查询统一目录，并在雷达中显示研究进展、开放问题、历史里程碑、标签和来源。空区段不显示标题。

新增或重写知识卡片介绍以前，必须先阅读 [`docs/CONTENT_TEMPLATE.md`](../docs/CONTENT_TEMPLATE.md) 中的段落格式和行文风格，并阅读其中链接的微积分实际版本。模板是写作约束真源，本手册只记录产品行为。

卡片中的“放大查看内部”会沿当前画布连续深入。该操作只在概念关联有效子空间时出现。单击节点本身继续用于打开卡片，完整规则见[节点钻取与 LOD](./06-节点钻取与LOD.md)。

卡片需要稳定链接。链接至少包含概念 ID；位于子空间时同时包含空间路径。分享链接重新打开后，应恢复目标卡片和可用的场景上下文。

## 互动组件

互动组件是卡片中的登记式教学模块。每个组件声明稳定组件 ID、版本、学习目标、输入边界和完成条件。内容记录只引用组件 ID 和经过校验的参数，不直接携带可执行脚本。

当前导数组件允许调整基准点和两点间距，并同步显示切线斜率、割线斜率和斜率差。用户移动基准点并把两点间距缩小到规定值后，组件发送标准完成事件。领域逻辑把完成记录写入当前概念进度。微积分的二维和三维卡片复用同一个组件与完成记录；三维深色主题使用对应的图表、控件和读数配色。

矩阵世界使用卡片内部的轻量视图状态，不登记学习完成事件。三个按钮使用原生 `button` 和 `aria-pressed` 表达当前视图；切换后只替换一张内联 SVG 和对应阅读提示。每张 SVG 都提供独立标题与长说明，关键条件同时以正文列表出现。窄栏保留可聚焦的横向滚动区域，避免把公式压缩到不可读；深色主题使用同一结构和独立对比配色。

组件默认不把每次输入写入玩家进度。只有内容记录声明的完成条件可以产生完成事件。重新打开卡片时，是否恢复中间状态由组件配置决定；已经确认的完成记录绑定概念 ID 和组件版本。

未知组件 ID 会显示安全的静态替代。加载失败后的重试入口仍在规划中。静态替代不自动满足完成条件。

## 组件注册与数据约束

互动组件通过注册表加载。注册项至少包含 `componentId`、支持的内容版本、参数校验器和 React 组件入口。内容构建阶段检查引用是否存在，运行时再次校验参数。

完成事件应包含概念 ID、组件 ID、组件版本和结果。组件不能直接修改全局发现状态、掌握集合或路线记录。版本升级改变完成含义时，需要迁移旧记录或要求重新完成，并在界面中说明结果。

数值组件需要明确单位、有效范围、精度和异常输入行为。随机过程需要支持固定种子，便于复现示例和测试。外部嵌入内容需要遵守来源许可和页面安全策略。

## 界面与无障碍

知识卡片由 React 渲染，与 PixiJS 和 Three.js 地图渲染器分离。地图渲染层的更新不改变卡片数据、链接和互动组件状态。长文标题使用语义化层级，公式带有文字解释，概念图提供可读标题、描述和图注；互动图表保留键盘控件和实时文本读数。

桌面端卡片与前沿雷达位于同一个可调宽度的右侧工作台。移动端统一使用底部面板，并保留返回地图的明确入口。工作台滚动条使用透明轨道，不显示系统底色、轨道或两端按钮，只保留悬浮在面板内的圆角滑块；浅色与深色面板分别使用可辨识但克制的滑块颜色。工作台内容滚动和左边缘拖拽不得带动画布缩放、平移或三维旋转。

所有卡片操作需要支持键盘。焦点进入卡片后按照内容顺序移动，关闭时回到触发节点。前沿雷达打开时，`Escape` 优先关闭雷达并把焦点恢复到实际打开它的按钮；拖拽分隔手柄提供可读名称、当前宽度和方向键替代操作。图表和画布互动需要提供文本名称、键盘操作或等价控件。组件需要遵守降低动态效果设置。

## 开发约束

- 卡片从概念 ID 查询数据，不保存地图节点对象或 PixiJS 图元。
- 关系列表读取统一关系数据，不能单独维护前置和后继文案事实。
- 内容区段使用登记的类型和 Schema。未知区段以安全方式跳过并记录错误。
- 自动导入内容只能进入暂存区，审核完成后才进入公开卡片。
- 互动组件不得执行内容文件提供的任意代码，也不得绕过参数校验。
- 来源、前沿和奖项区段遵守[前沿研究与奖项](./08-前沿研究与奖项.md)及[内容规范与审核](./09-内容规范与审核.md)。
- 卡片关闭和节点切换需要取消不再使用的加载请求，避免旧响应覆盖新选择。

## 边界情况

- 选中节点在当前筛选下被弱化时，卡片继续显示，地图保持原筛选条件。
- 内容只有摘要时，卡片只显示可用区段。
- 组件 ID 未登记或版本不兼容时，卡片显示静态替代和错误状态。
- 参数越界时，组件拒绝运行并指出需要调整的字段。
- 同一组件出现在多个概念中时，完成记录按概念 ID 分开保存。
- 卡片加载期间用户选择新节点时，旧内容不得在新卡片中闪现。
- 深层链接中的概念存在而空间路径失效时，系统在最近有效场景打开卡片。
- 关系数据更新后，卡片根据当前图谱重新显示前置和后继状态。

## 验收标准

### 当前版本

1. 从地图、搜索和关系列表选择节点时，卡片内容同步更新，画布相机矩阵保持不变。
2. 卡片显示节点数据中的领域、层级、文字、标签、直接关系和建议时长。
3. 场域标签按钮会更新地图筛选，关系项会打开对应节点。
4. 探索模式中的未发现内容不会出现在详情面板；可学习节点和已掌握节点的按钮行为符合状态规则。
5. 关闭卡片后，画布位置、筛选和本地进度保持不变。
6. 微积分卡片显示完整文章、概念图、公式、来源和互动组件，组件满足条件后记录完成事件。
7. 三维公共知识卡片把标签显示在节点简介下方，并把当前透镜和类型化相邻关系显示在正文、图解、来源和互动内容之后；选择关系项时相机保持不变。
8. 三维画布单击空白关闭卡片，拖动画布保持卡片打开。
9. 三维地图内只显示光点和中文气泡，不创建标题卡或完整卡；完整内容只由右侧详情承载。
10. 切换三维颜色主题后，画布节点纹理和右侧公共知识卡片使用对应配色，当前相机和选择保持不变。
11. 进入任一已注册三维作用域后，选择内部节点会打开对应卡片并保持当前相机倍率，关系列表只显示当前子域中的有效类型化关系。
12. 三维选中节点的全部屏幕内直接关联气泡保持显示，不受远景 LOD、球体背面权重、碰撞或屏幕标签面积预算限制。
13. 二维和三维卡片只在存在关联条目时显示“前沿动态”入口，入口中的数量与前沿目录查询结果一致。
14. 从卡片打开雷达后，雷达按当前概念收窄；清除范围后恢复全部公开内容。
15. 详情卡和前沿雷达复用同一右侧工作台宽度；桌面拖拽或方向键调整后，二维画布保留区和本地宽度记录同步更新。
16. 雷达开启时，二维与三维命中卡片复用关联卡高亮，其他当前可见卡片降低透明度；关闭雷达后恢复原选择聚焦。
17. 雷达展开期间二维与三维节点仍可交互；选择任意可用节点后，右侧工作台以节点详情替换雷达，保持当前相机并切换为该节点的关系聚焦。
18. 三维选中节点保持普通气泡并把星点核心放大到两倍；关联气泡重叠时按相机空间深度绘制，近处覆盖远处，节点锚点和关系几何保持不变。
19. 详情卡与前沿雷达的滚动条不显示不透明轨道或两端按钮，只显示与当前明暗主题保持对比的圆角滑块。
20. 二维与三维微积分卡片从同一内容记录读取章节顺序和来源；三维卡片可以完成导数互动，深色主题下的正文、概念图、公式和控件保持可读。
21. 三维右侧详情具有 46 CSS 像素固定顶栏、38 CSS 像素固定页脚和页脚横线上方 5 CSS 像素渐隐带；滚动 176 CSS 像素后紧凑图标与标题完全接管顶栏。三维正文不显示“内容状态”。线性代数图标每次打开只播放一个 2 秒周期，关闭并重新打开后才重播。
22. 线性代数公共父卡只显示领域说明和学习路线；二维与三维的十二个内部节点使用相同稳定概念 ID，并各自命中唯一正式内容记录。矩阵世界只在“矩阵性质图谱”挂载一次；三个图解视图可以通过键盘按钮切换，窄栏可横向阅读，明暗主题均保持可辨认。类型关系明确区分实对称与一般实正规矩阵，矩阵分解节点使用带主元的 `PA=LU`，协方差节点写成必然半正定且仅在非退化时正定，SVD 与伪逆分别拥有低秩近似和最小范数解的解释。

### 规划版本

1. 稳定链接可以恢复目标概念卡片和有效空间路径。
2. 未登记组件、无效参数和加载失败均有可阅读的降级内容。
3. 组件只有在满足声明的完成条件后才发送完成事件，无法直接修改全局进度。
4. 键盘可以完成卡片打开、区段浏览、组件操作和关闭流程。
5. 同一概念的多个投影共享内容、来源和完成记录。
6. 替换地图渲染器后，卡片和互动组件行为保持一致。
