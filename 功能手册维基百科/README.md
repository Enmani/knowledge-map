## 当前范围与目标范围

当前原型收录 46 个数学全景主节点、69 个二维子节点投影和 184 个三维公共理科节点。数学全景公开 15 个可钻取子空间，微积分内部另有 1 个多元微积分子空间投影。三维公共空间包含数学、物理、化学、生物四个领域，每个领域包含 46 个主节点，并提供 487 条关系和六个公共透镜。三维微积分子域复用二维微积分中的 6 个节点和 7 条前置关系。画布浏览、节点详情、标签场域、前置关系、搜索、本地学习进度、两种浏览模式、迷雾、通用三层钻取、故事内容、一个互动组件、三维相机和连续公共投影已经可以使用。各专题页的“当前”部分记录现有行为。

目标范围继续扩展数学、物理、化学和生物的内容深度。知识点通过前置关系形成学习路径，通过标签和领域归属形成空间场域。用户从起点开始探索，完成阅读和互动后解锁后续内容。节点可以包含子空间，缩放到指定层级后显示内部知识结构。公共视角与个人认知状态分别维护。各专题页的“规划”部分记录目标行为和验收标准。

当前地图提供两种使用模式。探索模式记录发现和掌握进度，并执行解锁规则。自由浏览模式允许直接搜索和访问公开内容。

## 文档维护

产品行为发生变化时，应在同一个合并请求中更新相关页面。数据格式发生变化时，应同步更新技术架构、内容规范和术语表。文档中的规划功能需要标明目标行为，不得写成已经上线的功能。
