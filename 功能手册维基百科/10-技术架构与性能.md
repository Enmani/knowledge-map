# 技术架构与性能

[返回首页](./README.md)

本页同时记录当前架构和目标架构。标有“计划”或“目标”的内容尚未接入主应用。

## 总体结构

项目采用模块化前端结构。知识数据、图谱规则、布局计算、地图渲染、界面组件和玩家进度分别维护。早期版本使用本地内容文件和浏览器存储。服务端同步在账号和协作需求明确后接入。

主要模块如下：

```text
src/
  domain/          知识实体、关系、进度和校验
  knowledge/       公共多领域知识、透镜和三维投影
  content/         概念故事和来源
  engine/          场景、布局、LOD、相机和迷雾
  frontier/        前沿条目、来源、查询与校验
  renderers/       地图渲染适配器
  features/        地图、前沿雷达、详情、进度和导航
  widgets/         互动组件及注册表
  persistence/     本地进度和设置
```

## 数据流

二维内容文件经过格式校验后进入知识图谱。场景投影器根据当前空间筛选节点和关系。布局引擎为主场景计算紧凑花瓣领域簇，为子场景计算依赖分列。LOD 管理器根据相机和屏幕尺寸生成可见层级。三维公共数据经过独立结构校验，知识球投影器根据严格前置深度、正四面体领域方向、关系权重和标签计算节点、关系和场域状态。统一右侧工作台通过选中的概念 ID 或前沿雷达状态读取内容；桌面宽度由 React 单一状态维护，并传给工作台、二维地图内核和相机可用视口计算。

知识数据不保存渲染器对象。布局坐标属于空间投影。玩家进度绑定概念 ID。地图渲染器可以替换，内容和进度保持兼容。前沿目录使用 `relatedConceptIds` 连接稳定知识概念；React 前沿雷达按审核状态、类型、标签和概念查询目录，来源通过来源 ID 统一读取，并把当前可见条目的概念集合上报给共享卡片聚焦模块。

## 场景与 LOD

当前场景目录包含数学全景和 16 个子场景投影，其中 15 个直属数学全景，1 个直属微积分。多元微积分的规范投影与微积分中的别名投影各自关联向量微积分子场景。复动力系统在复分析和动力系统中使用共享概念投影。每个子场景通过稳定嵌入矩阵映射到所属父节点，递归组合后得到根坐标。单一根坐标相机负责全部缩放和平移。导航栈保存空间路径，换根只改变交互语义。界面挂载当前钻取关系的父层和子层。两个图层在进入和退出期间保持稳定，完全进入后父层透明度为零。

`src/features/map/analysisSceneContent.ts` 保存 10 组分析学专题节点数据。`sceneCatalog.ts` 将主地图节点、微积分节点、单节点专题和分析学专题统一转换为 `MapScene`。分析学专题场景使用 9200 × 3300 的世界区域、六倍卡片尺寸、220 个世界单位的节点间距和推进式布局。

LOD 使用节点投影到屏幕后的像素尺寸。连续显隐倍率会结合场景有效缩放和卡片尺寸倍率，使多层钻取保持接近的视觉触发尺寸。父作用域中的子层透明度由缩放进度和门户居中度共同计算；进入子作用域后只使用缩放进度。导航和交互作用域读取同一透明度值，在 80% 进入阈值和 20% 退出阈值之间保持滞回。单击子卡片可以将当前父子关系的显示值固定到 100%，缩放会解除固定，平移保留当前子域。子层完全显示时父层透明度归零。子节点选择只更新选择状态和详情，不修改相机矩阵。布局与父子嵌入矩阵在缩放过程中保持稳定。大型子场景的异步加载与缓存仍属于后续计划。

三维微积分子域通过 `calculusSubspace.ts` 读取二维 `MapScene`，生成带命名空间的节点身份、局部坐标和前置关系。局部坐标映射到微积分父节点所在球壳的切平面。内部卡片使用公共节点基础尺寸的 14.4%。父卡片投影高度通过平滑曲线生成子层权重，父层权重由同一进度生成。作用域切换与视觉显隐解耦：子层达到 80% 且相机达到 `scopeEnterZoom = 12.45` 时进入，进入后在相机高于 `scopeExitZoom = 8` 时保留已达到的子层权重，到达退出倍率才向 React 提交公共作用域。逐帧透明度、命中状态和相机更新保留在 `ThreeKnowledgeRenderer` 中。双击父节点使用同一子域运行时和显隐曲线，不创建第二套导航状态。

## 渲染边界

React 负责页面框架、视图模式、搜索、前沿雷达、统一右侧工作台和互动组件。二维主画布使用 PixiJS v8 WebGL。渲染器在初始化时建立场景目录中的节点、连线、标签场、迷雾、前沿徽标和文字图元，并在首帧前完成文字栅格化与纹理上传。运行帧更新相机矩阵、父子场景矩阵、透明度、可渲染状态和共享卡片聚焦角色。前沿徽标只读取概念关联条目数量；雷达高亮复用关系聚焦描边，不建立第二套前沿轮廓。WebGL 初始化失败时，地图区域显示明确的错误状态。

布局算法、前置关系、解锁规则和内容数据不依赖 PixiJS。`MapRenderKernel` 把相机与作用域状态解析为稳定的渲染帧，PixiJS 适配器读取 `MapScene` 与交互状态。

三维公共空间使用 Three.js WebGL，并在首次进入三维模式时动态加载。`src/knowledge/space3d/catalog` 分领域保存规范节点与前置关系，`bridges.ts` 保存明确的跨域联系，`data.ts` 组合公共数据集。`ThreeKnowledgeRenderer` 为每个节点建立保留式 Sprite，为每条关系建立 Line。每个领域场或标签场使用一个带着色器的 InstancedMesh，批量绘制成员节点周围的相机朝向 PlaneGeometry 散点。每个散点包含两个三角面。Raycaster 只命中可见、可交互且达到显示阈值的节点图元。

三维微积分子域的 6 个节点 Sprite 和 7 条关系 Line 在渲染器初始化时建立。折叠状态通过显示权重停用绘制、LOD 避让和 Raycaster 命中。显隐阈值不修改场景图对象数量。子域完全显示时，公共节点、公共关系和场域的最终显示权重为零。

三维颜色主题由 React 保存并传入 `ThreeKnowledgeRenderer`。主题切换时保留场景对象和相机状态，释放已经创建的标题卡与完整卡纹理，再按当前 LOD 延迟生成对应主题纹理。光点纹理、节点坐标、关系几何和场域实例保持复用。深色界面的 CSS 基底固定为 `rgb(24, 24, 24)`。

二维和三维组件条件挂载。三维模式下，画布父元素不绑定 PixiJS 的指针捕获、点击捕获或滚轮处理。两套渲染器使用独立选择、相机、错误和筛选状态，但共同读取 `cardFocus.ts` 解析出的 `primary / related / context / default` 显示身份和 0.46 上下文淡化系数。三维节点详情只读取公共知识记录，当前不接入玩家进度、迷雾或解锁计算。

## 公共三维投影

公共全景不保存人工三维位置。严格前置图的最长路径深度决定知识半径，`level` 提供校准和异常后备。深度半径公式为 `r = rCore + (R - rCore) × (d / dMax)^γ + Δr`。数学、物理、化学和生物采用正四面体方向，多领域节点使用领域方向加权和。关系力与标签力在球壳切平面内作用，径向锚定维持知识深度。三维空间哈希只检查相邻网格的节点锚点碰撞，默认锚点半径为 0.78，间隔为 0.18。完整卡片的遮挡由渲染器的屏幕空间 LOD 避让解决。相同输入始终生成相同结果。

渲染层不创建固定线框球壳。知识球的球心和深度半径仍由投影数据保存，节点、关系和三维颜色场域共同表达球体范围。移除装饰球壳不改变投影坐标、旋转锚点、碰撞或射线命中。

临时领域筛选只改变可见性。专业聚焦保留领域节点、必要前置闭包和关键跨领域桥梁，使用稳定散列分配固定 4096 槽 Fibonacci 球面采样，并保留 20% 至 35% 的公共方向锚定。两种模式均保持公共知识半径。隐藏节点退出渲染、关系、场域、搜索和射线命中。

透镜或筛选切换时，Three.js 保留现有图元，并通过阻尼插值更新节点位置、透明度、比例、关系权重、球瓣位置、球瓣半径、球瓣透明度和相机。节点身份与关系记录保持不变。普通关系线使用较低默认透明度；单卡选择时主卡和一跳关系卡进入聚焦，前沿雷达开启时命中卡片作为批量关联集合进入相同聚焦，集合外关系进一步降低。

三维相机使用透视投影。左键拖动平移。滚轮倍率使用 `PerspectiveCamera.zoom` 作为唯一全局尺度，范围为 `0.1` 至 `128`，重置值为 `1`，左下角显示 `round(camera.zoom × 100)%`。滚轮步进使用 `2^clamp(-deltaY × unit × control, -0.24, 0.24)`，像素、行和页滚轮分别使用对应单位换算。节点和空白使用同一倍率响应。连续帧使用 90 毫秒时间常数在对数倍率空间接近目标值。滚轮先用射线确定鼠标下的世界锚点；命中节点时使用节点交点，远景光点的近邻命中使用节点深度平面，空白处使用射线与观察平面的交点。每个连续帧根据锚点的相机空间坐标 `(a_x, a_y)` 沿相机右轴和上轴补偿 `a_x(1-Z/Z')` 与 `a_y(1-Z/Z')`。该补偿同步平移相机位置和观察点，二者的深度距离保持稳定。Alt 加左键或右键启动旋转时计算当前作用域枢轴 `P`：公共作用域读取投影声明的知识球心；子域读取其 `n` 个卡片当前世界坐标的算术中心 `P = (1/n)Σx_i`，没有有效卡片时回退到知识球心。枢轴在 `pointerdown` 时写入本次手势，节点动画、悬停和射线命中不会让拖拽中的枢轴漂移。每次指针增量生成偏航四元数 `q_y` 和俯仰四元数 `q_p`，使用 `q = q_p q_y` 计算 `C' = P + q(C - P)` 与 `T' = P + q(T - P)`。相机位置和观察点围绕当前作用域中心同步变化。

双击命中具有 `ThreeKnowledgeSubspace` 声明的父节点时，渲染器先按当前父卡投影高度建立显隐区间，再计算 `Z_target = min(Z_max, max(Z, Z_enter, Z × 1.02 × revealEndPx / h_owner))`。父节点当前世界坐标成为缩放锚点，倍率继续使用与滚轮相同的 90 毫秒对数阻尼，因此相机与子域透明度在一次短暂连续动画中衔接。降低动态效果设置会直接应用目标倍率。没有子域声明、不可见或不可交互的节点不会启动该动画。

三维子域启动器读取同一次滚轮事件的射线命中结果。只有向内缩放且命中声明的父节点时才进入预备状态。子层开始显现前，其他向内缩放会取消预备状态。显现开始后保持当前父子关系。默认微积分显隐区间为 360 至 620 CSS 像素，高倍率首次启动时使用当前父卡片高度作为新区间起点，终点至少为起点的 1.65 倍；该像素区间只控制连续视觉显隐。独立的 1245% 进入倍率和 800% 退出倍率控制交互作用域，向外缩放在退出倍率之上不会折叠子域。

行走模式在渲染器内部保存按键集合。WASD 按当前相机水平方向移动，Q 和 E 沿世界 Y 轴移动。基础世界速度由相机与观察点距离限制在每秒 4 至 22 个世界单位，再除以全局相机倍率，使不同缩放百分比下的屏幕行走速度保持一致。每帧把相同位移加入相机位置、观察点和两个目标状态，当前观察方向与相机距离保持不变。只有鼠标位于三维画布时才处理行走按键。输入框、文本框、选择框和可编辑元素获得焦点时不处理行走按键。关闭模式或窗口失焦时清空按键集合。

## 性能策略

指针移动通过 `requestAnimationFrame` 合帧。相机矩阵保存在连续控制器中，动画帧交给 `MapRenderKernel` 计算场景合成结果，再由 PixiJS 更新保留图元的矩阵和透明度。React 状态在动画结束和作用域阈值事件中提交。缩放数字通过固定 DOM 文本节点读取连续相机矩阵并逐帧更新。

父层和子层分别保存稳定的选择、路径、筛选和 LOD 渲染上下文。作用域切换不会替换场景图层，也不会让节点和连线随当前空间重新生成。PixiJS 应用关闭连续 ticker，只在相机帧或视觉状态变化后提交一次显式绘制。

地图组件卸载或重新初始化时会取消尚未完成的 PixiJS 创建流程，并立即释放已建立的 Canvas、纹理与 WebGL 上下文。开发环境的严格模式重复挂载不会留下重叠画布或重复 GPU 资源。

Three.js 关闭无条件动画循环。输入、透镜过渡或相机阻尼开始时请求动画帧，状态稳定后停止。设备像素比上限为 1.6。ResizeObserver 读取三维宿主元素的实际尺寸。卡片、标题和光点纹理按实际 LOD 懒创建。组件卸载时移除输入监听，取消动画帧，释放已创建纹理、材质、几何、渲染列表和 WebGL 上下文。三维模块独立分包，不增加二维首屏的 Three.js 执行成本。公共投影按透镜和筛选参数缓存，重复切换复用确定性结果。

三维节点依据相机空间深度、全局相机倍率和投影参数计算屏幕高度，并把实时指标交给 `stableLod.ts`。标题采用 28 像素进入、20 像素退出阈值，完整卡采用 70 像素进入、54 像素退出阈值。候选半球资格在点积高于 -0.05 时进入、低于 -0.3 时退出。调度器用可见节点中位投影高度生成 0 至 1 的细节量，并按视口面积把普通文字卡名额从每 120000 平方像素一张逐步放宽到每 32000 平方像素一张，数量限制在 6 至 80。远景评分权重为语义 0.85、正面 0.1、尺寸 0.05；近景平滑过渡到 0.55、0.25、0.2。中近景中，连续隐藏 6 秒的节点最多获得 0.08 等待奖励。当前文字卡获得 0.08 保留加成。评分使用 140 毫秒响应平滑，离散分配每 80 毫秒执行；升级候选连续保持 140 毫秒、降级候选保持 80 毫秒且当前 LOD 至少保持 180 毫秒后才提交，每次最多更换四张普通卡片。聚焦主卡始终显示完整卡，`related` 卡片优先完整卡并至少保留高亮标题卡，这两类显式交互状态不受普通换位额度限制。普通节点发生冲突时依次降为标题或光点，节点坐标不变。球体背面的普通节点降低显示权重。关联卡片免除背面衰减，并在当前作用域内保持 0.88 的最低最终透明度；`context` 卡片乘以 0.46 的共享淡化系数。三维默认、主卡和关联卡纹理继续按节点和主题懒缓存，雷达筛选变化只切换角色发生变化的节点，不销毁或重建场景。普通可见标题卡和完整卡在没有聚焦时使用 0.58 至 0.86 的材质透明度范围，纹理面板使用 0.86 的填充透明度。光点悬停使用独立标题 Sprite，按相机空间深度抵消全局倍率后保持 168 × 42 CSS 像素，并在节点投影点周围提供 10 CSS 像素命中半径。

节点 Sprite 使用 `default / selected / hovered` 三档显示层，当前顺序值为 `3 / 30 / 40`。选中与悬停层关闭材质深度测试，使卡片只在绘制上覆盖普通节点；悬停层覆盖选中层。悬停目标复用领域色关联纹理，最低显示透明度为 0.94，视觉宽高以阻尼过渡到 1.06 倍。移开后纹理、透明度、显示层和比例恢复；如果已有选中卡，选中卡继续停留在第二档显示层。显示层也用于重叠 Sprite 的射线命中排序，优先级相同时才比较相机距离。悬停身份不写入 `resolveNodeLods` 的候选优先级，不绕过既有碰撞结果，也不把放大后的矩形加入标签占位；因此其他卡片不会因鼠标移动而重新选择 LOD。所有变化只写 Sprite 的 `renderOrder`、材质和局部显示尺寸，不写 `currentPosition`、`targetPosition` 或 Group 的世界比例。远景光点继续使用独立悬停标题，标题位于悬停卡之上。

三维场域使用 4 个领域场和 51 个自动标签场，当前共包含 787 个成员散点。只有至少被两个节点共用的标签会生成场域。每个场域只产生一次实例化绘制调用。散点几何从每个球瓣约 224 个三角面降到 2 个三角面，当前场域几何约为 1574 个三角面。片元着色器根据归一化半径计算五次平滑边缘，并通过 `1 - exp(-0.72g)` 限制中心密度。颜色使用 `1 - (1 - C)(1 - αc)` 屏幕混合。隐藏散点的实例透明度为零。

场域实例缓冲只在透镜、专业聚焦或筛选引起成员位置、半径和透明度变化时更新。相机平移、旋转与行走只改变视图矩阵，全局缩放只改变投影矩阵；顶点着色器根据相机矩阵生成朝向相机的散点。颜色场域开关只更新场域整体透明度 uniform。稳定状态不逐帧重写 787 个实例矩阵和成员透明度属性。场域层在独立 WebGLRenderTarget 中以主画布物理分辨率的 42% 绘制，随后使用线性过滤合成。场域片元数量在同等屏幕覆盖下约为全分辨率的 17.6%。节点、关系、文字和射线命中继续使用主画布分辨率。

每个标签场在场景建立时把成员圆和场域连接合并成一张裁剪后的低分辨率蒙版，再统一模糊、着色并上传为单个纹理。同一场域的几何重叠不会重复叠加透明度。场域之间使用普通透明度混合，在重叠位置形成混色。筛选只切换已存在纹理的可见性和整体透明度，平移和缩放不重建场域。当前帧最多显示一个父层和一个正在显现的子层。远处图元裁剪、子空间异步加载和构建期搜索索引属于后续计划。

缩放过程中更新世界变换和父子层透明度。子场景复用已经生成的布局、关系、文字与场域图元。WebGL 内部视口使用地图宿主元素的实际 CSS 宽高，命中坐标也从该边界换算；设备像素比只改变后备缓冲区分辨率。布局计算达到明显耗时时移入 Worker。

## 性能预算

当前 PixiJS 渲染器预构建场景目录中的图元。逻辑数据可以继续增长，常驻图元应控制在 3,000 个以内。三维公共数据包含 184 个节点、487 条关系、4 个领域场和 51 个标签场。三维微积分子域增加 6 个常驻节点和 7 条常驻关系。球面松弛默认执行 48 轮，最终装箱最多执行 120 轮，两个阶段均重用确定性结果缓存。桌面设备的连续平移、缩放和透镜过渡目标为接近 60 FPS。点击反馈目标为 100 毫秒以内。暖缓存子空间展开目标为 100 毫秒以内。

性能数据需要在指定测试设备和浏览器中记录。官方库基准只能作为参考，不能替代项目场景测试。

## 故障处理

布局数据损坏时，场景回退到上一个 `layoutVersion`。子空间加载失败时，父场景保持可操作，并显示重试入口。过渡动画被取消时，导航状态回到最近的稳定场景。浏览器失去指针捕获时，拖拽状态立即结束。

## 验收标准

地图拖拽和缩放不会按动画帧触发整页重复渲染。缩放百分比随连续相机逐帧变化。父子图层在作用域切换时保持相同实例。子域中的平移不会改变当前作用域。缩放临界点不会产生持续闪烁。折叠子空间无法响应指针事件。PixiJS 画布与地图宿主元素使用相同的 CSS 视口，10% 至 100% 缩放下的命中位置与图元位置一致。标签筛选节点和其他不可交互节点不会被 PixiJS 命中。场域保持定义颜色并在重叠处混色，单个场域内部不产生重复透明度。三维公共全景具有可测量的 XYZ 体积，节点半径随前置深度总体递增，画面不显示固定线框球壳。三维节点在六个透镜和筛选模式间保持相同实例，射线命中与视觉位置一致，隐藏节点不能被命中，空白点击和拖动语义分离，镜头复位恢复当前透镜声明的位置与 100% 全局倍率。三维滚轮缩放保持光标下的世界锚点；全局倍率范围为 10% 至 12800%；节点与空白使用相同滚轮响应和 90 毫秒对数阻尼。公共作用域旋转使用知识球心；子域旋转使用该子域卡片当前世界坐标的算术中心；同一次拖拽期间节点悬停、命中和动画不改变已锁定的旋转中心。选中卡片在无其他悬停时保持最上层；悬停卡片临时覆盖选中卡并平滑放大到 1.06 倍，显示层和命中优先级变化不改变节点坐标，也不改变其他卡片的 LOD 或标签占位。实时 LOD 使用 80 毫秒评估、升级 140 毫秒与降级 80 毫秒候选驻留、180 毫秒最短保持、0.08 当前卡保留加成和单轮四张换位上限；标题与完整卡分别采用 28/20 和 70/54 像素滞回阈值；远景语义重要度主导，中近景增加正面、尺寸和有限等待奖励。远景光点悬停名称保持固定屏幕尺寸。普通三维标题卡和完整卡保持稳定半透明，筛选节点退出过程不受半透明下限影响。三维场域散点边缘连续降到零，使用有界屏幕混合，中心密度受指数响应限制。稳定场域在相机移动期间不重写实例缓冲。行走模式移动相机与观察点并保持当前距离，文本输入期间不响应行走按键。颜色场域开关不改变节点和相机状态。左下角颜色主题切换会更新界面与节点纹理，深色基底为 `rgb(24, 24, 24)`，相机、选择、筛选和场域状态保持不变。临时筛选保持公共坐标，专业聚焦保持知识半径并确定性重排球面方向。三维微积分子域可以由命中父节点的向内滚轮或双击父节点启动；双击通过短暂平滑倍率动画进入；6 个子节点与 7 条关系保持常驻；子层达到 80% 且实际倍率达到 1245% 后接管搜索、详情和命中，进入后缩小到 800% 才恢复公共作用域，滞回区间内子卡片保持可见和可交互；子层完全显示时父节点、父关系和颜色场域不可见。开发环境连续刷新后，每个地图宿主只保留一个 Canvas。连续进入和退出四层后，相机和面包屑保持一致。重复模式切换和钻取后内存趋于稳定。更换未来地图渲染器时，知识 ID、关系和玩家进度保持兼容。
