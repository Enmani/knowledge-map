# 技术架构与性能

[返回首页](./README.md)

本页同时记录当前架构和目标架构。标有“计划”或“目标”的内容尚未接入主应用。

## 总体结构

项目采用模块化前端结构。知识数据、图谱规则、布局计算、地图渲染、界面组件和玩家进度分别维护。早期版本使用本地内容文件和浏览器存储。服务端同步在账号和协作需求明确后接入。

主要模块如下：

```text
src/
  domain/          知识实体、关系、进度和校验
  knowledge/       公共多领域知识、透镜和三维投影
  content/         概念故事和来源
  engine/          场景、布局、LOD、相机和迷雾
  frontier/        前沿条目、来源、查询与校验
  renderers/       地图渲染适配器
  features/        地图、前沿雷达、详情、进度和导航
  widgets/         互动组件及注册表
  persistence/     本地进度和设置
```

## 数据流

二维内容文件经过格式校验后进入知识图谱。场景投影器根据当前空间筛选节点和关系。布局引擎为主场景计算紧凑花瓣领域簇，为子场景计算依赖分列。LOD 管理器根据相机和屏幕尺寸生成可见层级。三维公共数据经过独立结构校验；`semanticLayout.ts` 根据关系亲和矩阵、谱嵌入、基础—专业化半径和 Poincaré 图距离应力生成公共语义布局，`projection.ts` 再结合透镜、筛选、碰撞和场域计算渲染状态。统一右侧工作台通过选中的概念 ID 或前沿雷达状态读取内容；桌面宽度由 React 单一状态维护，并传给工作台、二维地图内核和相机可用视口计算。

知识数据不保存渲染器对象。布局坐标属于空间投影。玩家进度先把投影 ID 解析为规范概念 ID 再写入，因此同一概念的跨域投影共享一份内容和进度。地图渲染器可以替换，内容和进度保持兼容。前沿目录使用 `relatedConceptIds` 连接稳定知识概念；React 前沿雷达按审核状态、类型、标签和概念查询目录，来源通过来源 ID 统一读取，并把当前可见条目的概念集合上报给共享卡片聚焦模块。

## 场景与 LOD

当前场景目录包含数学全景和 17 个子场景投影，其中 16 个直属数学全景，1 个直属微积分。多元微积分的规范投影与微积分中的别名投影各自关联向量微积分子场景。复动力系统在复分析和动力系统中使用共享概念投影。每个子场景通过稳定嵌入矩阵映射到所属父节点，递归组合后得到根坐标。单一根坐标相机负责全部缩放和平移。导航栈保存空间路径，换根只改变交互语义。界面挂载当前钻取关系的父层和子层。两个图层在进入和退出期间保持稳定，完全进入后父层透明度为零。

`src/features/map/analysisSceneContent.ts` 保存 10 组分析学专题节点数据，`src/features/map/linearAlgebraSceneContent.ts` 保存线性代数的 18 个投影节点、31 条严格前置和 7 条补充语义关系。`sceneCatalog.ts` 将主地图节点、微积分节点、线性代数节点、单节点专题和分析学专题统一转换为 `MapScene`；场景可覆盖全局标签场定义，显式场还可以用 `minimumMembers` 覆盖通用的三成员阈值，线性代数据此稳定显示五个学习阶段场。线性代数与分析学专题场景都使用六倍卡片、220 个世界单位的节点间距和推进式布局；线性代数场景再由 `linearAlgebraSubspace.ts` 转换为三维子域，二维和三维保持相同的 `linear-algebra:` 投影 ID。`conceptIdentity.ts` 把 `linear-algebra:vectors-coordinates` 解析为公共 `vectors-coordinates`，内容目录和进度仓库都在读写前执行同一规范化。

LOD 使用节点投影到屏幕后的像素尺寸。连续显隐倍率会结合场景有效缩放和卡片尺寸倍率，使多层钻取保持接近的视觉触发尺寸。父作用域中的子层透明度由缩放进度和门户居中度共同计算；进入子作用域后只使用缩放进度。导航和交互作用域读取同一透明度值，在 80% 进入阈值和 20% 退出阈值之间保持滞回。单击子卡片可以将当前父子关系的显示值固定到 100%，缩放会解除固定，平移保留当前子域。子层完全显示时父层透明度归零。子节点选择只更新选择状态和详情，不修改相机矩阵。布局与父子嵌入矩阵在缩放过程中保持稳定。大型子场景的异步加载与缓存仍属于后续计划。

三维子域定义统一调用 `createThreeKnowledgeSubspace.ts`。工厂接收父节点 ID、内部节点、局部坐标、类型化关系列表、节点比例与场域样式，自动生成命名空间身份、关系、共享标签场和默认进入退出参数。关系支持严格前置、建议前置、共享模型、类比和应用；重复节点、域外关系、自指、重复关系、无效强度或严格前置环会在定义加载时直接报错，非严格语义环允许存在。`subspaceRegistry.ts` 集中注册全部子域，并校验唯一子域 ID、唯一父节点、公共父节点存在性和全局内部节点身份。局部坐标映射到父节点当前基础—专业化半径所在球面的切平面。父卡片投影高度通过平滑曲线生成子层权重，作用域切换与视觉显隐解耦：子层达到 80% 且相机达到默认 `scopeEnterZoom = 12.45` 时进入，进入后在相机高于默认 `scopeExitZoom = 8` 时保留已达到的子层权重，到达退出倍率才向 React 提交公共作用域。逐帧透明度、命中状态和相机更新保留在通用 `ThreeKnowledgeRenderer` 中。

## 渲染边界

React 负责页面框架、视图模式、搜索、前沿雷达、统一右侧工作台和互动组件。二维主画布使用 PixiJS v8 WebGL。渲染器在初始化时建立场景目录中的节点、连线、标签场、迷雾、前沿徽标和文字图元，并在首帧前完成文字栅格化与纹理上传。运行帧更新相机矩阵、父子场景矩阵、透明度、可渲染状态和共享卡片聚焦角色。前沿徽标只读取概念关联条目数量；雷达高亮复用关系聚焦描边，不建立第二套前沿轮廓。WebGL 初始化失败时，地图区域显示明确的错误状态。

三维右侧详情由 `KnowledgeSpaceDetailPanel.tsx` 维护独立滚动容器、紧凑顶栏和固定页脚。滚动事件用 `requestAnimationFrame` 合并，只向 React 提交一个归一化的 0 至 1 收拢进度；该进度驱动主视觉/标题与紧凑身份的交叉缩放和淡入淡出，不写入 Three.js 相机或节点状态。节点 ID 变化时滚动位置与收拢进度重置。线性代数详情直接复用 `LinearAlgebraIcon`，把实验页的默认 4 秒无限循环通过组件参数覆盖为 2 秒、单次播放；关闭详情会卸载 SVG，再次打开自然重新开始。

正式长文由 `src/content/index.ts` 按规范概念 ID 建立目录，二维和三维详情复用 `KnowledgeArticle.tsx` 与同一内容记录。线性代数目录包含一张 `linear-algebra` 父级导览卡和十七张 `linear-algebra:` 内部主题卡；第十八个子域投影读取公共 `vectors-coordinates` 卡。详细公式和图解只归属一个内容宿主。`MatrixWorldFigure.tsx` 只挂载在“矩阵性质图谱”，并只保存当前三选一视图的局部 React 状态；类型关系、分解条件和应用线索分别渲染为内联 SVG，并同时输出可访问标题、说明和静态阅读提示。原作位图不进入构建产物，来源和 CC0 许可记录在内容来源与 `THIRD_PARTY_NOTICES.md`。

动态图标实验页通过根入口查询参数 `?demo=concept-icons` 独立挂载，不进入二维或三维地图的状态与渲染循环，也不出现在正式导航中。`src/features/concept-icons` 使用 React 内联 SVG、CSS 动画和 SVG 运动路径呈现正弦波、原子轨道、黄金螺旋、光锥、环面与线性代数六个原型。画廊以正方形网格承载每个原型；线性代数图标采用无消失点的正交投影，XY、XZ、YZ 三个完整方形平面从中心向正负方向延伸并彼此穿透，正面平面接近方形，另外两个平面分别横向和纵向斜穿。固定层始终保留三张原始平面的轮廓，动态层绘制完整网格并沿明确的加减速曲线绕中心旋转，停留后回到初始姿态。页面提供播放、暂停、从头播放和三级变速。暂停状态同时冻结 CSS 与 SVG 动画，降低动态效果偏好会把连续动画收敛为静态画面。实验页只在自身挂载时解除文档滚动锁定，默认知识地图继续使用固定视口。

布局算法、前置关系、解锁规则和内容数据不依赖 PixiJS。`MapRenderKernel` 把相机与作用域状态解析为稳定的渲染帧，PixiJS 适配器读取 `MapScene` 与交互状态。

三维公共空间使用 Three.js WebGL，并在首次进入三维模式时动态加载。`src/knowledge/space3d/catalog` 分领域保存规范节点与前置关系，`bridges.ts` 保存明确的跨域联系，`data.ts` 组合公共数据集。`ThreeKnowledgeRenderer` 为每个节点建立保留式 Sprite；全部公共关系和子域关系写入一个带位置、颜色、透明度、线段进度和选中脉冲标记顶点属性的 LineSegments。全部领域场、标签场和子域场写入一个带颜色、透明度、近景衰减区间实例属性的 InstancedMesh，批量绘制成员节点周围的相机朝向 PlaneGeometry 散点。每个散点包含两个三角面。Raycaster 只命中可见、可交互且达到显示阈值的节点图元。活动气泡解析器只返回 `glow` 或 `title`，主选择节点固定返回 `title`；完整卡片、线性代数卡片图标及其开合状态机继续保留为回退代码，但不接入当前 `syncBubbleNodeLods`。

七个已注册三维子域合计 74 个节点 Sprite、139 条关系记录和 40 个颜色场记录，在渲染器初始化时建立；关系与场域记录分别写入共享 LineSegments 和共享 InstancedMesh。折叠状态通过显示权重停用绘制、LOD 避让和 Raycaster 命中。显隐阈值不修改场景图对象数量或批次结构。任一子域完全显示时，公共节点、公共关系和场域的最终显示权重为零。

三维颜色主题由 React 保存并传入 `ThreeKnowledgeRenderer`。主题切换时保留场景对象和相机状态，释放已经创建的标题卡与完整卡纹理，再按当前 LOD 延迟生成对应主题纹理。光点纹理、节点坐标、关系几何和场域实例保持复用；场域材质只更新领域/标签颜色、曝光和饱和度 uniform。深色界面的 CSS 基底固定为 `rgb(24, 24, 24)`；关系批次切换到更高明度的五类关系色、加法混合和 0.36 的满强度基础透明度，浅色主题继续使用原颜色、普通混合和 0.24 基础透明度。

二维和三维组件条件挂载。三维模式下，画布父元素不绑定 PixiJS 的指针捕获、点击捕获或滚轮处理。两套渲染器使用独立选择、相机、错误和筛选状态，但共同读取 `cardFocus.ts` 解析出的 `primary / related / context / default` 显示身份和 0.46 上下文淡化系数。三维节点详情只读取公共知识记录，当前不接入玩家进度、迷雾或解锁计算。

## 公共三维投影

公共全景不保存人工三维位置。语义布局先建立对称亲和矩阵：标签 Jaccard 相似度系数为 0.12，领域归属余弦相似度为 0.035，相同主领域弱先验为 0.025；严格前置、共享模型、应用、建议前置、类比和历史关系的基础权重依次为 1、0.85、0.65、0.55、0.35 和 0.2，再乘以各自关系强度并以互补概率形式合并。归一化亲和矩阵的前三个非平凡谱分量经过每分量 72 轮确定性幂迭代，生成初始三维方向。八个领域没有固定方向锚点。

严格前置图的最长路径深度由 `level` 校准并提供异常后备；严格后继按路径距离以 0.55 指数衰减，形成归一化基础性分数。基础—专业化进度使用 72% 归一化深度和 28% 的反基础性组合，并强制每条严格前置保持至少 0.018 的径向进度顺序。默认核心半径 3.2、外层半径 13.4、指数 0.82、确定性扰动上限 0.16。

亲和度通过 `0.3 - log(A + ε)` 转换为边成本，全图最短路径经第 90 百分位缩放后生成应力目标。松弛过程比较当前 Poincaré 距离与目标图距离，并同时施加谱方向锚定、径向锚定和节点锚点防碰撞。默认执行 32 轮三维松弛，最终最多执行 120 轮球面装箱；节点锚点半径为 0.78，间隔为 0.18。中文气泡的遮挡由渲染器的屏幕空间选择与选中临时层解决；地图内没有活动完整卡片。相同输入始终生成相同结果。

渲染层不创建固定线框球壳。公共空间中心和基础—专业化半径由投影数据保存，节点、关系和三维颜色场域共同表达空间范围。`KnowledgeSphereParameters`、`ProjectionOptions.sphere` 与投影结果中的 `sphere` 字段暂时作为公共 API 兼容名称保留；移除旧领域锚点语义不改变旋转锚点、碰撞或射线命中接口。

应用层的领域菜单只请求临时筛选，因此筛选只改变可见性并保持公共语义坐标；隐藏节点退出渲染、关系、场域、搜索和射线命中。两个上拉菜单共用 `spaceControlMenu` 状态以保证互斥，并在选择选项、点击外部或按 `Escape` 时关闭。`projectKnowledgeSpace` 继续接受专业聚焦参数以兼容投影接口和算法冒烟测试，但 `App.tsx` 不再保存筛选模式状态，也不从当前界面请求专业聚焦。

透镜或筛选切换时，Three.js 保留现有图元，并通过阻尼插值更新节点位置、透明度、比例、关系权重、球瓣位置、球瓣半径、球瓣透明度和相机。节点身份与关系记录保持不变。单卡选择时主卡和一跳关系卡进入聚焦，主卡与直接关联卡之间的边在深色主题中最高提升至 0.92 透明度，并以 1.8 秒周期沿 `source → target` 播放行进脉冲；集合外关系进一步降低。前沿雷达只有批量关联集合而没有主卡，因此保留聚焦高亮但不启动方向脉冲。

三维相机使用透视投影。左键拖动平移。滚轮倍率使用 `PerspectiveCamera.zoom` 作为唯一全局尺度，范围为 `0.1` 至 `128`，重置值为 `1`，左下角显示 `round(camera.zoom × 100)%`。滚轮步进使用 `2^clamp(-deltaY × unit × control, -0.24, 0.24)`，像素、行和页滚轮分别使用对应单位换算。节点和空白使用同一倍率响应。连续帧使用 90 毫秒时间常数在对数倍率空间接近目标值。滚轮先用射线确定鼠标下的世界锚点；命中节点时使用节点交点，远景光点的近邻命中使用节点深度平面，空白处使用射线与观察平面的交点。每个连续帧根据锚点的相机空间坐标 `(a_x, a_y)` 沿相机右轴和上轴补偿 `a_x(1-Z/Z')` 与 `a_y(1-Z/Z')`。该补偿同步平移相机位置和观察点，二者的深度距离保持稳定。Alt 加左键或右键启动旋转时计算当前作用域枢轴 `P`：公共作用域读取投影声明的公共空间中心；子域读取其 `n` 个卡片当前世界坐标的算术中心 `P = (1/n)Σx_i`，没有有效卡片时回退到公共空间中心。枢轴在 `pointerdown` 时写入本次手势，节点动画、悬停和射线命中不会让拖拽中的枢轴漂移。每次指针增量生成偏航四元数 `q_y` 和俯仰四元数 `q_p`，使用 `q = q_p q_y` 计算 `C' = P + q(C - P)` 与 `T' = P + q(T - P)`。相机位置和观察点围绕当前作用域中心同步变化。

双击命中具有 `ThreeKnowledgeSubspace` 声明的父节点时，渲染器先按当前父卡投影高度建立显隐区间，再计算 `Z_target = min(Z_max, max(Z, Z_enter, Z × 1.02 × revealEndPx / h_owner))`。父节点当前世界坐标成为缩放锚点，倍率继续使用与滚轮相同的 90 毫秒对数阻尼，因此相机与子域透明度在一次短暂连续动画中衔接。降低动态效果设置会直接应用目标倍率。没有子域声明、不可见或不可交互的节点不会启动该动画。

三维子域启动器读取同一次滚轮事件的射线命中结果。只有向内缩放且命中声明的父节点时才进入预备状态；双击父节点复用同一启动器。子层开始显现前，其他向内缩放会取消预备状态。显现开始后保持当前父子关系。公共工厂的默认显隐区间为 360 至 620 CSS 像素，高倍率首次启动时使用当前父卡片高度作为新区间起点，终点至少为起点的 1.65 倍；该像素区间只控制连续视觉显隐。独立的 1245% 进入倍率和 800% 退出倍率控制交互作用域，向外缩放在退出倍率之上不会折叠子域。

行走模式在渲染器内部保存按键集合。WASD 按当前相机水平方向移动，Q 和 E 沿世界 Y 轴移动。基础世界速度由相机与观察点距离限制在每秒 4 至 22 个世界单位，再除以全局相机倍率，使不同缩放百分比下的屏幕行走速度保持一致。每帧把相同位移加入相机位置、观察点和两个目标状态，当前观察方向与相机距离保持不变。只有鼠标位于三维画布时才处理行走按键。输入框、文本框、选择框和可编辑元素获得焦点时不处理行走按键。关闭模式或窗口失焦时清空按键集合。

## 性能策略

指针移动通过 `requestAnimationFrame` 合帧。相机矩阵保存在连续控制器中，动画帧交给 `MapRenderKernel` 计算场景合成结果，再由 PixiJS 更新保留图元的矩阵和透明度。React 状态在动画结束和作用域阈值事件中提交。缩放数字通过固定 DOM 文本节点读取连续相机矩阵并逐帧更新。

父层和子层分别保存稳定的选择、路径、筛选和 LOD 渲染上下文。作用域切换不会替换场景图层，也不会让节点和连线随当前空间重新生成。PixiJS 应用关闭连续 ticker，只在相机帧或视觉状态变化后提交一次显式绘制。

地图组件卸载或重新初始化时会取消尚未完成的 PixiJS 创建流程，并立即释放已建立的 Canvas、纹理与 WebGL 上下文。开发环境的严格模式重复挂载不会留下重叠画布或重复 GPU 资源。

Three.js 关闭无条件动画循环。输入、透镜过渡、相机阻尼或选中关系脉冲开始时请求动画帧；状态稳定或取消选择后停止。关系脉冲期间每帧只更新一个时间 uniform，线段位置、颜色、透明度、进度和脉冲标记缓冲均不重复上传；降低动态效果时不启动该循环。设备像素比上限为 1.6。ResizeObserver 读取三维宿主元素的实际尺寸。当前主循环只懒创建中文气泡和光点纹理；完整卡、旧标题卡与“线性代数”正交网格卡片纹理工厂保留为回退实现，不由选择或悬停触发。组件卸载时移除输入监听，取消动画帧，释放已创建纹理、材质、几何、渲染列表和 WebGL 上下文。三维模块独立分包，不增加二维首屏的 Three.js 执行成本。公共投影按透镜和筛选参数缓存，重复切换复用确定性结果。

节点发光采用独立于颜色场域的双通道管线。光点状态由主 Sprite 绘制外晕基准尺寸 `50%` 的高分辨率白热核心并承担射线命中；节点进入中文气泡后，主 Sprite 改画文字覆盖层，同时启用一个不可命中的独立星点 Sprite 继续绘制同透明度核心。主选择节点把独立星点 Sprite 的宽高乘以 `SELECTED_NODE_STAR_SCALE = 2`，取消选择后恢复 1；低分辨率光晕批次的半径和光学密度不随选择放大。一个相机朝向 InstancedMesh 将全部节点的近白核心、由 `fieldColor` 提亮的领域色内晕和宽外晕累积到 28% 物理分辨率的半浮点缓冲，再用有界透明度全屏合成。深色主题的星点 Sprite 使用加法混合，浅色主题使用普通混合；文字覆盖层始终使用普通混合。合成层位于关系线和节点气泡下方，不使用全场景 Bloom。实例矩阵、颜色和光学密度分别带脏标记；稳定画面不上传实例属性，也不重绘节点光晕缓冲。相机矩阵、视口、主题、节点位置、作用域权重或发光动画变化时才刷新该通道。

动态图标实验页不建立 JavaScript 逐帧循环。连续运动交给 CSS 和 SVG 动画引擎，播放控制只修改统一播放状态或重建六个 SVG 原型；它与地图渲染性能预算分开评估。右侧详情中的线性代数 SVG 同样不建立 JavaScript 动画循环，SMIL 只执行一次 2 秒周期；详情滚动的标题收拢只复用浏览器滚动帧。

矩阵世界三视图没有逐帧动画，也不进入 PixiJS 或 Three.js 渲染循环。用户切换视图时 React 只替换当前 SVG 子树与三条或四条阅读提示；未选中的两张 SVG 不挂载。窄栏通过单个局部横向滚动容器保持公式字号，不改变右侧工作台宽度或地图相机。

三维普通节点由 `bubbleLayout.ts` 在光点与中文气泡之间分配，主选择节点同样使用中文气泡，地图内不再覆盖完整卡片。气泡测量和纹理共用 13 CSS 像素字号、26 CSS 像素高度与实测中文文字宽度；圆角读取旧完整卡片的圆角/内容高度比例并设置 3 像素下限，形成小圆角矩形而非胶囊。气泡中心沿相机上轴移动 29 CSS 像素，使底边位于星点中心上方 16 CSS 像素。气泡在每帧按相机空间深度换算世界宽高，不随镜头缩放改变屏幕尺寸。选择器直接使用上移后的普通气泡屏幕矩形，以 7 像素间距排除碰撞，并把累计气泡矩形面积限制在 CSS 视口面积的 11%。普通候选只保留当前作用域中有效透明度高于 0.01、位于相机前方、与视口相交且不过度位于背面的可交互节点；普通优先级由镜头距离和 `foundationScore` 两条队列组成，按“两张近邻、一张关系中心节点”确定性交织。`foundationScore` 来自严格前置图的折扣下游覆盖，不读取节点 ID 或作者重要度。

渲染器分别持有普通气泡快照和选中期间的临时气泡集合。`setCardFocusState` 不把 `related` 节点写入普通快照；存在主选择节点时，临时集合直接包含全部投影落在视口内的直接关联节点，不再经过普通候选的半球背面、节点遮挡、气泡碰撞或面积预算筛选，同时隐藏全部无关名称。关联气泡关闭深度测试，并使用“基础显示层 + 相机空间深度倒数”生成渲染顺序，因此重叠时远处先画、近处后画；主选择节点保持普通气泡并通过两倍星点核心表达选择。取消选中清空临时集合并直接恢复普通快照。最后单击节点立即写入普通快照，并继续复用原有 45% 有效视距与 0.75 倍频程保留锚点。相机平移、旋转、行走、缩放或节点过渡期间，`resolveNodeBubbles` 在每个既有渲染帧直接重建候选矩形与两套选择结果；只发生靠近缩放时，普通快照使用 `addOnly` 强制保留前一帧 ID。相机静止后停止普通选择计算并沿用最后一帧快照。气泡每帧根据相机空间深度换算世界尺寸与相机上轴偏移，从而保持固定 CSS 像素大小与星点间距。

`domainOverview.ts` 把全局倍率 100% 至 70% 映射为平滑远景进度。普通标题透明度使用其反值，八个大域 Sprite 使用远景进度乘以 `DOMAIN_LABEL_MAX_OPACITY = 0.5`；大域 Sprite 固定为 48 CSS 像素高，位置在每帧对该领域全部公共成员节点的当前坐标求平均，多领域节点分别参与各自所属大域。大域纹理只绘制领域色填充文字，不绘制黑色、白色或其他描边；深色主题把领域色向黑色混合 58%，浅色主题向黑色混合 12%，切换主题时重建八张纹理。主选择节点和直接关联气泡的名称透明度固定为 1，不受远景进度影响。

旧 `stableLod.ts`、`createKnowledgeTitleTexture`、`setNodeLod` 和 `resolveNodeLods` 全部留在仓库中作为可回退实现；当前 `advance()` 与 `updateSceneObjects()` 只调用 `resolveNodeBubbles`，不调用旧实时 LOD。

节点 Sprite 使用 `default / selected / hovered` 三档显示层，当前顺序值为 `3 / 30 / 40`。选中与悬停层关闭材质深度测试，使覆盖层只在绘制上越过普通节点；悬停层覆盖选中层。悬停目标最低显示透明度为 0.94，视觉宽高以阻尼过渡到 1.06 倍。移开后纹理、透明度和显示层恢复；选中节点保持普通气泡，独立星点 Sprite 的宽高为普通值两倍。显示层也用于重叠 Sprite 的射线命中排序，优先级相同时才比较相机距离。悬停身份不写入普通气泡快照，不绕过既有碰撞结果，也不把放大后的矩形加入气泡占位；因此其他节点不会因鼠标移动而改变光点/气泡状态。所有变化只写 Sprite 的 `renderOrder`、材质和局部显示尺寸，不写 `currentPosition`、`targetPosition` 或 Group 的世界比例。光点继续使用独立的中文气泡悬停提示，提示位于其他节点之上。

三维公共空间使用 8 个领域场和 110 个自动标签场；七个已注册子域再增加 40 个局部场。只有至少被两个节点共用的标签会生成标签场；线性代数额外按五个学习阶段显式生成阶段场。全部场域球瓣合并为一次实例化绘制；每个成员散点由 2 个三角面构成。片元着色器组合紧凑核心与宽阔辉光两个指数核，并使用平滑外包络消除面片边缘。顶点着色器根据球瓣投影到屏幕后的半径降低近景核心和辉光，使镜头推进时光场逐渐变淡。隐藏散点的实例透明度为零。光学密度采用加法累积，批次合并不改变叠色顺序或最终颜色。

关系批次把位置、颜色、透明度、线段进度和脉冲标记保存为独立顶点缓冲。线段起点进度为 0、终点为 1；只有主选择节点与直接关联节点之间的边把脉冲标记设为 1。片元着色器以 1.8 秒周期让高亮峰值沿进度 0 到 1 移动。只有语义布局或子域锚点实际移动时才上传位置，关系种类或主题变化时才上传颜色，聚焦或父子作用域变化时才上传透明度和脉冲标记；脉冲播放只更新统一时间。相机平移、旋转、缩放和行走不上传关系顶点。场域批次同样把实例矩阵、颜色/近景参数和透明度分为独立脏缓冲。稳定的关系与场域跳过透明度插值遍历；镜头运动只更新相机矩阵、气泡固定像素尺寸/偏移，以及当帧候选屏幕矩形和 ID 快照，不重写关系与场域几何缓冲。

场域源层在半浮点 WebGLRenderTarget 中以主画布物理分辨率的 42% 绘制，以 `ONE / ONE` 分别累积 `Σ(cτ)` 与 `Στ`。场域源层片元数量在同等屏幕覆盖下约为全分辨率的 17.6%。外层辉光使用两个 21% 分辨率半浮点缓冲，先横向再纵向执行五采样高斯模糊；每个辉光缓冲的像素面积约为全分辨率的 4.4%。三段离屏通道覆盖完整画布，不使用随场域位置变化的局部 scissor。场域通道带有独立脏标记；相机矩阵、视口、主题、场域缓冲或父子进度没有变化时，悬停、选卡和普通关系聚焦直接复用上一份源层与辉光纹理。最终全屏材质归一化光学密度色相，以 `1 - exp(-EΣτ)` 有界映射透明度，再将清晰源层和模糊辉光按预乘透明度合成。节点、关系、文字和射线命中继续使用主画布分辨率。

每个标签场在场景建立时把成员圆和场域连接合并成一张裁剪后的低分辨率蒙版，再统一模糊、着色并上传为单个纹理。同一场域的几何重叠不会重复叠加透明度。场域之间使用普通透明度混合，在重叠位置形成混色。筛选只切换已存在纹理的可见性和整体透明度，平移和缩放不重建场域。当前帧最多显示一个父层和一个正在显现的子层。远处图元裁剪、子空间异步加载和构建期搜索索引属于后续计划。

缩放过程中更新世界变换和父子层透明度。子场景复用已经生成的布局、关系、文字与场域图元。WebGL 内部视口使用地图宿主元素的实际 CSS 宽高，命中坐标也从该边界换算；设备像素比只改变后备缓冲区分辨率。布局计算达到明显耗时时移入 Worker。

## 性能预算

当前 PixiJS 渲染器预构建场景目录中的图元。逻辑数据可以继续增长，常驻图元应控制在 3,000 个以内。三维公共数据包含 320 个节点、973 条关系、8 个领域场、110 个标签场和 10 个公共透镜；其中 243 个节点具有多领域归属，327 条关系跨越两端的主领域。七个三维子域增加 74 个常驻节点、139 条常驻关系和 40 个常驻场域。公共与子域的 1,112 条关系合并为一个关系绘制批次，158 个场域的全部球瓣合并为一个场域绘制批次。语义布局的每个谱分量执行 72 轮迭代，三维应力松弛默认执行 32 轮，最终装箱最多执行 120 轮，并重用确定性结果缓存。桌面设备的连续平移、缩放和透镜过渡目标为接近 60 FPS。点击反馈目标为 100 毫秒以内。暖缓存子空间展开目标为 100 毫秒以内。

节点发光的基准性能场景为 1920×1080 CSS 像素、设备像素比不高于 1.6、320 个公共节点全部可见。连续交互的 p95 帧时间目标低于 16.7 毫秒，节点光晕离屏与合成 GPU 时间目标低于 3 毫秒；相机与节点都稳定时，实例属性上传次数和节点光晕离屏重绘次数都应为零。视觉验收覆盖深色/浅色主题、颜色场域开/关、八个单学科透镜及远中近三档距离；峰值裁剪像素比例低于 1%，八领域光晕归一化线性亮度变异系数不超过 1%，亮核直径保持外晕基准尺寸的 `50%`。

性能数据需要在指定测试设备和浏览器中记录。官方库基准只能作为参考，不能替代项目场景测试。

## 故障处理

布局数据损坏时，场景回退到上一个 `layoutVersion`。子空间加载失败时，父场景保持可操作，并显示重试入口。过渡动画被取消时，导航状态回到最近的稳定场景。浏览器失去指针捕获时，拖拽状态立即结束。

三维领域强度由 `src/knowledge/space3d/domainFilter.ts` 统一定义档位与匹配规则，`ProjectionOptions.domainFilterStrength` 传给临时投影，默认 `inclusive`。`exclusive` 按完整 `domains` 的唯一归属筛选；`related` 从本领域全部成员扩展任意关系类型的双向一跳邻居，扩展过程中不把新邻居继续当作种子。结果作为明确节点集合进入既有可见性投影；空集合保留为空，不解释成全部节点。React 保存当前强度，搜索、详情关系和渲染命中沿用投影结果。

## 验收标准

领域强度验证覆盖八个领域的三档范围、跨领域非主归属、双向一跳及排除二跳、空结果、隐藏端点连线和公共坐标不变。滑块支持键盘与指针输入，调整时菜单保持展开；全部领域禁用滑块且保留已选档位。

地图拖拽和缩放不会按动画帧触发整页重复渲染。缩放百分比随连续相机逐帧变化。父子图层在作用域切换时保持相同实例。子域中的平移不会改变当前作用域。缩放临界点不会产生持续闪烁。折叠子空间无法响应指针事件。PixiJS 画布与地图宿主元素使用相同的 CSS 视口，10% 至 100% 缩放下的命中位置与图元位置一致。标签筛选节点和其他不可交互节点不会被 PixiJS
