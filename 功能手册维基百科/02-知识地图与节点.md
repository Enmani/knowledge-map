# 知识地图与节点

## 功能概述

知识地图以节点表示数学知识点，以有向连线表示前置关系。数学全景当前包含 47 个主节点。每个节点归属一个领域和一个学习层级，可以带多个场域标签和多个具体标签。

三维公共知识空间收录 320 个主节点，覆盖数学、物理、化学、生物、神经科学、认知科学、计算机科学、地球与环境科学。目录规模由父节点资格和真实知识边界决定：当前各领域包含 19 至 49 个主节点，不要求等量。三维节点可以同时归属多个领域，并指定一个主领域作为卡片颜色和默认归类。当前数据包含 243 个多领域节点、973 条公共关系和 327 条跨主领域关系。

公共主节点需要有稳定中心问题、清楚边界和内部关系，并能够继续容纳约 5 至 13 个有意义子主题。单一实验范式、局部机制、工具或无法与现有节点区分的术语进入父节点内部，不为凑齐领域数量提升到公共层。认知科学和神经科学按这条规则分别保留 19 与 20 个父节点；稳定 ID `neuroscience` 从生物学迁移到神经科学，生物学保留 45 个节点且不补位。完整分类依据见 `docs/research/science-taxonomy-frameworks.md`。

复合名称只有在各部分共享同一个中心问题时才保留。当前加速器物理与粒子辐射探测、溶液化学与酸碱化学、古生物学与古生态学、地磁学与空间天气已经分别拆开；火山学从岩石学和板块构造中独立出来。旧复合 ID 分别由加速器物理、酸碱化学、古生物学和地磁学与古地磁学继承，新增的另一半使用独立 ID。狭义相对论不再包含引力，构造地质与岩石变形不再拥有板块构造，化学反应与守恒不再拥有系统的氧化还原内容。

三维“数与运算”子域包含自然数、零与位值制，加法与减法，乘法与除法，整除、因数、倍数与质数，整数与数轴，分数与有理数，运算律、逆运算与混合运算，小数与表示转换，比、率、比例与百分数，幂、根与科学记数法，实数与数系扩张，复数与复平面，估算、近似与检验 13 个内部节点，以及 15 条严格前置和 6 条建议前置。渲染身份使用 `arithmetic:` 前缀，内容边界与来源记录在 `docs/research/arithmetic-subdomain-framework.md`。

三维微积分子域包含极限、导数、积分、微积分基本定理、级数和多元微积分 6 个内部节点，以及 7 条严格前置关系。内部节点复用二维微积分场景的文字、层级、标签和关系。三维渲染身份使用 `calculus:` 前缀，避免多元微积分等概念与公共节点 ID 冲突。

线性代数父节点同时拥有二维与三维子域。子域按“直观基础—方程计算—空间结构—几何与谱—进阶工具”五个学习阶段组织 18 个投影节点：先学习向量与坐标、线性组合与张成、矩阵基础与运算，再进入线性方程组、线性映射、向量空间、四个基本子空间、行列式、正交投影、最小二乘与 QR、特征值，以及矩阵分解、SVD、伪逆、正规/酉矩阵、Jordan 形，最后用矩阵性质图谱综合复盘。二维与三维复用相同的 `linear-algebra:` 投影 ID、文字和严格前置；三维共有 31 条严格前置、2 条建议前置、2 条共享模型和 3 条应用关系。

公共主图另设规范概念 `vectors-coordinates`，同时归属数学、物理和计算机科学。子域入口 `linear-algebra:vectors-coordinates` 只是该概念在线性代数路线中的情境投影，内容查询与学习进度都会解析回同一个规范身份，因此不会生成两张相互竞争的“向量”卡片。公共向量以“位移与力的分解”和“坐标与空间变换”两条应用关系分别连接经典力学与计算机图形学，并以“特征向量表示”共享模型关系连接机器学习；这些跨学科联系不会成为严格前置。证明方法只作为线性代数父节点的建议前置，不阻断初学者进入；需要证明的抽象内容在后续空间结构阶段逐步引入。

数学主节点与二维数学全景共用同一份 47 节点目录和前置关系。物理以 APS PhySH 与本科课程为主框架，化学以 ACS 五大基础分科和 IUPAC 专业边界为主框架，生物以大学入门课程、NCES 专业分类和 NSF 研究尺度为主框架。计算机科学覆盖理论、软件、系统、数据、网络、安全与人工智能主干；地球与环境科学覆盖地球系统、固体地球、地球物理与地球化学、大气、海洋、水文、气候、环境与可持续方向。分类依据和内容边界记录在 `docs/research/science-taxonomy-frameworks.md`。

当前主图包含范畴论、理论计算机科学、动力系统、博弈论、代数几何、测度论与积分、傅里叶与调和分析和变分法。数学全景公开 16 个可钻取子空间。线性代数、实分析、复分析、泛函分析、测度论与积分、傅里叶与调和分析、变分法、微分方程、数值分析、点集拓扑和动力系统具有多节点推进式子地图。初等函数、多元微积分、离散结构和随机过程分别关联三角学、向量微积分、序理论和金融数学。微积分子空间中的多元微积分投影也可以继续进入向量微积分。

分析学专题子地图合计包含 58 个节点投影。复动力系统同时出现在复分析和动力系统子地图，两个投影共享概念内容与进度。向量微积分也具有两个共享进度的子空间投影。

每个场景拥有固定大小的世界坐标区域。数学全景的最终位置由领域、领域内前置顺序和节点间距计算。子场景使用节点数据中的 `y` 保存纵向分支锚点。数据坐标不等同于浏览器中的最终像素位置。

## 浏览和选择节点

节点卡片显示序号、中文名、英文名、前两个场域标签和学习状态。序号来自节点在 `mathNodes` 数组中的顺序，从 01 开始生成。调整数组顺序会改变序号，也可能改变“下一站”在同级同坐标情况下的稳定顺序。二维地图继续使用统一的学习状态圆点。

三维公共空间不再在地图内展开“线性代数”完整卡片，因此中文气泡悬停和光点悬停都不播放卡片内正交图标。旧完整卡片纹理、旧 LOD 接线和 4 秒循环原型继续保留为回退代码，但当前气泡主循环不调用。节点完整内容统一由右侧信息栏承载；打开“线性代数”详情时，右侧信息栏复用同一正交 SVG，以 2 秒单次周期播放一次，关闭详情后再次打开才重新播放。

具有已发布或已审核前沿内容的二维节点额外显示独立的前沿计数徽标。该徽标不替代学习状态指示，不参与解锁、迷雾或前置路径。打开前沿雷达时，当前筛选结果关联的节点复用普通关系聚焦中的关联卡高亮，其余当前场景节点使用共享的低透明度上下文；关闭雷达后恢复原选中节点及其关联路径的聚焦样式。

点击节点后，系统执行三项操作：记录选中节点、保持当前相机矩阵、关闭并清空搜索。节点是否锁定不影响查看。锁定状态只限制“标记为已掌握”。

选中节点的详情面板提供以下信息：

- 所属领域和学习层级；
- 中文名、英文名、简介和学习理由；
- 全部场域标签和具体标签；
- 直接前置知识及其掌握状态；
- 将该节点列为直接前置的知识点；
- 建议投入时长。

详情中的关系项可以继续点击。选择新节点后，面板内容和前置路径会同步更新，视野位置保持不变。二维与三维详情共用右侧工作台外框，面板顶部不显示领域色装饰标尺。

三维模式中的节点选择使用独立状态。节点可以从画布或顶部搜索打开。公共作用域详情显示主领域、层级、中文名、英文名、简介、当前公共透镜、严格前置深度、基础—专业化半径、全部领域归属、主题标签和相邻公共关系。右侧详情使用独立滚动正文：顶部主视觉、标题、英文名、标签和简介随正文滚动离场，滚动 176 CSS 像素后由 46 CSS 像素高的紧凑顶栏完全接管图标与标题；关闭按钮固定在顶栏最右并纵向居中。38 CSS 像素高的页脚常驻底部，以细横线分隔并显示主领域与学习层级，正文在横线上方最后 5 CSS 像素内渐隐。三维正文不显示“内容状态”区段。任一三维子域的详情显示当前子域、内部节点简介、标签和子域前置关系。选择一个三维节点后，主节点继续显示普通中文气泡，星点核心放大到两倍，完整内容只在右侧信息栏出现；地图内不生成完整卡片。投影落在屏幕内的全部直接前置和直接后继进入关系聚焦与临时气泡层，不经过普通背面、遮挡、碰撞和密度筛选，无关节点名称全部隐藏。关联气泡重叠时，离镜头近者覆盖远者。普通气泡快照本身不因这层临时显示而改写；取消选择后临时层撤销，主节点因最后互动记录继续保留普通气泡，其余关联节点恢复自动选择。悬停不参与气泡排序或屏幕碰撞占位，因此不会连带改变周围节点。显示层同时用于重叠节点的点击、双击和滚轮命中优先级，但不改变任何规范或运行时节点坐标。前沿雷达开启时用雷达命中集合临时替代单节点关系聚焦：命中节点使用关系与透明度强调，其他节点降为共享上下文透明度；选中状态、相机和普通气泡快照不改变。选择关系项会打开另一端节点，三维相机保持不变并把新详情滚动位置重置到顶部。点击画布空白关闭详情，拖动画布不会触发关闭。

## 三维公共节点数据

`KnowledgeSpaceNode` 保存三维公共空间中的规范记录。

| 字段 | 类型 | 用途 | 约束 |
| --- | --- | --- | --- |
| `id` | `string` | 公共身份、关系引用和渲染键 | 全局唯一且长期稳定 |
| `title` | `string` | 中文名称 | 不得为空 |
| `englishTitle` | `string` | 英文名称 | 不得为空并参与搜索 |
| `summary` | `string` | 公共简介 | 参与搜索和详情 |
| `primaryDomain` | `ScienceDomainId` | 主领域 | 必须同时存在于 `domains` |
| `domains` | `ScienceDomainId[]` | 多领域归属 | 至少包含一个有效领域 |
| `tags` | `string[]` | 主题和共享方法 | 参与搜索和卡片展示 |
| `level` | `0 \| 1 \| 2 \| 3 \| 4` | 公共学习层级 | 映射为启程、基础、核心、进阶、前沿 |
| `importance` | `number` | 稳定语义重要性与透镜显著性的作者输入 | 可选；省略时按 `1`，提供时必须为有限非负数 |

三维远景节点使用“双通道发光”。稳定核心亮度先在规范公共图或当前子域的完整节点集合内，对 `importance` 做并列值中位秩，再与严格前置图产生的 `foundationScore` 按 `65% / 35%` 合成，并用第 5、95 百分位做稳健归一化；实时筛选、节点顺序和公共透镜都不重新定义这份核心排序。宽光晕在稳定显著性的基础上，再按 `60%` 稳定显著性与 `40%` 当前透镜强调度合成，因此切换视角时先改变“与当前问题的相关性”，不会把知识本身的重要性改写掉。公共图与每个子域分别计算，子域的基础性来自其自身严格前置图。视觉上采用白热亮核、领域色内晕和柔和外晕三段结构；亮核平面尺寸固定为外晕基准尺寸的 `50%`，避免远景光点膨胀成光球。

三维关系使用 `KnowledgeSpaceEdge`。关系类型包括前置、应用、类比、历史和共享模型。每条关系具有 0 至 1 的强度，并可以提供面向用户的连接说明。语义布局读取关系计算节点亲和度和图距离，公共透镜继续读取相同关系计算显著性。渲染方向始终从 `source` 指向 `target`；节点选中时，主节点与直接关联节点之间的线段沿该方向播放 1.8 秒循环脉冲，因此选中目标节点时前置脉冲流入，选中来源节点时后继脉冲流出。

`ThreeKnowledgeSubspace` 保存三维包含关系、父节点 ID、内部节点局部坐标、内部关系、屏幕投影显隐区间，以及彼此独立的作用域进入和退出倍率。`createThreeKnowledgeSubspace.ts` 是公共定义工厂，统一生成命名空间身份、类型化关系、共享局部场和默认进入退出参数。来源节点可声明严格前置、建议前置、共享模型、类比和应用；工厂拒绝重复节点、域外关系、自指、重复关系与严格前置环，但允许非严格语义关系形成环。`subspaceRegistry.ts` 集中登记全部子域并校验子域 ID、公共父节点和内部节点身份；`App.tsx` 不再保存手写子域数组。所有已注册子域默认都在 1245% 进入、800% 退出。子域成为当前作用域后，渲染器按该子域全部卡片的当前世界坐标计算算术中心，并把它作为旋转手势的范围中心。双击声明为 `ownerNodeId` 的父节点会复用同一显隐区间，并把目标倍率推进到显隐终点计算值与作用域进入倍率中的较大值。

## 三维关系驱动语义布局

三维公共节点不保存人工坐标，也不为八个领域预设固定方向。布局器先把关系、标签和领域归属统一为任意节点 $i,j$ 之间的亲和度：

\[
A_{ij}=1-(1-0.12J_{ij})(1-0.035C_{ij})(1-0.025I_{ij})\prod_{e:i\leftrightarrow j}(1-q_e s_e)
\]

其中 $J_{ij}$ 是标签 Jaccard 相似度，$C_{ij}$ 是多领域归属的余弦相似度，$I_{ij}$ 表示主领域相同，$s_e$ 是关系强度。严格前置、共享模型、应用、建议前置、类比和历史关系的 $q_e$ 依次为 1、0.85、0.65、0.55、0.35 和 0.2。领域项故意保持较弱，只帮助领域自然显现，不给任何学科分配固定领地。

方向来自归一化亲和矩阵的三个非平凡谱分量。实现对每个分量执行 72 轮确定性幂迭代，并剔除平凡向量和已经取得的分量；三个分量组成节点的初始三维单位方向。相同节点 ID、数据和参数始终得到相同结果。

径向部分仍先在严格前置关系构成的有向图上计算最长路径深度：

\[
d_i=\begin{cases}
0,& i\text{ 没有严格前置}\\
1+\max_{j\rightarrow i}d_j,& \text{其他情况}
\end{cases}
\]

`level` 用于校准关系尚不完整的节点。前置图中存在环时，环内节点确定性回退到 `level`，数据校验同时报告该问题。布局器还计算每个节点对严格后继网络的折扣覆盖：

\[
b_i=\frac{\log\!\left(1+\sum_{j\in Desc(i)}e^{-0.55(\ell_{ij}-1)}\right)}{\max_k\log\!\left(1+\sum_{j\in Desc(k)}e^{-0.55(\ell_{kj}-1)}\right)}
\]

归一化深度与基础性分数组合为基础—专业化进度 $p_i=0.72(d_i/d_{max})+0.28(1-b_i)+\Delta p_i$。确定性扰动只用于减少同层重合，随后每条严格前置都强制满足后继进度至少比前置大 0.018。语义半径为：

\[
r_i=r_{core}+(R-r_{core})p_i^\gamma
\]

当前默认参数为核心半径 3.2、外层半径 13.4、指数 0.82、径向扰动上限 0.16。共同基础总体靠近中心，专业内容总体靠近外层；高级数学不会仅因属于数学而进入中心，具有广泛后继覆盖的非数学基础也可以进入内层。投影公共 API 中的 `sphere` 参数和 `KnowledgeSphereParameters` 字段暂时兼容保留，但不再表示固定领域球瓣算法。

亲和度还会转换为图边成本 $c_{ij}=0.3-\log(A_{ij}+\varepsilon)$，再通过全图最短路径和第 90 百分位尺度得到归一化图距离 $g_{ij}$。目标应力距离为：

\[
\delta_{ij}=0.42+2.9\min(g_{ij},1.35)^{0.72}
\]

松弛过程比较节点在半径为 $R/0.94$ 的 Poincaré 球中的距离与 $\delta_{ij}$：

\[
d_H(x_i,x_j)=\operatorname{arcosh}\left(1+\frac{2\|x_i-x_j\|^2}{(1-\|x_i\|^2)(1-\|x_j\|^2)}\right)
\]

公式中的坐标先按 Poincaré 边界归一化。图距离应力、谱方向锚定、径向锚定和节点锚点防碰撞共同执行 32 轮三维松弛；切向力改变方向，径向力只容许目标半径附近的小幅过渡。最终最多 120 轮球面装箱消除残余锚点重叠并恢复精确基础—专业化半径。普通中文气泡使用真实 CSS 像素矩形执行屏幕避让；选中只改变主节点星点核心的视觉比例和临时名称集合，不驱动其他节点坐标变化。场域中心、场域半径和关系渲染长度继续使用三维欧氏距离。

当前界面的领域筛选只提供临时筛选：隐藏不匹配节点，公共坐标保持不变。领域菜单使用三档强度滑块：最强“仅本领域”只保留 `domains` 唯一归属为该领域的节点；默认“包含跨域”保留 `domains` 包含该领域的所有节点；最宽“直接关联”在默认集合上增加任意关系类型、任意强度的双向一跳邻居，不扩展间接关系。滑块从左到右越来越严格，全部领域时禁用；没有匹配节点时显示空结果。隐藏节点的透明度为零，同时退出关系、场域和射线命中。投影层仍保留专业聚焦解析能力作为兼容接口和算法测试入口，但三维控制栏不再提供该选项，也不会从应用状态请求专业聚焦投影。

## 节点数据结构

节点类型由 `MathNode` 定义。

| 字段 | 类型 | 用途 | 约束 |
| --- | --- | --- | --- |
| `id` | `string` | 存储、关系引用和渲染键 | 同一场景内唯一且长期稳定；同一概念的别名投影复用 ID |
| `title` | `string` | 中文名称 | 应能单独识别知识点 |
| `english` | `string` | 英文名称 | 同时参与搜索 |
| `domain` | `DomainId` | 所属数学领域 | 只能取已定义领域 ID |
| `level` | `0 \| 1 \| 2 \| 3 \| 4` | 学习层级 | 分别映射为启程、基础、核心、进阶、前沿 |
| `x`、`y` | `number` | 稳定排序和子图纵向锚点 | 应处于场景世界坐标附近 |
| `summary` | `string` | 知识点简介 | 参与搜索和详情展示 |
| `why` | `string` | 学习理由 | 只在详情展示 |
| `prerequisites` | `string[]` | 直接前置节点 ID | 引用必须存在，关系必须无环 |
| `fieldTags` | `FieldTagId[]` | 场域标签 | 影响布局、场域和筛选 |
| `tags` | `string[]` | 具体主题标签 | 用于详情和搜索 |
| `hours` | `number` | 建议投入时长 | 以小时显示，应为非负数 |

领域和标签的职责见[标签与场域](./03-标签与场域.md)。

## 搜索规则

搜索会去除输入首尾空白，并将输入和候选文本转为小写后执行包含匹配。以下字段参与匹配：`title`、`english`、`summary`、`fieldTags`、`tags`。`why`、领域名称、学习层级和建议时长当前不参与搜索。

输入为空时不显示结果列表。存在输入时最多返回数据顺序中的前 7 个匹配节点。搜索不依据学习状态或当前领域筛选缩小结果；用户可以从搜索结果进入一个已被筛选弱化的节点。

## 自动布局规则

每个场景解析一种布局策略。数学全景使用 `radial-clusters`。基础领域的五个节点形成中央簇。代数学、离散数学、概率与统计、几何与拓扑、分析学、应用数学形成六个紧邻中央簇的花瓣簇。每个花瓣簇从该领域的第一个知识点开始计算局部层级，后续知识向簇的外侧推进。相邻局部层级的半径差为 145 个世界单位，节点在切线方向交错分布。

带有 `parentSceneId` 的子场景默认使用 `progression`。系统根据前置关系计算依赖深度，同一深度进入同一纵向列，后续知识放在右侧列。节点数据中的 `y` 作为纵向分支锚点。只有一个依赖列时，该列在子场景中水平居中。每条前置连线的起点右边缘与终点左边缘之间保留节点安全间距。场景可以显式声明其他策略。

布局投影完成后，系统按当前场景的节点绝对尺寸检查轴对齐矩形碰撞。数学全景节点之间保留 24 个世界单位，现有子图节点之间保留 220 个世界单位。最终位置被限制在场景边界内。布局参数改变时，原有空间位置可能整体变化。

数学全景中的领域内连线直接连接卡片边缘。基础领域到外围领域的连线向外连接。跨外围领域的连线使用外侧控制点绕开中心核。推进式子图使用从左向右的平滑曲线。

画布最小缩放比例为 10%。滚轮、缩放按钮和快捷键均使用该下限。

## 开发约束

新增节点时，应先确定稳定的 `id`，再补全内容、关系、领域和标签。关系解析、搜索、详情、连线和本地进度均依赖同一个 ID。发布后修改 ID 会使已有进度失去对应节点，也会导致旧关系引用失效。

场景目录与知识图谱适配器根据 `mathNodes` 和子场景数据建立概念索引。主地图和每个子场景都要求场景内 ID 唯一。知识图谱适配允许同一概念在不同场景复用 ID，并将后续投影记录为别名。场景创建与知识图谱适配会检查重复 ID、缺失引用、空间包含环和严格前置环。无效数据会停止加载。

自动布局在模块加载时一次性生成。当前界面没有拖动单个节点并保存位置的功能。用户从节点区域开始拖动时，移动的是整个画布。

领域定义中的 `region` 是现有数据字段。当前自动布局函数不读取该字段。径向布局使用领域 ID 分配花瓣方向，使用领域内前置顺序确定局部半径。推进式布局使用依赖深度确定横向列。

## 边界情况

- `prerequisites` 为空的节点是路径起点，可在未掌握时直接学习。
- 节点可以同时被多个后继引用，详情中的“掌握后解锁”会列出全部直接后继。
- 卡片最多展示两个场域标签，详情会展示完整标签集合。
- 节点没有直接后继时，详情显示“当前地图中的前沿终点”。这只表示当前数据中没有后继。
- 节点坐标超出边界时，布局会把最终位置限制回画布范围。
- 前置 ID 缺失会在布局或渲染关系时访问不到节点。当前版本没有面向用户的错误恢复界面。
- 循环前置会使递归路径计算无法正常结束。数据发布前必须检查有向无环性。
- 推进式布局的场景宽度不足时，场景创建会失败。世界宽度需要容纳全部依赖列、节点宽度和列间安全间距。

## 验收标准

1. 每个概念具有稳定 ID，同一场景没有重复 ID，领域与场域标签均引用有效定义。
2. 每条前置关系都能解析到现有节点，图中不存在自引用或循环依赖。
3. 任意两个最终节点矩形之间至少保留设定的碰撞间距，节点没有越出世界边界。
4. 卡片序号与 `mathNodes` 数组顺序一致，详情中的文字和标签与数据源一致。
5. 锁定节点可以打开详情，掌握按钮保持禁用。
6. 搜索可命中五类声明字段，不会因领域筛选或学习状态漏掉匹配节点。
7. 点击详情中的前置或后继项后，选中节点和高亮路径同步更新，相机缩放和平移保持不变。
8. 数学全景中的六个基础节点位于中央簇，其他节点位于六个紧凑领域簇，领域内关系向簇外推进。
9. 带有父场景的新增子域在没有显式策略时使用推进式布局。
10. 47 个主节点与 87 个子节点投影均可由稳定 ID 查询，新增内容不引入缺失引用、空间包含环或严格前置环。
11. 三维公共数据包含八个领域、320 个节点、973 条关系、十个透镜、八个领域场和 110 个自动标签场；各主领域按真实边界包含 19 至 49 个节点，不强制等量。243 个节点具有多领域归属，327 条关系跨越两端的主领域。五个新增拆分节点具有独立摘要、至少三个标签和有效关系；旧复合 ID 指向语义最接近的继承节点，全部 ID 和引用通过结构校验。
12. 同一个三维节点在十个透镜中保持相同 ID，透镜变化只更新投影位置和视觉权重。
13. 三维搜索可以按中文名、英文名、简介、标签和领域名称找到节点。
14. 三维公共全景在 X、Y、Z 三个方向均具有显著跨度；基础—专业化半径同时反映严格前置深度和折扣后继覆盖，每条严格前置的后继都不位于其前置的更内层。
15. 三维控制栏只提供临时领域筛选；滑块支持仅本领域、包含跨域（默认）与直接关联三档，按完整领域归属和双向一跳关系逐步扩大集合，不扩展二跳；全部领域禁用滑块，无匹配显示空结果。所有强度均不改变任何节点坐标，界面不显示专业聚焦选项。
16. 筛选隐藏节点的透明度为零，不能被搜索、关系列表或射线命中。
17. 七个已注册三维子域共包含 74 个命名空间节点和 139 条有效关系；其中数与运算包含 13 个节点、15 条严格前置和 6 条建议前置，微积分保留 6 个节点与 7 条严格前置，线性代数包含 18 个节点、31 条严格前置、2 条建议前置、2 条共享模型和 3 条应用关系，四个认知与神经科学试点子域继续实际使用全部五种关系语义。公共 `vectors-coordinates` 与线性代数子域投影解析到同一个规范概念；从任一入口打开的知识卡片一致，推进或完成任一投影后只写入一份共享进度。公共向量到经典力学、计算机图形学和机器学习的三条直接关系分别保持“应用、应用、共享模型”语义，不得改成严格前置。
18. 三维作用域切换后，搜索、详情和关系列表只使用当前作用域中的节点与关系。
19. 选中三维节点后，主节点保持普通中文气泡并将星点核心放大到两倍，完整内容只显示在右侧信息栏；投影落在屏幕内的全部直接前置和直接后继显示中文气泡，不经过普通背面、遮挡、碰撞或密度淘汰，所有无关节点名称暂时隐藏。关联气泡重叠时按相机空间深度叠放，近处在上；关联节点不写入普通气泡快照。取消选中后关联节点恢复自动选择，最后互动的主节点继续保留。
20. 具有公开前沿内容的二维节点显示独立计数徽标；雷达开启时二维和三维只高亮当前筛选命中的节点，其余当前可见节点降低透明度，并且不改变学习状态、命中范围、前置路径或三维坐标。
21. 三维公共作用域在全部节点可见时围绕公共空间中心旋转；筛选隐藏任何节点后，只对筛选保留节点当前世界坐标取算术平均，作为旋转中心，隐藏节点不参与计算。单个结果围绕该节点旋转，空结果不执行旋转。每次旋转开始时计算并锁定中心，同一次拖拽不受悬停、选择或淡出动画影响。进入任意子域后使用该子域全部卡片的当前世界坐标算术中心，退出后按当前公共筛选结果重新确定中心。
22. 选中节点和悬停节点通过显示层覆盖普通气泡；选中星点核心固定为普通尺寸的两倍，显示置顶和命中优先级不会改写节点坐标，悬停也不参与普通气泡排序。
23. 双击具有子域声明的父节点会通过短暂平滑缩放进入对应子域；没有子域的节点保持普通双击行为且不会错误启动其他子域。
24. 三维子域的进入与退出倍率分别声明；当前七个已注册子域都在 1245% 进入后，实际镜头降到 800% 才退出，区间内子卡片保持可见和可交互。
25. 三维普通中文气泡使用 13 CSS 像素字号，固定为 26 CSS 像素高，左右各保留 10 像素文字内边距；气泡使用旧完整卡片圆角比例的小圆角矩形，底边位于星点中心上方 16 CSS 像素。选中后不改变气泡尺寸，只把独立星点核心放大到两倍。布局使用上移后的实际气泡矩形、7 像素间距和视口面积 11% 的文字面积预算。候选按“两张镜头近邻、一张严格前置关系中心节点”交织选择，输入顺序不改变结果。
26. 三维“线性代数”完整卡片与正方形正交网格动画保留为回退实现，当前选择、取消选择、中文气泡和光点悬停均不会在地图内创建或播放该卡片。
27. 前置关系覆盖中心度遍历每个节点沿严格前置边可达的下游知识，按关系步数指数衰减后求和、取对数并相对全图最大值归一化；不维护中心知识 ID 名单。线性代数由关系图自然得到约 0.982 的中心度并进入满额加成区间。
28. 镜头静止时普通气泡 ID 集合完全冻结；单击、取消选中、悬停和关系聚焦不触发普通排名。最后单击节点加入快照并在独立镜头范围内保留。相机或节点运动期间每一帧都按当前屏幕位置重新选择；纯靠近缩放只增不减，平移、旋转、行走、缩远、透镜或视口变化允许近处候选实时替换存量。
29. 三维远景节点的核心亮度在节点顺序、临时筛选和十个公共透镜之间保持同一稳定排序；`importance` 的非有限值或负值无法通过数据校验；每个子域只用自身严格前置关系产生非退化的基础性分数。
30. 对全部节点的 `importance` 施加确定性 ±5% 小扰动后，发光显著性 Top-20 与基线至少重合 90%；切换公共透镜时，稳定核心排序的 Spearman 相关系数至少为 0.95。
31. 深色主题的普通三维关系线必须比浅色基线更亮；主选择节点与直接关联节点之间的线透明度最高达到 0.92，并以固定 1.8 秒周期从 `source` 向 `target` 移动脉冲。没有主节点的前沿雷达聚焦不播放方向脉冲，降低动态效果时只保留静态高亮。
32. 全局倍率从 100% 降到 70% 的过程中，普通节点名称平滑淡出，八个大域名称平滑淡入，最大透明度统一限制为 50%。每个大域名称取该领域全部公共成员节点当前坐标的算术中心，只使用领域主题色填充，不绘制黑色或白色描边；深色主题使用明显压暗的领域色，以便在高亮星云与连线之上辨认。选中主节点及其全部屏幕内直接关联气泡不受远景淡出影响；选中期间无关节点名称全部隐藏。
