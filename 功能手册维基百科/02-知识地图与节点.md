# 知识地图与节点

## 功能概述

知识地图以节点表示数学知识点，以有向连线表示前置关系。数学全景当前包含 46 个主节点。每个节点归属一个领域和一个学习层级，可以带多个场域标签和多个具体标签。

三维公共知识空间收录 184 个主节点，数学、物理、化学和生物各 46 个。三维节点可以同时归属多个领域，并指定一个主领域作为卡片颜色和默认归类。当前数据包含 121 个多领域节点、487 条公共关系和 111 条跨主领域关系。

三维微积分子域包含极限、导数、积分、微积分基本定理、级数和多元微积分 6 个内部节点，以及 7 条严格前置关系。内部节点复用二维微积分场景的文字、层级、标签和关系。三维渲染身份使用 `calculus:` 前缀，避免多元微积分等概念与公共节点 ID 冲突。

数学主节点与二维数学全景共用同一份 46 节点目录和前置关系。物理以 APS PhySH 与本科课程为主框架，化学以 ACS 五大基础分科和 IUPAC 专业边界为主框架，生物以大学入门课程、NCES 专业分类和 NSF 研究尺度为主框架。分类依据和内容边界记录在 `docs/research/science-taxonomy-frameworks.md`。

当前主图包含范畴论、理论计算机科学、动力系统、博弈论、代数几何、测度论与积分、傅里叶与调和分析和变分法。数学全景公开 15 个可钻取子空间。实分析、复分析、泛函分析、测度论与积分、傅里叶与调和分析、变分法、微分方程、数值分析、点集拓扑和动力系统具有多节点推进式子地图。初等函数、多元微积分、离散结构和随机过程分别关联三角学、向量微积分、序理论和金融数学。微积分子空间中的多元微积分投影也可以继续进入向量微积分。

分析学专题子地图合计包含 58 个节点投影。复动力系统同时出现在复分析和动力系统子地图，两个投影共享概念内容与进度。向量微积分也具有两个共享进度的子空间投影。

每个场景拥有固定大小的世界坐标区域。数学全景的最终位置由领域、领域内前置顺序和节点间距计算。子场景使用节点数据中的 `y` 保存纵向分支锚点。数据坐标不等同于浏览器中的最终像素位置。

## 浏览和选择节点

节点卡片显示序号、中文名、英文名、前两个场域标签和学习状态。序号来自节点在 `mathNodes` 数组中的顺序，从 01 开始生成。调整数组顺序会改变序号，也可能改变“下一站”在同级同坐标情况下的稳定顺序。

点击节点后，系统执行三项操作：记录选中节点、保持当前相机矩阵、关闭并清空搜索。节点是否锁定不影响查看。锁定状态只限制“标记为已掌握”。

选中节点的详情面板提供以下信息：

- 所属领域和学习层级；
- 中文名、英文名、简介和学习理由；
- 全部场域标签和具体标签；
- 直接前置知识及其掌握状态；
- 将该节点列为直接前置的知识点；
- 建议投入时长。

详情中的关系项可以继续点击。选择新节点后，面板内容和前置路径会同步更新，视野位置保持不变。

三维模式中的节点选择使用独立状态。节点可以从画布或顶部搜索打开。公共作用域详情显示主领域、层级、中文名、英文名、简介、当前公共透镜、前置深度、球心距离、全部领域归属、主题标签和相邻公共关系。微积分作用域详情显示当前子域、内部节点简介、标签和子域前置关系。选择一个三维节点后，所有可见的直接前置和直接后继进入关系聚焦。关联节点至少显示高亮标题卡，屏幕空间充足时显示完整卡。相邻关联节点投影重叠时，渲染器优先将完整卡降为高亮标题卡，卡片位置继续读取节点的原始空间锚点。选择关系项会打开另一端节点，三维相机保持不变。点击画布空白关闭详情，拖动画布不会触发关闭。

## 三维公共节点数据

`KnowledgeSpaceNode` 保存三维公共空间中的规范记录。

| 字段 | 类型 | 用途 | 约束 |
| --- | --- | --- | --- |
| `id` | `string` | 公共身份、关系引用和渲染键 | 全局唯一且长期稳定 |
| `title` | `string` | 中文名称 | 不得为空 |
| `englishTitle` | `string` | 英文名称 | 不得为空并参与搜索 |
| `summary` | `string` | 公共简介 | 参与搜索和详情 |
| `primaryDomain` | `ScienceDomainId` | 主领域 | 必须同时存在于 `domains` |
| `domains` | `ScienceDomainId[]` | 多领域归属 | 至少包含一个有效领域 |
| `tags` | `string[]` | 主题和共享方法 | 参与搜索和卡片展示 |
| `level` | `0 \| 1 \| 2 \| 3 \| 4` | 公共学习层级 | 映射为启程、基础、核心、进阶、前沿 |
| `importance` | `number` | 视角中的基础显著性 | 可选 |

三维关系使用 `KnowledgeSpaceEdge`。关系类型包括前置、应用、类比、历史和共享模型。每条关系具有 0 至 1 的强度，并可以提供面向用户的连接说明。公共透镜读取这些关系计算显著性。

`ThreeKnowledgeSubspace` 保存三维包含关系、父节点 ID、内部节点局部坐标、内部关系和屏幕投影显隐区间。`calculusSubspace.ts` 读取 `sceneCatalog.ts` 中已经完成校验的微积分场景，并生成三维渲染适配数据。内部事实继续由二维场景维护。

## 三维同心知识球布局

三维公共节点不保存人工坐标。投影器先在严格前置关系构成的有向图上计算最长路径深度：

\[
d_i=\begin{cases}
0,& i\text{ 没有严格前置}\\
1+\max_{j\rightarrow i}d_j,& \text{其他情况}
\end{cases}
\]

`level` 用于校准关系尚不完整的节点。前置图中存在环时，环内节点确定性回退到 `level`，数据校验同时报告该问题。

深度通过幂函数映射为离球心的语义半径：

\[
r_i=r_{core}+(R-r_{core})\left(\frac{d_i}{d_{max}}\right)^\gamma+\Delta r_i
\]

当前默认参数为核心半径 3.2、外层半径 13.4、指数 0.82、确定性径向扰动上限 0.16。基础知识靠近球心，前沿知识靠近外层。径向扰动只用于减少同层重合，相同数据始终得到相同结果。

数学、物理、化学和生物的方向使用正四面体四个单位顶点。节点的初始方向由主领域权重 1、附属领域权重 0.68 和小幅标签方向共同计算：

\[
u_i=\operatorname{normalize}\left(\sum_d w_{i,d}a_d+0.16\,t_i\right),\qquad p_i=r_i u_i
\]

约束迭代在完整 XYZ 空间中计算关系吸引、共享标签吸引和节点锚点防碰撞。关系与标签作用力投影到节点所在球壳的切平面：

\[
F_{tan}=F-(F\cdot u_i)u_i
\]

径向力把节点约束在目标半径附近，最终球面装箱步骤消除残余锚点重叠并恢复精确语义半径。完整卡片在屏幕空间执行 LOD 避让。场域中心、场域半径和关系长度全部使用三维欧氏距离。

领域筛选具有两种布局语义。临时筛选只隐藏不匹配节点，公共坐标保持不变。专业聚焦保留匹配节点、必要前置闭包和高强度跨领域桥梁，并将稳定散列映射到固定 4096 槽 Fibonacci 球面采样。新增节点不会改变其他节点的初始采样槽。聚焦后的方向保留 20% 至 35% 的公共方向锚定，节点半径保持不变。隐藏节点的透明度为零，同时退出关系、场域和射线命中。

## 节点数据结构

节点类型由 `MathNode` 定义。

| 字段 | 类型 | 用途 | 约束 |
| --- | --- | --- | --- |
| `id` | `string` | 存储、关系引用和渲染键 | 同一场景内唯一且长期稳定；同一概念的别名投影复用 ID |
| `title` | `string` | 中文名称 | 应能单独识别知识点 |
| `english` | `string` | 英文名称 | 同时参与搜索 |
| `domain` | `DomainId` | 所属数学领域 | 只能取已定义领域 ID |
| `level` | `0 \| 1 \| 2 \| 3 \| 4` | 学习层级 | 分别映射为启程、基础、核心、进阶、前沿 |
| `x`、`y` | `number` | 稳定排序和子图纵向锚点 | 应处于场景世界坐标附近 |
| `summary` | `string` | 知识点简介 | 参与搜索和详情展示 |
| `why` | `string` | 学习理由 | 只在详情展示 |
| `prerequisites` | `string[]` | 直接前置节点 ID | 引用必须存在，关系必须无环 |
| `fieldTags` | `FieldTagId[]` | 场域标签 | 影响布局、场域和筛选 |
| `tags` | `string[]` | 具体主题标签 | 用于详情和搜索 |
| `hours` | `number` | 建议投入时长 | 以小时显示，应为非负数 |

领域和标签的职责见[标签与场域](./03-标签与场域.md)。

## 搜索规则

搜索会去除输入首尾空白，并将输入和候选文本转为小写后执行包含匹配。以下字段参与匹配：`title`、`english`、`summary`、`fieldTags`、`tags`。`why`、领域名称、学习层级和建议时长当前不参与搜索。

输入为空时不显示结果列表。存在输入时最多返回数据顺序中的前 7 个匹配节点。搜索不依据学习状态或当前领域筛选缩小结果；用户可以从搜索结果进入一个已被筛选弱化的节点。

## 自动布局规则

每个场景解析一种布局策略。数学全景使用 `radial-clusters`。基础领域的五个节点形成中央簇。代数学、离散数学、概率与统计、几何与拓扑、分析学、应用数学形成六个紧邻中央簇的花瓣簇。每个花瓣簇从该领域的第一个知识点开始计算局部层级，后续知识向簇的外侧推进。相邻局部层级的半径差为 145 个世界单位，节点在切线方向交错分布。

带有 `parentSceneId` 的子场景默认使用 `progression`。系统根据前置关系计算依赖深度，同一深度进入同一纵向列，后续知识放在右侧列。节点数据中的 `y` 作为纵向分支锚点。只有一个依赖列时，该列在子场景中水平居中。每条前置连线的起点右边缘与终点左边缘之间保留节点安全间距。场景可以显式声明其他策略。

布局投影完成后，系统按当前场景的节点绝对尺寸检查轴对齐矩形碰撞。数学全景节点之间保留 24 个世界单位，现有子图节点之间保留 220 个世界单位。最终位置被限制在场景边界内。布局参数改变时，原有空间位置可能整体变化。

数学全景中的领域内连线直接连接卡片边缘。基础领域到外围领域的连线向外连接。跨外围领域的连线使用外侧控制点绕开中心核。推进式子图使用从左向右的平滑曲线。

画布最小缩放比例为 10%。滚轮、缩放按钮和快捷键均使用该下限。

## 开发约束

新增节点时，应先确定稳定的 `id`，再补全内容、关系、领域和标签。关系解析、搜索、详情、连线和本地进度均依赖同一个 ID。发布后修改 ID 会使已有进度失去对应节点，也会导致旧关系引用失效。

场景目录与知识图谱适配器根据 `mathNodes` 和子场景数据建立概念索引。主地图和每个子场景都要求场景内 ID 唯一。知识图谱适配允许同一概念在不同场景复用 ID，并将后续投影记录为别名。场景创建与知识图谱适配会检查重复 ID、缺失引用、空间包含环和严格前置环。无效数据会停止加载。

自动布局在模块加载时一次性生成。当前界面没有拖动单个节点并保存位置的功能。用户从节点区域开始拖动时，移动的是整个画布。

领域定义中的 `region` 是现有数据字段。当前自动布局函数不读取该字段。径向布局使用领域 ID 分配花瓣方向，使用领域内前置顺序确定局部半径。推进式布局使用依赖深度确定横向列。

## 边界情况

- `prerequisites` 为空的节点是路径起点，可在未掌握时直接学习。
- 节点可以同时被多个后继引用，详情中的“掌握后解锁”会列出全部直接后继。
- 卡片最多展示两个场域标签，详情会展示完整标签集合。
- 节点没有直接后继时，详情显示“当前地图中的前沿终点”。这只表示当前数据中没有后继。
- 节点坐标超出边界时，布局会把最终位置限制回画布范围。
- 前置 ID 缺失会在布局或渲染关系时访问不到节点。当前版本没有面向用户的错误恢复界面。
- 循环前置会使递归路径计算无法正常结束。数据发布前必须检查有向无环性。
- 推进式布局的场景宽度不足时，场景创建会失败。世界宽度需要容纳全部依赖列、节点宽度和列间安全间距。

## 验收标准

1. 每个概念具有稳定 ID，同一场景没有重复 ID，领域与场域标签均引用有效定义。
2. 每条前置关系都能解析到现有节点，图中不存在自引用或循环依赖。
3. 任意两个最终节点矩形之间至少保留设定的碰撞间距，节点没有越出世界边界。
4. 卡片序号与 `mathNodes` 数组顺序一致，详情中的文字和标签与数据源一致。
5. 锁定节点可以打开详情，掌握按钮保持禁用。
6. 搜索可命中五类声明字段，不会因领域筛选或学习状态漏掉匹配节点。
7. 点击详情中的前置或后继项后，选中节点和高亮路径同步更新，相机缩放和平移保持不变。
8. 数学全景中的五个基础节点位于中央簇，其他节点位于六个紧凑领域簇，领域内关系向簇外推进。
9. 带有父场景的新增子域在没有显式策略时使用推进式布局。
10. 46 个主节点与 69 个子节点投影均可由稳定 ID 查询，新增内容不引入缺失引用、空间包含环或严格前置环。
11. 三维公共数据包含四个领域、184 个节点、487 条关系和六个透镜，每个主领域恰好包含 46 个节点，所有 ID 和引用通过结构校验。
12. 同一个三维节点在六个透镜中保持相同 ID，透镜变化只更新投影位置和视觉权重。
13. 三维搜索可以按中文名、英文名、简介、标签和领域名称找到节点。
14. 三维公共全景在 X、Y、Z 三个方向均具有显著跨度，节点离球心的平均距离随前置深度递增。
15. 临时筛选不改变任何节点坐标；专业聚焦只改变可见节点的球面方向，不改变知识半径。
16. 筛选隐藏节点的透明度为零，不能被搜索、关系列表或射线命中。
17. 三维微积分子域包含 6 个命名空间节点和 7 条有效前置关系，文字、标签和层级与二维微积分场景一致。
18. 三维作用域切换后，搜索、详情和关系列表只使用当前作用域中的节点与关系。
19. 选中三维节点后，当前作用域内可见的直接前置和直接后继至少保持高亮标题卡；关联卡片不因普通 LOD 或标签碰撞退化为光点。
