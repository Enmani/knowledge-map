# 探索与游戏化

[返回首页](./README.md)

## 当前探索流程

当前原型以一张数学地图作为探索入口。页面初次打开时显示简短引导，关闭后在当前浏览器中记录已读状态。地图默认选中“微积分”，并把视野定位到该节点附近。

用户可以切换到包含八个领域、320 个节点和 973 条关系的三维公共空间，并通过公共全景、八个单领域视角与跨域桥梁共十个透镜探索同一份公共知识。十个透镜和临时领域筛选都从左下角控制栏的上拉菜单进入；临时筛选保持公共坐标，当前界面不提供专业聚焦。三维空间不读取个人掌握进度、迷雾或解锁状态。

用户可以从空白区域或节点区域开始拖动。指针移动不足 5 像素时，节点操作按单击处理并打开详情卡片。详情已经打开时，单击画布空白区域会清除当前选择并收起详情。指针移动达到阈值后，操作改为拖动画布，当前选择保持不变，随后产生的单击会被抑制。滚轮围绕指针位置缩放，缩放按钮围绕视口中心缩放。当前根相机缩放范围为 10% 至 12800%。子空间按固定嵌入比例读取有效缩放。

搜索、领域筛选、场域筛选和小地图用于缩短定位过程。搜索和领域筛选会降低无关内容的视觉权重并停止其画布交互。场域筛选只绘制包含当前标签的节点、当前场域和双端匹配关系。筛选不修改地图数据。单击搜索结果会选择节点、关闭搜索并清空输入。单击小地图会移动主画布。

节点选中后，系统突出其完整前置路径和直接后继。前置路径使用实线和正常权重显示。直接后继代表掌握当前节点后可以继续探索的下一批内容，使用 100% 不透明的黑白卡片、虚线边框和虚线箭头显示，并带有“下一批”锁形标记。节点右侧的状态圆点继续显示当前真实学习状态。其他上下文节点维持 33% 可见度。详情中的前置知识和后继知识可以继续选择。具体操作见[知识卡片与互动组件](./07-知识卡片与互动组件.md)。

## 当前学习反馈

当前学习状态由版本化玩家进度和严格前置关系计算。

| 状态 | 条件 | 可执行操作 |
| --- | --- | --- |
| 已掌握 | 节点进度达到掌握 | 查看详情 |
| 可以学习 | 自由模式中的公开节点，或探索模式中全部严格前置已掌握 | 打开详情，记录发现，标记掌握 |
| 尚未解锁 | 探索模式中至少一个严格前置未掌握 | 通过前置路径继续探索 |

探索进度等于当前场景已掌握节点数除以当前场景节点数，结果显示为四舍五入后的整数百分比。领域和场域筛选不会改变分母。当前游戏化反馈包括状态图标、进度百分比、迷雾和“下一站”入口。当前版本没有积分、排行榜、签到或成就徽章。

“下一站”从全部可学习节点中选择一项。候选先按学习层级排序，再按节点数据中的横坐标排序。推荐结果不读取当前选中节点和筛选条件。没有候选时，按钮保持禁用。

玩家进度保存在 `localStorage` 的 `knowledge-map-progress`，数据包含格式版本、浏览模式、概念进度和已完成互动。旧的 `math-atlas-progress` 会迁移到新格式。当前原型预置 6 个示例掌握节点。重置操作恢复这些节点，并保留当前浏览模式。

## 当前浏览模式与迷雾

自由浏览模式允许直接查看当前场景的公开节点。探索模式根据未知、感知、发现和掌握状态计算可见性。切换模式不会清除已有进度。

探索模式中的已掌握和已发现节点会清除周围迷雾。满足解锁条件的未知节点显示为不含真实名称和标签的轮廓，单击后记录为已发现并打开详情。仍未满足条件的节点和关系不进入当前场景输出。标签场保留环境色，标签文字隐藏。

迷雾属于场景显示状态，不修改知识图谱、节点位置或内容数据。搜索只返回当前允许显示真实名称的节点。互动组件完成记录绑定概念 ID 和组件 ID。

## 后续规划

后续学习路线由稳定概念 ID、可选互动和完成条件组成。路线可以包含分支。路线进度与全图掌握率分别计算。首条计划路线将从八个领域中选择有真实关系支撑的跨学科路径，并包含一个互动组件和一个带来源的前沿入口。

## 产品规则

- 单击当前筛选允许交互的节点会打开对应卡片。可见子卡片达到 20% 透明度后可以接收单击，系统随后完成场景换根并将子层显示到 100%，相机缩放和平移保持当前值。相关规则见[节点钻取与 LOD](./06-节点钻取与LOD.md)。
- 自由浏览模式开放当前公开节点。探索模式按照迷雾可见性控制节点身份和详情。
- 掌握状态单向推进。重置操作用于恢复示例进度。
- 发现、掌握和路线完成状态分别保存。界面不得使用节点颜色推断其中任何状态。
- 重置进度只清除或恢复玩家状态，不修改内容、关系和布局。
- 奖项内容记录学术或行业事件。它与探索反馈分开管理，规则见[前沿研究与奖项](./08-前沿研究与奖项.md)。

## 开发约束

进度逻辑以稳定概念 ID 为键。概念可以出现在多个空间投影中，所有投影读取同一份发现和掌握记录。发布后修改 ID 时，需要提供进度迁移。

状态计算位于领域逻辑层。地图渲染层只接收节点状态和可见性结果，并回传选择、拖动和进入等标准事件。渲染组件不得直接写入掌握集合。

持久化数据需要带格式版本。读取旧版本时先校验数组、ID 和状态值。未知 ID 不应计入进度，迁移失败时保留可恢复的原始记录。

路线完成条件需要可重复计算。互动组件只能通过登记的完成事件更新路线进度。仅打开卡片、改变缩放或浏览到节点附近不能自动标记掌握。

## 边界情况

- 本地存储不存在或无法解析时，当前原型回退到示例进度。
- 用户从节点开始拖动时，节点不会被选中，已有选中状态保持不变。
- 用户从画布空白区域开始拖动时，详情保持打开，画布随指针移动。
- 筛选弱化的节点仍可通过搜索、“下一站”或小地图附近的画布操作访问。
- 关系数据更新后，已完成互动保留完成记录；路线详情应重新计算当前关系状态。
- 同一概念具有多个空间投影时，首次打开任意投影只产生一次发现记录。
- 自由浏览模式打开公开内容时，系统不得自动写入掌握状态。
- 没有可推荐节点时，路线仍可显示已完成步骤和手动浏览入口。

## 验收标准

### 当前版本

1. 单击节点打开详情，拖动超过 5 像素时只移动画布。
2. 详情打开后单击画布空白区域会收起详情，从空白区域拖动会保留详情并移动画布。
3. 选中节点后，完整前置路径和直接后继保持可辨认，直接后继与前置路径和普通上下文具有不同样式。
4. 缩放、显示全部和小地图导航都能改变视野，节点关系保持一致。
5. 标记掌握后，节点状态、探索进度和下一站候选立即更新。
6. 刷新页面后有效进度保留；重置后恢复 6 个示例节点。
7. 两种浏览模式可以切换，探索模式显示迷雾并隐藏未解锁节点身份。
8. 切换到三维空间后，十个公共透镜可以浏览同一组 320 个节点；透镜和筛选不会写入二维学习进度。

### 规划版本

1. 路线视图可以读取现有发现、掌握和互动完成记录。
2. 首次打开概念后，所有空间投影同步显示已发现状态。
3. 迷雾只改变场景显示，不改变知识数据和布局结果。
4. 路线完成条件可以从概念状态和互动完成事件稳定重算。
5. 旧进度经过版本迁移后继续对应有效概念，未知 ID 不计入统计。
