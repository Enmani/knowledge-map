# 知识关系与解锁

## 功能概述

每个节点通过 `prerequisites` 声明直接前置知识。画布连线从前置节点指向目标节点，箭头表示建议的学习方向。同一节点可以有多个前置，也可以成为多个节点的前置。

前置关系用于路径高亮、学习状态、下一站推荐和详情中的关系导航。地图数据需要保持有向无环结构。

子空间的父节点作为该空间起点的隐含严格前置。用户在探索模式中需要先掌握父节点，随后才能解锁没有局部前置的首批子节点。子空间内部的连线和详情列表只显示当前空间中的局部前置。

同一概念出现在多个场景时，各投影声明的局部严格前置会在概念层汇总。复动力系统在复分析子地图中依赖解析函数，在动力系统子地图中依赖混沌理论，探索模式会同时检查两侧要求。两个投影共享发现与掌握进度。

情境投影也可以使用不同的局部 ID 指向一个公共规范概念。当前 `linear-algebra:vectors-coordinates` 指向 `vectors-coordinates`：前者保留线性代数子域中的位置、阶段标签和局部关系，后者承担内容与进度身份。状态读取、状态推进和缺失前置比较都会先解析规范身份，避免同一个“向量与坐标”被重复学习。公共规范概念到经典力学和计算机图形学使用应用关系，到机器学习使用共享模型关系；三者都只表达知识迁移，不参与严格前置闭包或解锁。

## 查看知识关系

选择节点后，系统递归查找其所有前置节点。选中节点、前置闭包内的节点和闭包内部的连线会突出显示。其他节点和连线降低视觉权重。

详情中的“前置知识”只列出直接前置，并显示各项是否已掌握。点击任一前置可继续查看它的详情。

“掌握后解锁”列出所有把当前节点写入 `prerequisites` 的直接后继。这个列表说明结构上的下一层关系。后继拥有多个前置时，完成当前节点后仍可能需要补齐其他前置。

没有前置的节点显示起点说明。没有直接后继的节点显示当前地图的前沿终点说明。

## 学习状态

每个节点在运行时具有一种状态。

| 状态 | 判定规则 | 用户操作 |
| --- | --- | --- |
| 已掌握 `mastered` | 概念进度达到掌握 | 查看详情 |
| 可以学习 `available` | 自由模式中的公开节点，或探索模式中全部直接前置均已掌握 | 可发现并标记为已掌握 |
| 尚未解锁 `locked` | 探索模式中至少一个直接前置未掌握 | 不进入公开场景输出 |

状态计算先检查玩家进度。掌握状态单向推进。自由模式绕过解锁条件，探索模式按严格前置计算。

锁定按钮会显示尚缺多少个直接前置。数量只计算当前未掌握的直接前置，不包含更上游的间接前置。

## 标记掌握

“可以学习”的节点可以标记为已掌握。操作完成后，节点图标、探索进度、相关后继状态和下一站候选会立即更新。

“已掌握”的节点保持掌握状态。用户需要重新开始时，可以重置全部玩家进度。

当前版本采用用户确认制。标记操作不需要完成课程或测验。详情中的建议投入时长不会参与状态计算。

## 下一站推荐

“下一站”候选包含全部状态为“可以学习”的节点。候选先按 `level` 从低到高排序，再按节点数据中的 `x` 从小到大排序。按钮选择排序后的第一项，并执行普通节点选择流程。

推荐不读取当前选中节点、领域筛选、场域筛选或搜索输入。被领域或搜索弱化的节点、被场域标签排除的节点仍可能成为下一站。没有候选时按钮禁用。

## 进度保存和重置

玩家进度使用带版本的对象保存到 `localStorage` 的 `knowledge-map-progress`。记录包含浏览模式、规范概念进度、互动完成 ID 和更新时间。所有投影 ID 在读写前解析为规范概念 ID。读取旧的 `math-atlas-progress` 时，系统把节点 ID 数组迁移为掌握记录。记录缺失或无法解析时，系统载入内置示例进度。

内置示例进度包含“数与运算”“数理逻辑”“集合论基础”“证明方法”“函数与关系”“初等代数”。“重置示例进度”恢复这 6 项，并选中当前根场景的起始节点。随后保存逻辑会覆盖当前浏览器中的进度记录。

探索进度为当前场景已掌握节点数除以当前场景节点数，再四舍五入为整数百分比。领域和标签筛选不会改变分母。

## 开发约束

关系的唯一来源是目标节点的 `prerequisites` 数组。连线、直接后继列表和解锁计算均从该字段推导。开发者不需要维护单独的 `successors` 字段。

前置闭包使用已访问集合避免重复递归。知识图谱校验会检查缺失引用、规范投影、空间包含环和严格前置环。无效图谱会在适配层初始化时停止加载。

当前进度读取会校验格式版本、浏览模式、概念 ID、进度层级和互动完成 ID。未知概念 ID 会被丢弃，并在读取结果中记录。旧节点 ID 数组经过校验后迁移为版本化掌握记录。解析失败时使用示例进度。

改变状态规则时，需要同步验证节点样式、详情按钮、关系列表图标、探索进度、“下一站”和本地存储。状态文本和 `LearningStatus` 类型应保持一一对应。

## 边界情况

- 起点节点在未掌握时满足“全部直接前置均已掌握”，因此状态为可以学习。
- 已掌握节点不要求当前前置仍为已掌握。
- 一个后继只有在全部直接前置已掌握后才会变为可以学习。
- 直接后继列表不代表该后继已经可以学习，用户需要查看它的当前状态。
- 关闭详情或改变筛选不会改变掌握集合。
- 清除浏览器站点数据会移除进度记录，并在下次打开时恢复示例进度。
- 使用隐私浏览窗口、其他浏览器或其他设备时，进度相互独立。
- 存储内容可以解析但包含未知 ID 时，读取逻辑丢弃未知 ID，并在结果中记录迁移信息。

## 验收标准

1. 每条连线从直接前置指向目标节点，箭头方向与详情关系一致。
2. 选择含多层前置的节点后，全部上游节点和闭包内部连线得到突出显示。
3. 未掌握节点仅在全部直接前置已掌握时显示为可以学习。
4. 锁定节点的掌握按钮禁用，缺失前置数量与直接前置数据一致。
5. 重置玩家进度后，所有节点状态根据示例掌握记录重新计算。
6. “下一站”始终选择按层级和数据横坐标排序后的首个可学习节点，没有候选时按钮禁用。
7. 刷新页面后有效掌握记录保留；重置后恢复 6 个示例节点并选中“微积分”。
8. 发布前的数据检查确认所有前置 ID 存在，且关系图中没有自引用或循环。
9. 探索模式中的子空间起点在父节点未掌握时保持锁定，父节点掌握后按局部前置继续解锁。
10. 复动力系统只有在复分析侧和动力系统侧的直接前置均已掌握后才会解锁，任一投影上的掌握状态会同步到另一投影。
11. 从公共“向量与坐标”或线性代数子域投影推进学习状态时，存储中只产生 `vectors-coordinates` 一条规范进度记录，两个入口立即显示相同状态；它到经典力学、计算机图形学和机器学习的应用/共享模型关系均不参与严格前置闭包或解锁。
