# 内容规范与审核

[返回首页](./README.md)

## 内容单位

知识内容按概念、故事、互动、前沿条目和来源记录组织。每个单位使用稳定 ID。标题和展示位置可以修改，稳定 ID 不随重命名变化。

概念记录包含标题、摘要、学科、标签、难度、内容引用和关系引用。故事记录保存发现过程、人物经历和历史背景。互动记录声明学习目标、组件 ID、输入范围和完成条件。前沿条目保存类型、发布日期、复核日期、内容标签、相关概念和来源。奖项关系附着在研究条目上，通过受控标签和授奖机构官方来源表达，不生成脱离知识内容的独立雷达卡片。

## 关系要求

严格前置关系参与解锁计算，并接受有向无环检查。建议前置关系提供学习提示，不阻断访问。类比、应用和历史影响可以形成环。

空间包含关系单独维护。每个子空间只能直属一个父投影。一个概念可以在多个空间出现，所有投影共享同一份内容和进度。规范投影和别名投影都可以关联各自的子空间，子空间所有者需要与投影概念一致。

同一概念在多个场景出现时复用稳定 ID。各场景可以声明本地直接前置，图谱适配层按概念 ID 汇总严格前置。复动力系统当前使用该机制连接复分析和动力系统。新增共享概念时需要联合检查所有投影的前置关系和全图有向无环性。

## 标签要求

标签使用受控词表。每个标签包含稳定 ID、中文名、英文名、所属维度和颜色。参与布局的标签数量应保持有限。搜索标签可以更丰富，但不会全部参与场域计算。

新增顶级标签需要说明用途、适用节点和与现有标签的差异。近义词应记录为别名，避免形成重复场域。

前沿内容标签不参与场域布局，可以表达问题名、方法、证据状态和奖项关系。`菲尔兹奖`的存储值保持纯文本，界面负责添加 `🏅`；内容数据不得保存带 emoji 的重复标签。奖项标签必须同时具有授奖机构官方来源，摘要不得把授予个人的奖项表述为颁给猜想或论文。

“数量、空间、变化、结构”当前不作为新的顶级场域标签。数学分类扩展优先补充缺失概念、稳定前置关系和子空间层级。需要表达数量主题时，可以在具体标签中使用“数量”或更精确的术语。

## 来源要求

科学结论需要可追溯来源。基础知识优先引用教材、标准参考书和学术机构材料。前沿内容需要包含原始论文或官方技术材料。预印本需要显示未同行评审状态。

历史故事需要区分有来源事实和存在争议的叙述。无法确认的轶事不得作为确定事实发布。

来源记录至少包含标题、作者或机构、发布日期、链接、访问日期和许可信息。外部图片、视频和论文图表只有在许可明确时才能进入仓库。

## 审核状态

内容使用以下状态：

- `draft`：作者正在编写。
- `review`：等待学科或教学审核。
- `verified`：审核完成，可以发布。
- `needs-review`：超过复核日期或来源发生变化。
- `archived`：内容保留，但不再进入默认地图。

前沿条目必须设置 `reviewedAt` 和 `reviewDue`。到达复核日期后，系统将其标记为待复核。自动导入的数据只能进入暂存区，审核完成后才能发布。

## 审核流程

普通文字修正由一位维护者审核。新概念和故事需要学科审核。严格前置关系需要同时检查学科准确性和学习路径。跨学科关系需要相关学科的审核意见。前沿研究和带奖项标签的解读需要两位审核者确认来源和表述。

互动组件需要检查科学计算、输入边界、键盘操作和降低动态效果模式。涉及医学、生物安全或伦理风险的内容需要额外审核。

## 自动检查

主地图内容位于 [`src/data/mathMap.ts`](../src/data/mathMap.ts)，分析学子地图内容位于 [`src/features/map/analysisSceneContent.ts`](../src/features/map/analysisSceneContent.ts)，故事内容与类型位于 [`src/content`](../src/content)。图谱校验位于 [`src/domain/knowledgeValidation.ts`](../src/domain/knowledgeValidation.ts)，前沿目录校验位于 [`src/frontier/validation.ts`](../src/frontier/validation.ts)。新条目可以从[内容条目模板](../docs/CONTENT_TEMPLATE.md)开始。

内容合并前执行以下检查：

- ID 唯一，引用存在。
- 包含关系没有循环。
- 严格前置关系没有循环。
- 前沿条目具有来源和复核日期。
- 奖项标签具有官方来源，`菲尔兹奖`不会形成独立公开条目。
- 资源文件具有许可声明。
- Markdown 链接有效。
- 互动组件 ID 已在注册表登记。

## 验收标准

发布内容可以从界面追溯到来源。深层节点可以通过稳定链接访问。前沿内容能够显示研究状态和最后复核日期。失效引用会阻止构建。未经审核的自动导入内容不会出现在公开地图中。
