# 标签与场域

## 功能概述

地图使用领域、场域标签和具体标签描述知识点。三者承担不同职责。

| 分类 | 节点数量约束 | 当前用途 |
| --- | --- | --- |
| 领域 `domain` | 每个节点一个 | 领域筛选、节点主色、详情归类、小地图节点颜色 |
| 场域标签 `fieldTags` | 每个节点可有多个 | 自动布局、模糊场域、场域筛选、搜索、详情标签 |
| 具体标签 `tags` | 每个节点可有多个 | 搜索和详情中的主题说明 |

当前版本定义 7 个领域和 11 个场域标签。11 个场域标签都达到可视场域的成员数量要求。领域表达学科归属，场域标签表达可以横跨多个领域的共同主题。具体标签用于补充节点内部的术语，不参与空间聚集。

三维公共空间定义数学、物理、化学、生物、神经科学、认知科学、计算机科学、地球与环境科学八个领域。三维节点使用 `domains` 表达多领域归属，使用 `primaryDomain` 确定卡片主色；当前 320 个节点中有 243 个具有多领域归属。领域不再对应预设方向，而是以较弱的领域亲和度与关系、标签共同参与谱嵌入，形成可辨认、可分裂且相互重叠的自然知识区域。每个领域生成柔和彩色体积场，当前 110 个至少被两个节点共用的主题标签也会自动生成标签体积场。场中心、球瓣和作用包络随当前透镜与筛选投影重新计算。

## 领域筛选

左侧领域栏列出全部领域。点击一个已启用领域会将其关闭；当该领域是唯一启用项时，点击不会关闭它。点击已关闭领域会重新启用。

关闭领域后，对应节点会降低视觉权重。跨越关闭领域的关系线也会降低视觉权重。筛选保留节点和连线在原位，因此用户仍能判断它们与当前内容的空间关系。

领域栏同时显示启用数量和探索进度。探索进度依据全图掌握节点计算，不随领域筛选改变。

## 场域生成

每个 `TagField` 定义标签 ID、颜色和说明。自动布局先找到包含该标签的所有节点。成员少于 3 个时不生成可视场域；节点仍可保留该标签并参与搜索与详情展示。

达到生成条件后，系统计算成员中心，并根据成员位置生成最小生成树。数学全景的成员连接距离上限为 756 个世界单位，成员周围的场域半径为基础值的 1.4 倍。子场景根据节点几何尺度计算连接上限。保留的连接和成员周围的圆形区域共同形成场域轮廓。

PixiJS 渲染器先把同一标签的成员圆与保留连接合并为一张不透明蒙版，再统一模糊、着色并生成一个裁剪后的低分辨率纹理。一个场域只应用一次整体透明度，同一场域内部的重叠不会反复累积颜色。各场域使用普通透明度混合，透明边缘保持标签颜色，相邻场域重叠时形成混色。标签名称位于成员位置的算术中心。

场域形状来自标签成员的实际位置。新增节点、调整标签或修改布局参数都可能改变轮廓、标签中心和重叠区域。

## 场域筛选

用户可以在节点详情中点击场域标签。选中后，地图只显示当前标签的场域、包含该标签的节点以及两端都包含该标签的关系。其他场域、节点和关系停止绘制，也不参与画布命中。再次点击同一标签会恢复全部场域。左侧状态区也提供清除当前场域筛选的按钮。

三维知识卡片中的领域与主题标签位于节点简介正下方，先于长文、图解和互动内容显示。标签承担快速定位作用，不再被公共视角说明隔开；当前公共视角和公共知识关系统一移到卡片末尾。

一条前置连线只有在两端节点都包含当前场域标签时，才保留场域筛选下的正常权重。节点只需包含当前标签即可保留正常权重。

领域筛选与场域筛选可以同时生效。当前标签场只要覆盖至少一个启用领域，就可以绘制背景；其中属于关闭领域的节点继续保持弱化并停止接收画布点击。

## 三维领域场与标签场

三维投影为每个领域成员和标签成员生成一个以节点坐标为中心的柔和球瓣。领域球瓣半径为 `2.7 + 0.9 × 节点尺度`，标签球瓣半径为 `2.1 + 0.72 × 节点尺度`；实际绘制面片再扩展到语义半径的 1.48 倍，为外层辉光预留连续衰减范围。球瓣透明度结合节点可见度和显著性。多个同类球瓣重叠后形成连续场域，成员分成多个空间簇时会保留多个分离场域。簇之间的空白区域不进入场域着色。

公共全景同时显示八个领域场和 110 个成员数量达到条件的标签场。单学科透镜提高当前领域的场域权重，并保留关联领域的弱场作为上下文。跨域桥梁透镜使用接近的八领域权重。公共场与子域场的全部球瓣进入同一个相机朝向 InstancedMesh；颜色、透明度、近景衰减区间和所属作用域通过实例属性区分。每个散点由两个三角面组成，散点中心保留三维节点坐标，镜头旋转时面片持续朝向相机。光学密度加法与绘制顺序无关，因此合并批次不改变场域叠色结果。

散点内的归一化半径为 `ρ`。片元同时计算紧凑核心 `core = 2^(-6.4ρ²)` 与宽阔辉光 `halo = 2^(-1.7ρ²)`，再乘以从 `ρ = 0.76` 开始平滑降到零的外包络。基础密度为 `0.72 × core + 0.16 × halo`。顶点着色器还根据球瓣的屏幕投影半径计算近景衰减：镜头推进、单个球瓣在屏幕上变大时，核心和辉光分别降低，但不会突然切断。片元只在光学密度小于 `10⁻⁵` 时停止写入，因此可见边缘不会形成硬壳。

球瓣不直接把 RGB 叠到主画布，而是在半浮点场域缓冲中以 `ONE / ONE` 累积光学密度：RGB 保存 `Σ(cτ)`，Alpha 保存 `Στ`。合成时先用两者比值恢复稳定色相，再以 `α = 1 - exp(-EΣτ)` 把密度映射为有界透明度。密集重叠会变亮但不会线性漂成白色，绘制顺序也不改变结果。领域色和标签色按深色、浅色主题分别映射；深色主题提高色彩饱和度，浅色主题使用较低曝光，避免灰雾和脏色。

场域源层按主画布物理分辨率的 42% 绘制。外层辉光在 21% 分辨率的两个中间缓冲中执行横向、纵向高斯模糊，再与清晰源层以预乘透明度合成到主画布。三个离屏通道始终覆盖完整画布，避免场域平移、旋转或缩放时出现矩形切边。节点、关系和文字仍保持主画布分辨率，辉光不会参与射线命中。

节点自身的光晕不是领域场或标签场。它使用独立的实例批次与 28% 物理分辨率半浮点缓冲，把白热亮核、提亮后的领域色内晕和宽外晕分层累积，再以 `1 - exp(-Στ)` 有界合成到关系线下方。星点取领域的明亮 `fieldColor`，并在线性空间内归一到 0.43 目标亮度，增益限制为 0.92 至 1.08；色相只进入内外晕，核心保持近白，因此不会出现光点比场域更暗、更脏的情况。颜色空间转换在预乘透明度之前完成。高分辨率亮核的世界尺寸为外晕基准尺寸的 `50%`，外晕覆盖范围保持不变。节点光晕不参与场域开关、场域模糊或射线命中，关闭颜色场域仍保留节点星光。

左下角颜色场域开关同时控制领域场和标签场。关闭时场域透明度连续降到零，节点、关系、相机和投影坐标保持不变。开启时场域按照当前透镜和领域筛选结果连续恢复。

场域包络中心按可见成员的透明度和显著性加权计算，包络半径使用完整 XYZ 欧氏距离。包络用于统计和过渡，实际颜色来自成员散点。隐藏节点的对应散点透明度为零。三维场域不参与节点命中。透镜或筛选切换期间，散点位置、半径和透明度连续插值。相机单独移动时复用稳定的实例缓冲。场域离屏结果带有独立脏标记：仅悬停、选择卡片或关系聚焦时复用上一份清晰场和辉光纹理；相机、主题、场域数据、视口或父子进度变化时才重新生成。

进入任一已注册三维子域时，公共颜色场从子层进度 5% 至 72% 连续淡出；子域颜色场从 18% 至 82% 连续显现，两套场在中段短暂重叠，避免镜头推进时出现暗断层。数与运算、微积分、线性代数、记忆、感觉与知觉、细胞与分子神经科学、认知神经科学分别生成 5、4、6、7、6、7、5 个局部场，共 40 个。线性代数的 6 个局部场由一个主领域场和“直观基础、方程计算、空间结构、几何与谱、进阶工具”五个学习阶段场构成；其他子域仍只为至少两个内部节点共同使用的标签生成局部标签场。子域球瓣同样随屏幕投影半径变淡，使镜头穿入局部知识空间时背景光逐渐让位给内部节点和关系。

## 三维领域筛选

三维领域筛选位于左下角控制栏右侧的“领域范围”上拉菜单，不再占据左上画布。菜单提供“全部领域”和八个单领域选项，只使用临时筛选：改变节点、关系和场域的可见性，节点保留关系驱动的公共坐标。菜单内容超过可用视口高度时在弹层内部滚动。当前界面不提供专业聚焦选项。

菜单底部提供三档“筛选强度”滑块，从左到右越来越严格：

| 档位 | 显示范围 |
| --- | --- |
| 直接关联（最宽） | 所有归属于当前领域的节点，加上与这些节点有任意类型直接连线的双向一跳邻居；不限制关系强度，不扩展二跳或更远关系。 |
| 包含跨域（默认） | `domains` 包含当前领域的全部节点，同时保留仅属本领域和跨领域归属的节点，不要求当前领域是 `primaryDomain`。 |
| 仅本领域（最强） | `domains` 只有当前领域一项的节点；排除任何多领域归属。 |

滑块实时更新显示结果、档位说明和可见公共节点数量，支持鼠标、触屏及键盘方向键。没有符合条件的节点时保留空结果。“全部领域”下显示完整公共空间，滑块禁用并提示先选择领域；本次页面会话中切换领域或暂时显示全部领域会保留已选强度。强度控制公共空间筛选，已进入的子域继续使用其自身节点集合。

“领域范围”与相邻的“观察视角”菜单互斥。打开其中一个会收起另一个；选择领域和调整滑块时保持菜单展开，点击菜单外部、再次点击领域按钮或按 `Escape` 后收起。按钮本身显示当前领域范围，移动端显示较短的“领域”文字，选项和功能保持完整。

筛选隐藏的节点透明度为零，不绘制关系和场域，也不参与射线命中、搜索结果或详情关系跳转。临时筛选不修改公共节点、关系、公共坐标或规范基础—专业化半径。投影模块内部继续保留专业聚焦解析能力用于兼容和算法测试，但应用界面不请求该模式。

筛选实际隐藏节点后，公共视图旋转中心使用当前筛选保留节点的三维世界坐标算术平均值，不按领域、重要性或透明度加权；画面外但仍在筛选结果内的节点也计入，已经被筛选排除的节点即使仍在淡出也不计入。每次右键拖拽或 `Alt` 加左键拖拽开始时重新计算并锁定中心，拖拽期间中心保持稳定。筛选只有一个结果时围绕该节点旋转，空结果不执行旋转；恢复全部节点后使用公共空间中心。切换筛选本身不移动相机或节点。已进入子域时继续使用当前子域的几何中心，退出子域后使用当时公共筛选结果的中心。

## 标签命名规则

场域标签使用稳定的中文 ID。该 ID 同时承担数据值、搜索词、界面文字和筛选条件。修改场域标签 ID 时，需要同步更新所有节点引用。

具体标签可以使用中文、英文或常见缩写，例如 `ODE`、`PDE`、`MCMC`。同义词不会自动合并，大小写只在搜索比较时被忽略。需要聚合统计或统一筛选的概念应使用一致的字符串。

标签数组应避免同一节点内的重复值。当前渲染直接遍历数组，并以标签文本作为 React 键；重复值可能引发键冲突，也会在详情中重复显示。

## 开发实现边界

场域标签类型 `FieldTagId` 是封闭联合类型。新增场域标签时，需要同时修改类型定义、`tagFields` 定义和相关节点。仅添加定义而没有成员时，不会产生场域。

`fieldColor` 在找不到定义时返回棕色后备值。该后备只避免部分样式失效，无法补齐场域说明或生成成员关系。类型检查通过的正式数据不应依赖后备颜色。

自然布局中的标签吸引按两个节点共享的场域标签数量计算。径向主图先按领域形成分支簇，再根据最终节点位置生成跨簇场域。推进式子图按依赖深度投影到横向列，纵向位置使用数据锚点。场域始终读取最终节点位置。

节点尺寸会参与吸引距离、前置关系间距和碰撞间距计算。卡片放大后，节点间距和场域连接范围会按几何尺度同步扩展。最终布局逐对消除重叠。自然布局保留两个坐标轴上的位置差异；推进式布局保留纵向分支差异。

模糊场域在场景建立时生成稳定纹理，活动领域或活动标签变化时只更新纹理的可见性和整体透明度。平移和缩放只改变世界图层变换，不重建场域。场域纹理在渲染器销毁时同步释放。调整栅格比例、气泡半径、连接带宽、模糊半径或透明度时，需要同时验证颜色、边缘质量和显存占用。

## 边界情况

- 一个节点没有场域标签时，仍可按领域显示，但不会属于任何自动场域。
- 一个场域只有 1 或 2 个成员时，界面不会生成其背景和名称；详情中的标签按钮仍可触发筛选。
- 最小生成树中的长边被移除后，同一场域可能显示为多个分离区域，标签名称仍放在全部成员的平均中心。
- 关闭部分领域时，跨领域场域可能继续显示背景，其中关闭领域的成员节点保持弱化。
- 具体标签与场域标签同名时，详情中可能同时出现按钮和文本标签；二者交互能力不同。
- 当前场域筛选生效时，画布无法选择不含该标签的节点。通过搜索或详情关系打开其他节点时，筛选不会自动清除，地图仍只绘制匹配内容。

## 验收标准

1. 每个领域 ID、每个场域标签 ID 在各自定义中唯一。
2. 节点的 `domain` 和 `fieldTags` 均能通过 TypeScript 类型检查，并能找到对应定义。
3. 启用或关闭领域后，节点、连线和场域背景按规则更新；界面始终至少保留一个启用领域。
4. 点击详情中的场域标签后，只绘制相关节点、当前场域和双端匹配的连线；其他内容无法从画布命中。
5. 成员达到 3 个的场域具有背景和标签名称；成员不足时不生成可视场域。
6. 相同数据在刷新后生成相同的节点位置、场域连接和标签中心。
7. 径向主图和推进式子图调整节点位置后，场域背景随最终位置和连接范围同步更新。
8. 拖动画布期间没有重复执行场域布局，视觉移动保持连续。
9. 父地图和子地图中的节点没有重叠。
10. 场域保持各自的标签颜色，相邻场域重叠处可见混色，不出现覆盖地图的大面积黑色或灰色遮罩。
11. 单个场域内部的成员圆和连接带合并后只应用一次透明度，缩小画面时不出现独立圆纹理的锐利边界。
12. 三维公共全景显示八个柔和领域场与 110 个自动标签场，单学科透镜保持聚焦领域清晰并保留跨领域上下文。
13. 三维场域重叠处可见混色，场域不遮挡卡片文字，也不参与射线命中。
14. 三维透镜切换期间，场中心、半径和透明度连续变化。
15. 三维场域中心、半径和节点碰撞使用完整 XYZ 距离。
16. 左下角“领域范围”菜单只提供全部领域和八个临时筛选选项；筛选保持关系驱动的公共坐标，短屏时菜单内部滚动，界面不出现专业聚焦选项。
17. 筛选隐藏节点不绘制、不进入场域计算，也不能被搜索、详情关系或射线命中。
18. 三维场域由成员节点散点构成，分离簇之间的空白不会被单一包围球填色。
19. 三维散点边缘连续降到零，缩放和旋转后不出现球壳硬边、黑色硬边或脏色遮罩。
20. 颜色场域开关只改变场域显示状态，开关过程不重算关系驱动语义布局。
21. 三维场域先累积光学密度再做指数有界合成，重叠颜色可辨认，密集区域不会因线性累加形成过亮白斑。
22. 相机平移、缩放、旋转和行走期间不重复上传已经稳定的场域实例矩阵。
23. 镜头推进时，公共场域随球瓣屏幕半径和子层进度连续变淡；当前七个子域各自的局部场连续接管画面，父子场域交接不出现硬边、闪断或全黑间隙。
24. 公共场和子域场合并为一个实例批次后，颜色、透明度、主题和近景衰减与合并前一致；悬停或选择卡片不会重新执行场域源层和两次模糊。
25. 场域离屏通道覆盖完整画布；平移、旋转和缩放后不出现矩形切边或辉光缺口。
26. 三维知识卡片的标签紧跟节点简介显示，公共视角和公共关系不会插入简介与标签之间。
27. 关闭颜色场域不会关闭节点核心或节点光晕；节点光晕始终绘制在关系和卡片下方，不能扩大节点命中范围。
28. 八个领域节点光晕的归一化线性亮度变异系数不超过 1%，深色与浅色主题下均保留可辨认领域色，白热核心不被领域色染暗，密集区域不出现大面积白斑。

29. 三维领域滑块从左到右按直接关联、包含跨域、仅本领域递增强度；默认包含跨域，各档集合逐步收窄，最宽档不扩散到二跳。
30. 八个领域的三档强度均依据完整 `domains` 判断归属；主领域不同的交叉节点仍进入中档，任何多领域节点均不进入最强档。无匹配时显示空结果。
31. 拖动或使用键盘调整强度即时更新节点数量、搜索、详情关系与命中集合，隐藏端点的连线同步隐藏，所有节点公共坐标保持不变。
32. 选择领域与调节强度后菜单保持展开；全部领域禁用滑块，返回具体领域保留强度；深浅主题及窄屏均可完整操作。

33. 所有三档领域强度下，公共旋转中心只由筛选保留节点当前世界坐标决定；移动隐藏节点不得影响中心。拖拽内中心稳定，重新调整筛选后的下一次旋转使用新集合，空结果不旋转，取消筛选恢复公共空间中心。
