# 节点钻取与 LOD

[返回首页](./README.md)

## 当前缩放、钻取与选择

当前原型包含数学全景和 17 个子场景投影。数学全景显示 47 个节点，并公开 16 个可钻取子空间。微积分子空间显示极限、导数、积分、微积分基本定理、级数和多元微积分 6 个节点；线性代数子空间按“直观基础—方程计算—空间结构—几何与谱—进阶工具”显示从向量与坐标到矩阵性质图谱的 18 个节点。实分析、复分析、泛函分析、测度论与积分、傅里叶与调和分析、变分法、微分方程、数值分析、点集拓扑和动力系统子地图合计包含 58 个节点投影。初等函数、多元微积分、离散结构和随机过程分别包含三角学、向量微积分、序理论和金融数学。向量微积分同时具有主图多元微积分入口和“数学全景 / 微积分 / 多元微积分”三层入口。

单击节点会打开右侧知识卡片。数学全景和全部子地图在节点选择时都保持当前相机缩放和平移。用户从节点区域拖动超过 5 像素时，系统拖动画布并取消本次单击。具有子空间的知识卡片提供连续放大的按钮。用户把父节点移到视口中心并持续放大时，内部节点会逐步显现。子层透明度超过 80% 时，导航路径和交互作用域自动进入对应子空间。子层透明度达到 20% 后，子卡片可以接收单击；单击会立即进入对应子空间，并将子层显示状态置为 100%，相机矩阵保持当前值。

根场景和全部子场景使用同一台根坐标相机。进入子空间只更新导航路径、选择和交互归属，画布矩阵保持不变。面包屑显示从数学全景到当前子空间的路径和深度。返回按钮、根场景按钮和 `Escape` 可以退出子空间。退出时继续使用当前镜头，并选中刚刚退出的父节点。

## 二维当前语义 LOD

LOD 根据节点投影到屏幕后的像素尺寸决定基础显示层级。系统还会考虑选中状态、搜索命中、路径关系和玩家进度。重要节点可以在较远比例下保留标题或状态，其他节点按基础层级简化。

当前使用以下显示层级。

| 层级 | 主要内容 | 交互 |
| --- | --- | --- |
| 远景标记 | 领域颜色、概念位置和必要状态 | 单击打开卡片 |
| 节点摘要 | 标题、领域、学习状态和少量标签 | 单击打开卡片，查看关系高亮 |
| 内部预览 | 子节点数量和进入提示 | 继续放大或使用卡片按钮进入 |
| 当前子空间 | 子节点、局部关系、场域和导航上下文 | 完整浏览当前场景 |

内部节点在父卡片的基准视觉倍率达到 180% 时开始连续显现，在 260% 完成显现，缩小时按同一曲线连续消失。基准视觉倍率由场景有效缩放乘以该场景的卡片尺寸倍率得到，因此不同层级以接近的屏幕卡片尺寸触发显隐。父卡片和父层内容随内部结构淡出。子层达到 100% 可见时，父层透明度为零。进入子域前，子层透明度同时读取缩放倍率和父节点相对视口中心的位置；进入子域后，透明度只读取缩放倍率，画布拖拽和小地图平移不会触发退域。当前交互作用域读取同一透明度：子层超过 80% 时进入子域，低于 20% 时回到父域，20% 至 80% 区间保留当前作用域。该滞回区间用于避免临界点反复切换。单击可见子卡片会暂时把子层显示固定在 100%，缩放会解除固定并恢复倍率驱动的透明度。普通 LOD 层级变化保留 70 毫秒显示停留。卡片中的放大入口会把刚好进入内部空间的镜头比例再放大两倍。第 2 层的子卡片使用初始卡片六倍的绝对世界尺寸，节点间保留 220 个世界单位的最小间隔，并以完整几何尺寸参与布局和防碰撞。只有一个依赖列的专题子图会把卡片水平居中。标签场的气泡半径、连接带宽、模糊范围和成员连接距离随子卡片尺度扩大。进入子空间时相机矩阵保持原值。滚轮输入更新目标倍率，实际相机通过阻尼逐帧接近目标，并保持鼠标指针下的世界坐标稳定。

连续相机矩阵由独立控制器保存。滚轮、拖拽和自动深入在动画帧中直接更新世界变换、父层透明度和子层透明度。React 在动画结束、选择变化和作用域跨越阈值时更新界面语义。左下角缩放百分比在每个相机帧直接更新固定文本节点，不触发根组件逐帧渲染。卡片按钮触发的自动深入使用视口中心与可见宽度的缩放插值，后续输入从当前屏幕矩阵接管。

当前父层和子层在一次钻取周期内保持稳定挂载。进入 80% 和退出 20% 时保留两个场景的节点、连线、场域位图和雾层实例，只更新面包屑、详情、指针归属和场景透明度。父层透明度为零时仍保留已生成内容，缩小时可以直接恢复。场景内部渲染上下文按场景保存，换根不会让两层节点同时重新计算。节点从远景标记进入摘要使用 30 像素进入阈值和 24 像素退出阈值。

具有子空间的节点进入视口中心并达到相应尺寸后显示内部预览。普通节点根据投影高度在远景标记和节点摘要之间切换。后续版本会加入搜索命中、路线目标和关系路径的完整语义优先级。

三维“线性代数”完整卡片纹理与旧开合接线继续保留为回退实现，但当前气泡主循环不再创建完整卡片，因此中文气泡悬停和光点悬停都不会播放该动画。右侧详情单独复用正交 SVG：每次打开“线性代数”详情播放一个 2 秒周期且只播放一次，关闭后重新打开才重播；动态图标实验页继续使用 4 秒循环，不受详情交互时长影响。

## 三维当前气泡显示机制

三维节点不再按投影尺寸生成完整卡片，也不再持续计算完整卡、标题卡和光点之间的实时 LOD。地图内只保留光点和中文气泡，完整内容统一显示在右侧信息栏。气泡只显示中文名，使用 13 CSS 像素字号，固定为 26 CSS 像素高，左右各 10 像素内边距，宽度按实际文字测量并紧包裹；气泡使用旧完整卡片圆角比例的小圆角矩形，不使用胶囊或椭圆外形，底边固定在星点中心上方 16 CSS 像素。用户单击主节点后，主节点继续显示普通气泡，独立星点核心放大到两倍。选中期间，投影落在屏幕内的全部直接关联节点都显示中文气泡，不经过普通背面、遮挡、碰撞或密度淘汰；无关节点名称全部退回光点，关联气泡重叠时由相机空间深度决定叠放，离镜头近者在上。取消选择后星点核心恢复普通尺寸，关联临时层立即撤销。星点核心和光晕使用独立显示层，气泡出现时不压暗星点。

气泡数量直接读取当前 CSS 视口的像素承载能力。布局累计真实气泡矩形面积，不超过视口面积的 11%，并在气泡之间保留 7 CSS 像素间距。候选只有两条普通优先级：与镜头的距离，以及从严格前置关系图计算的 `foundationScore`。分配顺序固定交织两张镜头近邻和一张关系中心节点，因此中心知识能自然进入画面，又不会压过镜头已经切换到的近处内容；节点 ID、作者硬标和随机数都不参与排序。

普通气泡集合以 ID 快照保存。镜头静止时不执行重新评分；单击、取消选择、悬停、搜索详情和关系聚焦只改变覆盖状态，不改变快照。最后一次单击的节点会立即加入快照，并在点击时有效视距 45% 与 0.75 个缩放倍频程范围内保持。缩放保留区间包含上下边界，即点击时倍率除以或乘以 `2^0.75`；实现直接比较倍率区间，避免对数往返计算的浮点误差。相机平移、旋转、行走、缩放或节点过渡期间，每个渲染帧都用当前相机矩阵、星点位置和上移后的气泡矩形重新选择，因此气泡会随画面实时出现和退出。纯靠近缩放使用只增不减模式；其他镜头运动允许近处候选直接替换旧气泡。镜头停止后保留最后一帧快照，不运行后台刷新。

全局倍率低于 100% 后，普通气泡随倍率平滑淡出，八个大域名称同步淡入，并在 70% 时完成切换；大域名称的材质透明度随远景进度增长，但最大只到 50%。每个大域名称取该领域全部公共成员节点当前三维坐标的算术中心，多领域节点参与其所属的每个大域；文字只使用领域主题色填充，不绘制黑色或白色描边，深色主题把领域色明显压暗以越过高亮星云背景。选中主节点气泡及全部屏幕内直接关联气泡不乘这层远景透明度，即使倍率低于 70% 也保持完整可读。

旧 `stableLod.ts`、旧标题卡纹理和旧实时 LOD 解析器继续保留在代码库中作为回退实现，但当前 Three.js 主循环不调用它们。

## 三维知识子域

三维公共作用域由八个领域、320 个节点和 973 条关系构成，公共节点位置来自关系驱动语义布局。集中注册表当前收录“数与运算”、微积分、线性代数、记忆、感觉与知觉、细胞与分子神经科学、认知神经科学七个子域，合计 74 个命名空间节点、139 条关系和 40 个局部场。数与运算包含 13 个节点、15 条严格前置、6 条建议前置和 5 个局部场；微积分复用二维场景中的 6 个节点、7 条严格前置和 4 个局部场；线性代数复用二维场景中的 18 个稳定投影 ID，包含 31 条严格前置、2 条建议前置、2 条共享模型、3 条应用关系和 6 个局部场；其中 `linear-algebra:vectors-coordinates` 解析到公共 `vectors-coordinates` 的规范内容与进度。四个认知与神经科学试点分别包含 9、10、9、9 个节点，并实际使用全部五种关系语义。全部内部卡片的局部坐标都映射到对应父节点所在球面的切平面。内容依据见 `docs/research/arithmetic-subdomain-framework.md`、`docs/research/linear-algebra-subdomain-framework.md` 与 `docs/research/science-taxonomy-frameworks.md`。

三维子域的启动条件由滚轮事件和节点命中共同决定。用户需要把指针放在声明了子域的父节点上并向内滚动，也可以双击该父节点。子层开始显现前，如果下一次向内滚动命中空白或其他节点，本次启动状态会取消。子层已经开始显现后，后续缩放沿当前父子关系连续进行。进入作用域后向外滚动会先缩小子域视野，实际倍率到达独立退出阈值时才退出，退出过程不要求命中父节点。

显隐进度读取当前父卡片的屏幕投影高度。公共工厂默认区间为 360 至 620 CSS 像素。用户在更高倍率首次触发时，起点使用当前投影高度，终点至少为起点的 1.65 倍，使子层仍然保留连续出现过程。子层进度使用平滑三次曲线。公共节点和关系从子层进度 18% 开始淡出，在子层进度 100% 时归零。颜色场域使用独立的尺度交接曲线：公共场域在 5% 至 72% 之间淡出，子域场域在 18% 至 82% 之间显现；两者在中段重叠，配合球瓣的屏幕投影半径衰减形成“穿入子域”的连续光线变化。

三维作用域采用倍率滞回。子层进度达到 80% 且实际相机倍率达到 1245% 时进入对应子域；进入后锁住已达到的子层显示权重和命中状态，允许用户继续缩小查看，直到实际倍率达到 800% 才返回公共知识空间。三维内部节点达到 80% 后才参与射线命中。进入和退出只修改显示权重、命中状态和 React 作用域标识，不重新运行公共语义布局；相机位置、观察点和全局倍率保持连续。左下角控制栏在进入后动态显示当前子域标题与“内部”。

三维父层与七个子域的 74 个节点、139 条关系和 40 个局部场在渲染器初始化时一次性建立。缩放阈值不创建或销毁 Three.js 对象。子域节点和场域在完全折叠时保持常驻并退出绘制、LOD 避让或射线命中。子域定义中的 `fields` 字段为可选项，旧定义或开发态热更新缺少该字段时按空数组处理，不阻断 WebGL 启动。三维缩放范围为 10% 至 12800%，滚轮步进和 90 毫秒对数阻尼与二维画布一致。

`createThreeKnowledgeSubspace.ts` 是所有三维节点共用的子域定义模块。调用方声明父节点、内部节点、局部坐标、类型化关系列表、节点比例和场域样式；工厂统一添加命名空间、生成关系与共享标签场，并应用 360–620 像素显隐和 1245%/800% 进入退出默认值。只有严格前置参与环检测；建议前置、共享模型、类比与应用仍参与布局、渲染和详情。`subspaceRegistry.ts` 是全部子域的注册真源，拒绝重复子域、重复父节点或不存在的公共父节点。渲染器中的启动、显隐、滞回、命中、搜索和作用域切换继续由同一套通用运行时处理。新增节点子域不需要修改 `App.tsx` 或复制进入退出代码。

## 场景换根

每个可钻取概念关联一个子空间。子空间使用独立的世界尺寸、布局、标签场和小地图，并通过固定缩放与平移矩阵嵌入父节点。系统根据场景目录计算任意子空间到根空间的坐标和缩放映射。

微积分子空间采用四列推进布局。极限位于第一列；导数和积分位于第二列；微积分基本定理和级数位于第三列；多元微积分位于第四列。纵向位置表达分支和汇合。前置连线保持从左向右，曲线控制点位于相邻列的间隔内。

分析学专题子地图使用同一套推进布局。实分析从数列与函数列进入极限与连续，再分向微分、积分和一致收敛。测度论从 σ 代数与可测函数推进到测度、勒贝格积分、收敛定理、乘积测度、Lp 空间和 Radon–Nikodym 定理。复分析、泛函分析、傅里叶分析、变分法、微分方程、数值分析、点集拓扑和动力系统分别按各自的直接前置分列。

新增子空间在未声明布局策略时采用推进式布局。每个子空间需要为节点提供稳定的纵向锚点，并提供足以容纳全部依赖列的世界宽度。领域内容沿横向阅读方向推进。

导航换根只改变当前空间 ID、面包屑、选择和指针交互归属。进入和退出沿用当前相机。滚轮、拖拽和面包屑操作会取消尚未完成的镜头动画。进入动作不会直接改变概念的掌握状态。

多元微积分同时出现在数学全景和微积分子空间。知识模型把全景位置保存为规范投影，把微积分子空间位置保存为别名投影。两个投影共享概念进度。两个投影分别嵌入一个向量微积分子场景，子场景中的向量微积分投影共享同一概念进度。

复动力系统同时出现在复分析和动力系统子地图。复分析投影提供解析函数一侧的前置，动力系统投影提供混沌理论一侧的前置。知识图谱按概念 ID 汇总两侧关系，并把后出现的场景位置记录为别名投影。

## 面包屑与深层链接

面包屑显示当前空间路径，从根地图开始排列。每一项对应导航栈中的空间，不使用前置关系推导层级。单击上级项会退出到对应空间，画面保持在当前连续相机位置。

当前面包屑支持层级返回和根场景跳转。稳定深层链接仍在规划中。链接将包含空间路径和目标概念 ID，失效路径会回退到最近可用的上级空间。

搜索命中深层概念时，结果应显示其主要空间路径。选择结果后，系统可以直接进入该路径。若概念有多个投影，搜索结果使用主要投影，卡片提供其他入口。

## 数据与渲染边界

多尺度探索使用概念、空间、投影和场景四类数据。概念保存内容和关系；空间保存包含结构；投影保存概念在某个空间中的位置；场景是根据当前空间、进度和 LOD 生成的可渲染结果。

React 负责页面框架、知识卡片、面包屑和互动组件。主地图使用 PixiJS WebGL 绘制节点、连线、标签场和迷雾。WebGL 初始化失败时，地图区域显示错误状态。布局、关系、解锁、内容和导航栈不依赖 PixiJS 对象。

`MapRenderKernel` 根据相机、视口、面板宽度和当前作用域生成父子场景帧。PixiJS 适配器读取场景帧与视觉状态，并回传标准化命中结果。领域逻辑决定是否选择节点、打开卡片或执行换根。

## 开发约束

- LOD 阈值以屏幕像素为依据，并在桌面和移动视口分别验证。
- 进入阈值和退出阈值需要形成滞回区间。相机轻微抖动不得反复改变当前空间。
- 父子场景的嵌入矩阵保持稳定，导航换根前后的同一子节点屏幕位置误差控制在 0.5 CSS 像素以内。
- 相机动画取消时，系统从当前矩阵继续响应用户输入。
- 连续相机帧只修改世界变换和场景合成属性。根组件不接收逐帧相机状态更新。
- 缩放百分比读取连续相机矩阵，并通过固定文本节点逐帧更新。
- WebGL 内部视口以地图宿主元素的 CSS 边界为准。命中测试使用同一边界内的 CSS 像素坐标，设备像素比只影响绘制分辨率。
- 一次父子钻取期间保持场景图层实例稳定。作用域阈值不得触发父层或子层整体卸载。
- 每个投影引用有效概念和空间。空间包含关系必须无环。
- 布局缓存包含 `layoutVersion`。数据或算法变化后，需要生成新版本。
- 当前作用域中的节点单击用于打开卡片。父作用域中达到 20% 可见度的子卡片单击同时执行换根和卡片选择。渲染迁移需要保留拖动阈值和点击抑制规则。
- 三维悬停属于最终 Sprite 覆盖效果，不参与普通气泡排序和标签碰撞占位；悬停前后，其他节点的中文气泡和光点状态保持不变。
- 三维地图内只有光点和中文气泡，不按投影尺寸或选择状态生成完整卡。主节点完整内容只在右侧信息栏显示；选中期间主节点保持普通气泡、星点核心放大到两倍，屏幕内全部直接关联节点进入不受背面、碰撞和密度淘汰的临时气泡层，无关节点名称全部隐藏，取消选中后恢复自动选择。
- 三维深色主题的全部关系线使用更高明度的关系类型色与更高基础透明度。主节点选中期间，仅主节点与直接关联节点之间的边进一步提亮并沿 `source → target` 方向播放 1.8 秒循环脉冲；取消选择即停止。降低动态效果时不播放脉冲。
- 公共知识节点的中心度直接来自严格前置关系图：沿每个节点的下游关联知识广度优先遍历，距离为 `d` 的关联知识贡献 `exp(-0.55 × (d - 1))`，总和经过 `log1p` 并按全图最大值归一化。气泡选择直接使用这份 `foundationScore`，不再叠加作者硬标、实时投影尺寸、等待奖励或驻留公式，也不检查任何具体节点 ID。
- 三维空间记录最后一次单击节点时的相机位置、观察点和缩放。相机与观察点的位移都不超过点击时有效视距的 45%，且缩放变化不超过 0.75 个倍频程时，该节点保留在普通气泡快照；任一阈值越界后释放独立保留。空白单击和小范围拖动不提前清除该锚点。
- 相机平移、旋转、行走、缩放和节点过渡期间，气泡选择在每个渲染帧实时执行；镜头静止后沿用最后一帧结果。纯靠近缩放保留全部旧气泡并增量补充；其他镜头运动按当前画面完整选择。
- 普通气泡使用 13 CSS 像素字号，固定高 26 CSS 像素、左右内边距各 10 像素，使用实际文字宽度；圆角比例沿用旧完整卡片设计，底边位于星点中心上方 16 CSS 像素。气泡按相机深度实时换算世界尺寸，因此不随缩放改变屏幕大小。普通布局使用上移后的真实矩形、7 CSS 像素碰撞间距和视口面积 11% 的气泡面积预算。候选按两张近邻和一张关系中心节点交织处理。
- 全局倍率从 100% 降到 70% 时，普通节点名称逐渐淡出，六个固定 48 CSS 像素高的大域名称逐渐淡入。大域位置取全部公共成员节点的动态空间中心，文字只以领域主题色填充且不绘制描边；深色主题使用压暗领域色，选中节点及其直接关联气泡始终绕过该淡出。
- 三维节点发光与气泡覆盖层分离。`glow` 层的白热紧凑核心透明度随稳定语义显著性在 0.72 至 1 之间变化，核心平面尺寸固定为外晕基准尺寸的 `50%`；进入中文气泡后，独立星点 Sprite 继续显示同一核心亮度，选中主节点把该 Sprite 宽高放大到两倍，外晕光学密度保持原值。文字使用原有可读透明度且不乘核心亮度。透镜强调度变化使用 160 毫秒 T95 增亮、650 毫秒 T95 衰减；降低动态效果时直接提交目标值。
- 门户居中度只参与父作用域的子层显现。进入子作用域后，平移不改变子层透明度，缩放倍率继续控制退出。
- 推进式子图中的每条前置关系保持从左向右，源节点右边缘与目标节点左边缘之间至少保留场景节点间距。
- 新增子域沿用推进式默认策略；需要使用其他空间语义时在场景定义中显式声明布局策略。

## 边界情况

- 节点没有子空间时，高 LOD 继续显示知识卡片入口，不显示进入操作。
- 子空间为空或加载失败时，父场景保持可操作，并提供重试或返回入口。
- 浏览器尺寸变化时，系统按新的 CSS 视口面积和气泡矩形重建一次普通气泡快照，当前选择保持不变。
- 用户在过渡动画中再次返回时，前一次动画停止，导航栈只提交一次。
- 面包屑路径中的空间已被删除时，深层链接回退到最近有效空间。
- 同一概念的多个投影具有不同局部 LOD，卡片内容和进度保持一致。
- 搜索结果指向未加载子空间时，界面等待场景准备完成后再定位目标。

## 验收标准

### 当前版本

1. 根相机缩放范围保持在 10% 至 12800%，缩放过程中节点、连线和场域同步变换。
2. 单击数学全景或子地图节点会打开卡片，并保持相机缩放和平移；拖动节点区域超过 5 像素时只移动画布。
3. 数学全景当前 16 个可钻取节点可以通过卡片按钮和居中放大进入子空间，子节点在进入前连续显现。
4. 子层透明度超过 80% 时作用域进入子域，低于 20% 时回到父域，阈值之间不切换；进入子域后的画布拖拽和小地图平移不改变透明度或作用域。
5. 子层透明度达到 20% 后，单击子卡片会进入子域并显示到 100%，相机缩放和平移保持不变。
6. 子层达到 100% 可见时，父卡片和父层内容透明度均为零。
7. 面包屑、返回按钮和 `Escape` 可以退出子空间，退出前后的画面位置保持连续。
8. 微积分子空间中的 6 个节点、线性代数子空间中的 18 个节点、10 个分析学专题子地图中的 58 个节点投影均无重叠；5 个单节点子空间投影中的卡片水平居中；全部子空间使用同一套场景、碰撞和场域渲染机制。
9. 导航换根前后的父子矩阵屏幕位置误差小于 0.5 CSS 像素。
10. 在数学全景或任一子域中依次选择多个节点时，作用域保持在当前地图，相机矩阵保持不变。
11. 从数学全景进入微积分后，可以继续从多元微积分进入向量微积分；三层面包屑、选择和相机保持连续。
12. 复动力系统在复分析和动力系统子地图中共享概念进度，并同时保留两侧严格前置。
13. 进入和退出子域时，父层与子层节点数量和图层实例保持稳定，80% 与 20% 作用域阈值不触发整层重建。
14. 连续滚轮和自动深入期间，React 根组件不按动画帧重复渲染；缩放百分比随实际矩阵逐帧变化，并在动画结束时与最终矩阵一致。
15. 在 10% 至 100% 的远景比例下，卡片中心与远景标记中心可以命中对应节点，卡片外空白不会沿垂直方向误命中。
16. PixiJS 画布与地图宿主元素使用相同的 CSS 宽高；窗口和面板尺寸变化后命中位置保持一致。
17. 三维子域只在指针命中已声明子域的父节点且滚轮向内，或双击该父节点时启动；在显现前改为缩放空白或其他节点会取消启动。
18. 七个已注册三维子域的 74 个节点、139 条关系和 40 个局部场都随各自父卡片投影高度连续显现；进入和退出期间相机位置、观察点和全局倍率不跳变。
19. 三维子层达到 80% 且实际镜头达到 1245% 后进入对应作用域并允许节点命中；进入后缩小到 800% 才返回公共作用域，1245% 至 800% 区间内子卡片保持可见和可交互；完全进入后公共节点、公共关系和颜色场域均不可见。
20. 三维父层与七个已注册子域都保持常驻，缩放和作用域阈值不会创建、销毁或整体替换图元。
21. 三维镜头静止至少 10 秒时普通气泡 ID 集合不变；选中节点时，地图内不得创建完整卡片，主节点保持 13 CSS 像素字号、26 CSS 像素高的普通气泡，星点核心宽高必须精确放大到两倍，右侧信息栏继续显示完整内容。投影落在屏幕内的全部直接关联节点必须绕过普通背面、遮挡、碰撞和密度筛选显示气泡，无关节点名称全部隐藏，且关联节点不得写入普通快照。关联气泡重叠时必须由相机空间深度决定叠放，近处在上。取消选择后，除最后互动主节点加入快照外，其余普通气泡恢复原快照，主节点星点恢复普通尺寸。镜头平移、旋转、行走、缩放或节点过渡期间，每个渲染帧都必须使用当前屏幕位置刷新气泡；纯靠近缩放后的集合必须是前一帧集合的超集。所有气泡底边位于对应星点中心上方 16 CSS 像素，并沿用旧完整卡片的小圆角比例。
22. 进入或退出任一三维子域不会重新计算八领域公共语义布局；320 个公共节点的身份和基础—专业化半径保持稳定。
23. 公共场域在子层进度 5% 至 72% 连续淡出，当前子域自己的局部场在 18% 至 82% 连续显现；镜头推进时父子光场中段重叠且没有硬边、闪断或全黑间隙。
24. 单击任一三维节点后，在相机位置与观察点位移不超过点击时有效视距 45%、当前倍率处于点击时倍率除以至乘以 `2^0.75` 的闭区间内，即使关闭详情或轻微移动镜头，该节点仍保留中文气泡；放大和缩小恰好到达边界时都保留，越过范围后可以在下一次快照重建时让位。该边界行为在 Windows 与 Linux 上一致。
25. 三维“线性代数”完整卡片与动态图标代码保留但不接入当前气泡主循环；中文气泡、光点悬停、选择和取消选择均不在地图内创建或播放完整卡片。
26. 同一节点从光点进入中文气泡时，文字透明度不受稳定核心亮度压低；独立星点核心与外晕保持光点状态且不闪断。选择时核心宽高放大到两倍，取消选择后恢复；透镜切换时光晕约 160 毫秒增亮、650 毫秒衰减，稳定核心排序不改变，降低动态效果时没有持续发光动画。
27. 深色主题中普通关系线清晰可见；选中任一节点时，所有当前可见的直接关系边稳定高亮，脉冲从关系源端移向目标端。前置边在选中目标时表现为流入，后继边在选中来源时表现为流出；取消选择、没有主节点或降低动态效果时没有持续脉冲。
28. 全局倍率为 100% 时大域名称不可见；降至 85% 时普通节点名称显示约一半、大域名称达到约 25% 透明度；降至 70% 或更低时普通名称完全淡出，而八个大域名称稳定在 50% 最大透明度。大域名称位于各自公共成员节点的当前空间中心，只绘制领域色文字，不出现黑色、白色或其他描边；深色主题的文字必须明显暗于浅色主题，以便在高亮星云与连线之上保持清晰。选中主节点气泡及全部屏幕内直接关联气泡在任意倍率下保持完整可读。
29. 三维右侧详情的正文独立滚动；46 CSS 像素顶栏与 38 CSS 像素页脚不参与正文滚动，页脚横线上方具有 5 CSS 像素渐隐带。滚动 176 CSS 像素后，主视觉和大标题由紧凑图标与标题完全接管；关闭按钮在顶栏最右侧纵向居中。打开“线性代数”时正交图标以 2 秒周期只播放一次，关闭并重新打开后重新播放。

### 规划版本

1. 新增子空间沿用当前 LOD 滞回和连续显隐规则。
2. 搜索命中、路线目标和必要路径遵循确定的语义优先级。
3. 连续进入和退出四层空间后，面包屑、选择状态和相机位置均能恢复。
4. 深层链接可以直接打开有效子空间；失效路径回退到最近有效上级。
5. 未来地图渲染器读取当前场景模型时，概念 ID、关系和进度结果保持一致。
6. 子空间加载失败后，用户仍可操作最近的稳定场景。
