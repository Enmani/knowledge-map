# ADR-003：关系驱动语义布局

日期：2026-07-28
状态：已采用
取代：[ADR-002：同心知识球与专业聚焦投影](./ADR-002-concentric-knowledge-sphere.md)

## 背景

公共三维知识空间已扩展到数学、物理、化学、生物、神经科学、认知科学、计算机科学、地球与环境科学。当前规范数据包含 8 个领域、319 个主节点和 967 条关系，其中 242 个节点具有多领域归属，325 条关系跨越主领域。各领域按真实知识边界保留 19 至 49 个父级主节点，不再用等量目录制造视觉对称。固定的学科方向会随着领域增加而重新分配空间，也会把“同属一个学科”置于具体知识关系之上。

三维位置需要同时回答三个问题：哪些知识在语义上接近，哪些知识是广泛共享的基础，以及如何在卡片具有实体尺寸时保持可读。领域仍应能够形成可辨认的聚集区，但不应被强制为互不重叠的领地。相同数据必须生成相同坐标，已有透镜、筛选、专业聚焦和渲染接口还需要连续工作。

## 决策

公共坐标采用“关系亲和矩阵＋谱嵌入方向＋基础性半径＋Poincaré 图距离应力松弛”的确定性布局。领域归属只提供弱亲和度，不再提供正四面体或其他固定方向锚点。

### 关系亲和矩阵

对节点 (i,j) 合成无向亲和度：

\[
A_{ij}=1-(1-0.12J_{tag})(1-0.035C_{domain})(1-0.025I_{primary})\prod_e(1-q_e s_e)
\]

其中 (J_{tag}) 是标签 Jaccard 相似度，(C_{domain}) 是多领域成员向量的余弦相似度，(I_{primary}) 表示主领域相同，(s_e) 是关系强度。关系类型基础权重为：严格前置 1.00、共享模型 0.85、应用 0.65、类比 0.35、历史关系 0.20；推荐前置使用 0.55。多个信号以饱和合成方式叠加，结果限制在稳定数值范围内。

### 谱嵌入方向

亲和矩阵按节点加权度归一化，并以 \((I+D^{-1/2}AD^{-1/2})/2\) 把谱平移到 \([0,1]\)，避免二分图的负特征模态按绝对值支配普通幂迭代。对平凡分量做正交消除后，以稳定节点 ID 哈希初始化并迭代求取三个非平凡谱分量，将每个节点的三个分量归一化为三维方向。当前每个分量执行 72 轮确定性迭代。

谱方向表达整张关系图的主要变化轴。学科区域可以由高密度内部关系自然显现，也允许同一学科分裂成多个子簇，或通过跨领域节点与其他区域重叠。

### 基础性半径

严格前置图继续计算最长路径深度，人工 `level` 只校准当前节点。节点的后继覆盖按图距离指数衰减，随后使用 `log1p` 和全局最大值归一化为基础性分数 (f_i\in[0,1])。令归一化严格前置深度为 (h_i)，径向进度为：

\[
p_i=\operatorname{clamp}\left(0.72h_i+0.28(1-f_i)+\epsilon_i,0,1\right)
\]

\[
r_i=r_{core}+(r_{outer}-r_{core})p_i^\gamma
\]


其中后继距离衰减系数为 0.55，\(\epsilon_i\) 是由稳定 ID 生成并受 `radialJitter` 限制的轻微扰动。严格前置边额外保证目标节点的径向进度至少比来源节点增加 0.018；若严格前置图含环，受环阻塞的节点回退到人工 `level`，并跳过相关径向顺序约束。前置少且支撑大量后续知识的节点更靠近中心，专业化节点更靠外；领域名称本身不决定半径。

### 图距离应力与碰撞松弛

亲和度转换为边成本 (c_{ij}=0.3-\log(A_{ij}+\varepsilon))，以全源最短路得到节点对的知识图距离。图距离用第 90 百分位归一化后，转换为目标距离：

\[
\delta_{ij}=0.42+2.9\hat d_{ij}^{0.72},\qquad
w_{ij}=\frac{1}{0.3+\delta_{ij}^2}
\]

松弛过程在外半径除以 0.94 得到的边界内计算 Poincaré 距离误差，并用欧氏方向上的启发式切向力降低该误差；这不是完整的黎曼应力梯度。同时加入谱方向锚定、基础性半径锚定和三维实体碰撞排斥。默认执行 32 轮松弛，随后最多执行 120 轮等半径切向装箱，最终严格恢复每个节点的目标半径。

Poincaré 距离用于强调分支知识图的层级与长程结构；最终交互和渲染坐标仍是 Three.js 使用的三维欧氏坐标。

### 透镜、筛选与兼容边界

公共全景、八个领域和跨域桥梁共 10 个透镜。公共透镜改变显著性、关系权重和相机，不复制节点，也不重新引入领域方向。临时领域筛选只改变可见性。底层聚焦投影继续选择匹配节点、严格前置闭包和强跨域桥梁，以固定槽位的 Fibonacci 球面方向重新利用可见空间，并保留 20% 至 35% 的公共方向以及完整基础性半径；当前界面只公开临时筛选。

为避免同时重写渲染与调用方，以下接口暂时兼容保留：

- `KnowledgeSpaceProjection.sphere`、`ProjectionOptions.sphere`、`KnowledgeSphereParameters` 和 `DEFAULT_KNOWLEDGE_SPHERE` 的名称不变。
- `coreRadius`、`outerRadius`、`radialGamma` 和 `radialJitter` 现在控制关系驱动布局的径向包络，不代表领域锚定知识球。
- `globalAnchorWeight` 继续控制专业聚焦保留公共方向的比例。
- 投影节点的 `knowledgeDepth`、`radius`、稳定 ID、可见性和交互字段保持原有契约。

调用方不得再根据节点方向推断固定学科扇区。后续若重命名 `sphere` 相关类型，应另做兼容迁移，不在本决策中破坏公共 Projection API。

## 选择理由

- 一套亲和公式统一使用前置、应用、共享模型、类比、历史、标签和多领域归属，不需要为每个学科维护手工空间规则。
- 谱嵌入从全图结构产生方向，新增领域不需要重排固定锚点。
- 基础性半径同时使用学习深度和后继覆盖，避免把全部数学或任何完整学科预设为中心。
- Poincaré 图距离适合表达从共享基础向多个分支扩展的结构，三维应力与碰撞约束则保持渲染可读。
- 稳定哈希、固定迭代次数和数据缓存使同一规范数据的投影可复现。

## 代价与权衡

- 亲和矩阵和全源最短路目前分别需要平方级存储和立方级计算；319 个公共节点仍可接受，但大规模扩展需要稀疏图或近似最短路。
- 谱嵌入对全图关系变化敏感。相同输入完全稳定，但批量新增节点或关系可能使原有区域整体移动。
- 弱领域先验允许更真实的重叠和分裂，也意味着领域边界不再天然整齐，需要颜色场、透镜和标签帮助识别。
- Poincaré 应力、径向顺序与实体碰撞之间存在竞争；参数变化必须同时检查语义距离和最小碰撞间距。
- 保留 `sphere` 命名降低迁移风险，但会留下术语债务，文档必须把它解释为兼容径向参数。

## 后果

- 八个领域由关系密度形成柔性区域，跨领域节点可以处于交界或独立桥接簇。
- 新增学科只需增加规范节点、关系、领域定义和透镜，不需要为公共布局设计新的几何方向。
- 110 个重复主题标签场和八个领域场读取同一语义坐标，呈现关系聚集后的空间密度。
- 公共坐标仍是可审查的设计投影，不是知识的唯一客观坐标；个人掌握状态不得改写它。
- [ADR-002](./ADR-002-concentric-knowledge-sphere.md) 作为历史记录保留，其正四面体领域方向和领域锚定松弛不再代表当前行为。

## 验收条件

1. 公共数据包含 8 个主领域，目录规模按真实边界确定，总计 319 个节点、967 条关系和 10 个透镜；测试必须确认领域节点数并非强制相等。
2. 多领域节点统计为 242，跨主领域关系统计为 325；公共投影生成 110 个标签场。
3. 同一数据与同一参数重复投影时，节点坐标、半径、可见性和场域结果一致。
4. 强关系定义为 `strength >= 0.78`；其欧氏空间距离中位数应小于无直接关系确定性样本中位数的 0.55。当前实测比值约为 0.34。
5. 严格前置总体从内向外，并满足径向顺序约束；推荐前置不参与知识深度计算。
6. 公共全景在 X、Y、Z 三轴均具有显著跨度，Z 轴不得退化为平面。
7. 完整三维实体碰撞后的节点间距在 0.01 数值容差内满足卡片代理半径与配置留白，不以屏幕二维距离替代公共布局碰撞。
8. 临时筛选保持公共坐标；专业聚焦只重排可见子图方向，保留基础性半径和公共方向锚定。
9. 八个领域不依赖固定方向断言；任一领域仍能通过邻近节点、颜色场与领域透镜辨认。
10. 现有 Projection API、透镜切换、连续插值、场域、射线命中和稳定节点 ID 继续通过回归检查。
