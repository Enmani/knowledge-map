# ADR-002：同心知识球与专业聚焦投影

日期：2026-07-27
状态：已采用

## 背景

首个公共三维投影沿用人工填写的三维坐标。节点主要分布在 XY 平面，Z 轴只提供少量层次。领域场使用面向相机的平面图元，碰撞计算也只处理屏幕平面距离。该结构可以连续切换公共透镜，但无法稳定表达知识深度、三维领域方向和球体内部关系。

三维空间还需要支持领域与专业筛选。简单隐藏节点会在原有领域扇区留下大面积空白。每次筛选都从零布局会破坏公共地图的空间记忆。

## 决策

公共三维空间采用同心知识球模型。严格前置深度决定节点半径，领域归属决定节点方向，知识关系与共享标签决定球壳内的局部邻近。全部距离、碰撞和场域范围使用 XYZ 三维欧氏距离。

数学、物理、化学和生物使用正四面体的四个单位方向。多领域节点使用领域方向的加权和。严格前置图计算公共知识深度，`level` 在关系不完整时提供后备值。节点目标半径由核心半径、球体半径、归一化深度和密度指数计算。

\[
d_i=\begin{cases}0,&i\text{ 没有严格前置}\\1+\max_{j\rightarrow i}d_j,&\text{其他情况}\end{cases}
\]

\[
r_i=r_{core}+(R-r_{core})\left(\frac{d_i}{d_{max}}\right)^\gamma+\Delta r_i
\]

人工 `level` 只校准当前节点，不沿前置边传播。推荐前置不参与深度计算。公共数据不保存人工三维坐标。

确定性约束迭代同时处理关系吸引、标签吸引、领域方向锚定、目标半径锚定和三维碰撞。关系与标签作用力主要投影到球壳切平面，目标半径在迭代中保持稳定。稳定散列提供轻微角度和径向扰动，避免同层节点重合，并保证相同输入得到相同结果。

公共透镜保留节点的知识深度半径。透镜调整相机、显著性、关系权重和有限的球面方向偏移。

筛选提供两种模式。临时筛选只改变可见性。专业聚焦选择匹配节点、必要前置闭包和关键跨领域桥梁，对可见子图重新分配球面方向。聚焦采样使用固定 4096 槽 Fibonacci 球面，稳定散列决定节点槽位。聚焦投影保留公共半径，并以公共方向作为锚点。隐藏节点退出绘制、场域、关系和射线命中。关闭筛选后，节点连续返回公共投影。

## 渲染边界

领域场和标签场使用节点周围的三维柔和散点。散点中心与半径读取完整三维投影，渲染几何使用相机朝向的实例化 PlaneGeometry。径向密度采用五次平滑曲线和有界指数响应。颜色采用逐通道屏幕混合，结果不依赖场域绘制顺序。同类散点重叠形成连续密度区域，分离簇之间保留空白。节点位置、关系端点、场中心和场半径读取三维投影。卡片按照相机距离和投影尺寸切换远景标记、中景标题和近景完整内容。射线命中只接受当前可见并达到交互阈值的节点。

三维实体碰撞使用完整卡片半宽作为代理半径。渲染层继续执行相机相关的屏幕标签避让，冲突标签降低 LOD，选中节点具有最高显示优先级。

Three.js 渲染器继续保留场景对象，并通过阻尼插值更新位置、透明度、比例、场域和相机。筛选与透镜变化不会重建 React 页面或替换节点身份。

## 选择理由

- 知识深度获得稳定的空间语义，用户可以通过离球心的距离判断基础程度。
- 正四面体方向为四个领域提供对称的三维起点。
- 多领域节点自然位于领域方向之间，跨领域关系可以形成连续边界。
- 专业聚焦能够利用空出的球面空间，同时保留公共坐标记忆。
- 规范数据、公共投影和筛选派生投影继续保持独立。

## 代价

- 球体内部存在遮挡，需要 LOD、透明度和旋转浏览共同保证可读性。
- 迭代布局的参数会影响密度和关系长度，需要确定性测试与视觉回归。
- 大面积透明散点仍会增加片元混合成本，移动设备需要限制屏幕覆盖率和像素比。
- 前置关系不足的节点仍依赖人工层级作为后备。

## 被拒绝的方案

### 所有节点位于同一球面

该方案只能表达领域方向，无法表达由基础到前沿的知识深度。

### 筛选后完全重新生成坐标

该方案可以充分填满空间，但返回公共地图时难以维持位置记忆。

### 筛选后只隐藏节点

该方案实现简单，但专业节点仍被限制在原有扇区，空间利用率低。

## 验收条件

1. 公共全景在 X、Y、Z 三个轴上均具有显著跨度。
2. 严格前置深度总体随节点半径增加，基础节点位于球心附近。
3. 四个单领域方向构成正四面体，多领域节点位于对应方向之间。
4. 碰撞、关系长度和场域范围使用三维欧氏距离。
5. 相同数据、透镜和筛选参数生成相同投影。
6. 临时筛选不改变节点位置，专业聚焦只重排可见子图的球面方向。
7. 专业聚焦保持知识深度半径，并保留公共坐标锚定。
8. 隐藏节点和关系不绘制、不进入场域计算，也不能被射线命中。
9. 透镜、筛选和复位之间使用连续过渡，节点 ID 保持不变。
10. 领域场的中心、半径和遮挡读取三维空间，重叠区域保持可辨认的颜色混合。
11. 重复标签自动生成三维标签场，分离成员簇之间保留空白。
12. 完整卡片和标题经过屏幕空间避让后不互相覆盖，选中节点保持可见。
