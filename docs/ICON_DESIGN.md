# 知识卡片动态图标设计规范

版本：1.0（2026-07-29）

## 目的与适用范围

本规范是知识卡片动态图标的设计与实现依据，适用于新增、重制和审核数学、物理及其他科学概念图标。目标是让图标在静止时可识别，在运动时解释概念，并能稳定放入正方形知识卡片占位。

图标只承载一个核心概念和一种主要运动。卡片负责标题、学科和说明文字；图标内部不重复这些文字。

## 信息来源优先级

| 优先级 | 来源 | 决定内容 |
|---|---|---|
| 1 | 目标知识卡片的概念定义、公式和几何关系 | 科学与数学正确性 |
| 2 | `docs/ICON_DESIGN.md` | 画布、视觉语言、几何表达、运动和交付标准 |
| 3 | 已采用的同系列知识卡片图标 | 系列连续性 |
| 4 | 外部图片或灵感参考 | 只用于构图启发，不得覆盖前三级规则 |

发生冲突时按优先级处理。不得为了贴近参考图片而破坏概念关系。

## AI 执行契约

设计或实现每个图标时必须满足：

1. 先用一句话写清“静态结构表达什么”，再用一句话写清“运动解释什么”。
2. 只选择一个主要运动；辅助运动只能帮助读取主要运动。
3. 使用正方形 SVG 画布和固定 4 秒主周期。
4. 优先设计自然闭环；只有自然闭环会损害概念表达或产生明显跳变时，才使用倒放回程。
5. 首帧、循环接缝和降低动态效果后的静态帧都必须是成立的图标。
6. 实现后分别检查静态截图、周期中段截图和跨循环接缝的连续性。

## 视觉语言

### 画布与构图

| 项目 | 标准 |
|---|---|
| 比例 | `1:1` |
| SVG 坐标 | 优先使用 `viewBox="0 0 160 160"` |
| 逻辑中心 | `(80, 80)` |
| 主体占幅 | 宽高的 `70%–82%` |
| 安全区 | 重要结构不得进入画布外侧 `12` 单位 |
| 卡片适配 | 图标容器保持正方形；缩放时不得裁切或改变几何比例 |

- 构图保持居中、安静、留白充分。
- 图形以线框、网格、轨迹和少量半透明面为主。
- 图标内部不放标题、公式说明、坐标名称或装饰性文字。
- 不使用写实材质、透视景深、投影、拟物高光或复杂粒子背景。

### 色彩与线条

| Token | 值 | 用途 |
|---|---|---|
| `icon-bg` | `#161714` | 深色基底 |
| `icon-ink` | `#E8E9DF` | 主结构线 |
| `icon-muted` | `#8D9188` | 次级参照 |
| `icon-accent` | `#B9CBBD` | 唯一强调色 |
| `icon-boundary` | `rgba(232, 233, 223, 0.24)` | 弱边界 |

- 网格与次级结构线宽：`0.6–0.9`。
- 主结构线宽：`0.9–1.2`。
- 主要运动轨迹线宽：`1.5–2.2`。
- 半透明面的不透明度：`0.03–0.10`；不得遮住相交关系。
- 曲线默认使用圆头；多边形和网格使用一致的转角规则。
- 强调色只标记当前变化、运动载体或关键关系，不用于装饰。

## 几何表达

- 静止首帧必须完整表达概念，不能只绘制便于动画的局部。
- 对称、共心、相交、平行、垂直、相切和周期关系必须在几何上成立。
- 三维结构使用轴侧正交投影，不使用透视投影；平行线投影后仍保持平行。
- 多个三维对象共享中心时，必须由同一组三维坐标和同一个投影函数生成，不能靠屏幕坐标目测拼接。
- 平面、曲面和网格必须显示足够的完整边界，使其空间朝向可判断。
- 表达变换前后关系时，原状态使用较暗的固定轮廓，变化状态使用较亮的完整结构；二者共享同一中心和尺度。
- 除非原点、节点或粒子本身就是概念对象，否则不添加中心圆点、十字、箭头或坐标标签。
- 遮挡必须服务于空间层级；透明度不能让交线或关键拓扑消失。

## 动画语法

### 固定周期

- 标准速度下的主周期固定为 `4000ms`，不得使用近似值。
- 图标内所有子动画共用同一个 4 秒主时钟。允许设置相位偏移，但每个子动画都必须在 4 秒边界重新同步。
- 默认持续循环：CSS 使用 `animation-duration: 4s`、`animation-iteration-count: infinite`、`animation-direction: normal`；SMIL 使用 `dur="4s"`、`repeatCount="indefinite"`。
- 如果采用倒放回程，去程与回程必须共同包含在一个 4 秒主周期内，所有子动画仍在周期边界同步。

### 循环策略

按以下优先级选择循环方式：

1. **自然闭环**：沿单一方向完成闭合运动。`t=4s` 与 `t=0s` 相同或几何等价，例如 `360°` 与 `0°`、相位 `2π` 与 `0`、粒子沿闭合轨道完成一周。
2. **无感交接**：使用相位包裹、遮罩交接、形态接续或双层交叉淡化隐藏重置。
3. **倒放回程**：只有前两种方式会歪曲概念、破坏几何关系或产生更明显跳变时才使用 `A → B → A`。

- 连续运动使用闭合路径或周期函数；接缝两侧的方向和速度必须连续。
- 事件型运动默认在周期前后各保留最多 `8%` 的静止区间，中间 `84%` 单向完成变化；运动段默认使用 `cubic-bezier(0.65, 0, 0.35, 1)`。
- 自然连续的轨道、传播和相位流不设置停顿，可使用线性或周期缓动，但接缝不得跳动。
- 无法自然闭合的生长或描绘动画，先尝试相位包裹、遮罩交接或双层交叉淡化；这些方案损害语义时才采用倒放。
- 比较原状态与变化状态时，原状态参照层保持固定；动态层优先完成自然闭环，必要时可在 4 秒内平滑返回。
- 使用倒放回程时，转向点必须有清晰的减速和再启动，不能突然改变速度或方向。

### 运动层级

- 每个图标只能有一个主运动焦点。
- 同时运动的独立对象不超过三组；更多对象必须被组织为同一个相位系统。
- 辅助脉冲、亮度和描边变化必须与 4 秒主周期同步，不得形成无关的短周期闪烁。
- 不使用纯装饰性的漂浮、抖动、呼吸或随机噪声。

## 知识卡片映射与交付

每个图标交付时必须明确：

| 字段 | 要求 |
|---|---|
| `conceptId` | 与目标知识卡片稳定 ID 一致 |
| 中文名称 | 与卡片标题一致 |
| 英文名称 | 使用卡片采用的标准术语 |
| 静态语义 | 一句话描述首帧表达的结构 |
| 动态语义 | 一句话描述 4 秒运动解释的关系 |
| `aria-label` | 用中文描述对象和运动，不写“动态图标” |

- 优先交付可缩放的内联 SVG；不得把 GIF、视频或栅格序列作为知识卡片主图标。
- 动画参数应由 CSS 变量、组件属性或 SVG 动画声明集中管理，避免散落的魔法时间值。
- 降低动态效果时停止持续循环，并显示语义完整的静态帧。
- 图标必须在卡片最小显示尺寸下检查辨识度；细网格缩小后不得糊成实心色块。

## 禁止项

| 应当 | 禁止 |
|---|---|
| 用运动解释概念关系 | 只做无语义旋转或呼吸 |
| 用完整几何结构建立识别 | 只截取局部以简化实现 |
| 用正交投影表达三维关系 | 使用夸张透视制造空间感 |
| 用单一强调色提示变化 | 同时使用多种高饱和颜色 |
| 4 秒内优先完成自然闭环 | 未评估闭环方案就默认来回摆动 |
| 保持循环接缝连续 | 在第 4 秒突然重置位置或透明度 |
| 让卡片承担文字 | 在图标内部堆放标签和说明 |

## 验收清单

- [ ] 画布为正方形，推荐 `160 × 160` SVG 坐标。
- [ ] 静止首帧无需文字即可识别核心结构。
- [ ] 数学或物理关系准确，三维图形使用正交投影。
- [ ] 只有一个主要运动语义。
- [ ] 标准周期严格为 4 秒，所有子动画在周期边界同步。
- [ ] 已优先评估自然闭环和无感交接；若使用倒放回程，原因来自概念或几何限制。
- [ ] 跨循环接缝无位置、方向、速度或透明度跳变。
- [ ] 无多余原点、标签、箭头和装饰动画。
- [ ] 正常动画、暂停状态和降低动态效果状态均可用。
- [ ] 已填写知识卡片映射字段和可读的 `aria-label`。

## 如何使用本文件

新增或重制图标时，先读取目标知识卡片的概念定义，再按“AI 执行契约”确定静态语义和动态语义；实现后逐项执行验收清单。审核图标时，本文件是视觉、几何和运动规则的唯一规范来源。
