# 数与运算子域的内容依据

三维“数与运算”子域用于展开公共节点 `quantity-arithmetic`。内容边界覆盖数的表示、四则运算、整除结构、有理量的多种表示、比例关系、幂与根、实数与复数、估算和结果检验；方程、一般函数、几何量、概率、同余理论、指数与对数函数及复分析仍由主图中的相邻节点负责。

## 公开来源

- 中华人民共和国教育部《[义务教育数学课程标准（2022 年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf)》把“数与运算”界定为整数、小数和分数的认识及其四则运算，并在初中阶段进一步要求有理数乘方、平方根与立方根、无理数估计、近似数和科学记数法。本子域据此保留四则运算主干，并新增“幂、根与科学记数法”。
- Rice University OpenStax 的开放教材《[Prealgebra 2e](https://openstax.org/books/prealgebra-2e/pages/preface)》依次组织 Whole Numbers、Integers、Fractions、Decimals、Percents 和 Properties of Real Numbers，并把方程、多项式和图像放到后续章节。本子域据此校准从位值与整数运算，到分数、小数、比例表示和实数性质的学习顺序，同时把方程与一般代数式留在“初等代数”。
- 美国国家研究委员会报告《[Adding It Up: Helping Children Learn Mathematics](https://www.nationalacademies.org/read/9822)》（National Academies Press，2001，DOI: 10.17226/9822）分别讨论整数熟练度、有理数的多重表示和比例推理，并把估算视为数感、结果判断与日常数学的重要能力。本子域据此将“小数与表示转换”“比、率、比例与百分数”分开，并保留“估算、近似与检验”作为综合节点。
- [Common Core State Standards for Mathematics](https://www.thecorestandards.org/Math/Content/6/RP/) 把比和比例关系组织为建立在乘除与分数之上的独立领域；其[八年级指数与根标准](https://www.thecorestandards.org/Math/Content/8/EE/)另行组织整数指数、平方根、立方根和科学记数法。本子域据此把比例关系和幂根分别设为桥接节点，避免继续压在“小数”或“四则运算”中。
- OpenStax《[Precalculus 2e：Complex Numbers](https://openstax.org/books/precalculus-2e/pages/3-1-complex-numbers)》把虚数单位、复数表示、复平面及复数四则运算组织成独立单元。本子域据此把“复数与复平面”作为数系扩张的高级出口，不提前进入复函数和复分析。

## 节点与边界

子域包含 13 个节点，分为三组：

- 数的表示与扩张：自然数、零与位值制；整数与数轴；分数与有理数；小数与表示转换；实数与数系扩张；复数与复平面。
- 运算体系：加法与减法；乘法与除法；整除、因数、倍数与质数；运算律、逆运算与混合运算；幂、根与科学记数法。
- 数量关系与结果控制：比、率、比例与百分数；估算、近似与检验。

“整除、因数、倍数与质数”止于质因数分解、最大公因数和最小公倍数，深层整除理论与同余归入“初等数论”。“幂、根与科学记数法”只负责运算意义、基本性质和数量级表示，一般指数函数、对数及其图像归入“初等函数”。“复数与复平面”只覆盖表示和基本运算，后续理论归入“复分析”。

为保持概念身份稳定，原内部 ID `decimals-percents-ratios` 继续承接“比、率、比例与百分数”，新增 `decimal-representations` 表达小数位值及分数—小数转换。

## 关系取舍

子域包含 15 条严格前置和 6 条建议前置。严格前置只表达稳定的学习依赖：位值制先于加减；加减支撑乘除和整数；乘除分别通向整除、分数、运算结构和幂；分数支撑小数与比例；整数、分数和幂根共同支撑实数；实数再通向复数；小数和运算结构共同支撑估算与检验。

建议前置表达有帮助但不应虚构成唯一顺序的联系：整除帮助约分通分，整数帮助理解负有理数，小数帮助理解百分数表示，运算律和小数表示帮助学习指数律与科学记数法，幂和科学记数法帮助进行数量级估算。节点之间存在但不构成必要学习顺序的联系不写成严格前置。
