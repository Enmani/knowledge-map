# 理科领域分类依据

三维公共知识空间收录数学、物理、化学、生物、神经科学、认知科学、计算机科学、地球与环境科学 8 个领域，共 319 个主节点。目录规模按真实知识边界确定：数学和计算机科学各 46 个，物理与化学各 47 个，生物学 45 个，地球与环境科学 49 个，神经科学 20 个，认知科学 19 个。领域不再为了视觉对称强制等量。

## 公共主节点资格

公共主节点不是任意术语或单篇课程内容。新增节点需要同时满足以下条件；不够宽的机制、实验范式、工具或专题应进入父节点的三维子域。

- 能够自然拆成约 5 至 12 个互不重复、各自有解释价值的子主题。
- 在多所高校课程、教材或研究机构分类中具有稳定身份，不依赖短期热点命名。
- 能用一个明确中心问题界定研究对象，并能说明哪些相邻内容不归它所有。
- 内部具有可表达的学习依赖、共享模型或应用关系，而不是同义词集合。
- 与其他领域存在真实解释或方法联系，但自身身份不由这些跨域联系替代。
- 与现有公共节点没有实质重复；仅解释层次不同的主题需要在标题和摘要中明确区分。
- 对神经科学等边界敏感领域，范围必须清楚；本轮神经科学只收录非临床基础与研究方法。

节点数不是验收目标。一个领域可以少于 46 个，只要其每个公共节点都足以成为后续子域的稳定父节点；为了补齐数量而添加的细项会削弱层级和关系布局。

## 数学

数学三维目录直接投影 `src/data/mathMap.ts` 的 46 个主节点。两个视图共用节点名称、简介、学习层级、场域标签和前置关系。`numbers`、`logic` 和 `sets` 在三维公共数据中分别使用稳定 ID `quantity-arithmetic`、`mathematical-logic` 和 `set-theory`。

主要分支为数学基础、代数学、几何与拓扑、分析学、离散数学、概率与统计、应用数学。

## 物理

物理目录使用 [APS Physics Subject Headings](https://physh-alpha.aps.org/about) 和 [APS 学术分部](https://www.aps.org/membership/units) 检查学术分支覆盖，使用 [APS 期刊范围](https://journals.aps.org/scope) 补充量子材料、非平衡系统、光子学和现代凝聚态方向。[MIT Physics Subjects](https://physics.mit.edu/academic-programs/subjects/) 和 [Caltech Physics Option](https://www.catalog.caltech.edu/current/information-for-undergraduate-students/graduation-requirements-all-options/physics-option-ph/) 用于校准前置顺序。[Paris-Saclay 物理地图](https://vulgarisation.fr/projet/la_carte_de_la_physique/?lang=en) 和 [The Map of Physics](https://www.youtube.com/watch?v=ZihywtixUYo) 用于检查宏观层级的可辨识性。

物理目录包含八个分支簇：

- 方法与经典基础，6 个节点。
- 连续介质、波与场，8 个节点。
- 热学与统计物理，4 个节点。
- 复杂物质与生命系统，3 个节点。
- 量子、原子与信息，6 个节点。
- 凝聚态与材料，6 个节点。
- 核、粒子、等离子体、束流与探测，8 个节点。
- 引力与宇宙，6 个节点。

地球物理、气候物理、医学物理、量子引力和弦理论保留为后续子节点候选。

“加速器与探测器物理”原先把粒子束动力学与辐射传感、读出和事件重建放在一个节点中。两者具有不同研究对象和课程体系，因此拆为“加速器物理”与“粒子与辐射探测”；旧 ID `accelerator-detector-physics` 由加速器物理继承。原“相对论”收窄为“狭义相对论与时空”，引力和弯曲时空继续由“广义相对论与引力”拥有。

## 化学

化学目录使用 [ACS 本科化学课程要求](https://www.acs.org/education/policies/acs-approval-program/guidelines/coursework.html) 建立分析、生物化学、无机、有机和物理化学五大主干。[IUPAC 化学分部](https://iupac.org/who-we-are/divisions/) 用于检查聚合物、环境、健康、命名和结构表示的专业边界。[RSC 化学课程框架](https://www.rsc.org/policy-and-campaigning/policy-library/answering-the-big-questions-our-chemistry-curriculum-in-detail) 用组成、结构、性质、反应、能量、速率、平衡、合成和分析检查基础层。[MIT Chemistry Subjects](https://catalog.mit.edu/schools/science/chemistry/) 用于校准配位、金属有机、固态材料、光谱、电化学和计算方向的进阶层级。

化学目录包含七个分支簇：

- 化学基础与共同语言，10 个节点。
- 物理与理论化学，8 个节点。
- 有机、合成与分子设计，7 个节点。
- 无机、固体与材料，8 个节点。
- 分析、测量与数据，5 个节点。
- 生物、药物与健康，6 个节点。
- 环境、可持续与计算，3 个节点。

化学信息学、过程化学、食品化学、地球化学、光化学和表面化学保留为后续子节点候选。

“酸碱与溶液”拆为“溶液化学”与“酸碱化学”：前者拥有溶剂化、浓度、活度、离子强度和依数性，后者拥有酸碱理论、质子转移、pH、缓冲与滴定。旧 ID `acids-bases-solutions` 由酸碱化学继承。“化学反应与氧化还原”收窄为“化学反应与守恒”，一般反应表示和守恒由它负责，系统的氧化还原与电极过程由电化学负责。

## 生物

生物目录使用 [AP Biology](https://apcentral.collegeboard.org/courses/ap-biology) 和 [OpenStax Biology 2e](https://openstax.org/books/biology-2e/pages/preface) 建立生命化学、细胞、遗传、进化、生物多样性、个体系统与生态的基础顺序。[NCES CIP 26 Biological and Biomedical Sciences](https://nces.ed.gov/ipeds/cipcode/cipdetail.aspx?cipid=88385&y=55) 用于检查专业分支覆盖。NSF 的 [Molecular and Cellular Biosciences](https://www.nsf.gov/funding/opportunities/mcb-division-molecular-cellular-biosciences-core-programs)、[Integrative Organismal Systems](https://www.nsf.gov/bio/ios/about) 和 [Environmental Biology](https://www.nsf.gov/bio/deb/about) 用于补充分子、细胞、个体、种群、群落和生态系统尺度。[Gene Ontology](https://www.geneontology.org/docs/ontology-documentation/) 支持多父节点、多标签和跨簇关系的数据表达。

生物目录包含七个分支簇：

- 分子结构与细胞功能，12 个节点。
- 发育与个体系统，8 个节点。
- 生物多样性与微生物，5 个节点。
- 进化与系统学，4 个节点。
- 生态与保护，6 个节点。
- 宿主、防御与疾病，4 个节点。
- 定量与工程生物学，6 个节点。

海洋生物学、古生物学、药理学和医学诊疗保留为后续子节点候选。

生物信息学与计算生物学继续作为两个公共父节点：前者关注生命数据的表示、管理和分析，后者关注算法、模拟与统计模型对生命系统的解释。两者有稳定的独立身份，但生物信息学只作为系统生物学和计算生物学的建议背景，不构成严格学习前置。

## 神经科学

神经科学目录使用 [MIT Brain and Cognitive Sciences](https://catalog.mit.edu/schools/science/brain-cognitive-sciences/) 的分子与细胞、系统、认知和计算四条主轴校准解释层次；使用 [NIH BRAIN 2025 科学愿景](https://www.braininitiative.nih.gov/vision/nih-brain-initiative-reports/brain-2025-scientific-vision) 检查细胞类型、跨尺度回路、活动记录、因果干预、理论和数据分析等研究方向；[NIH BRAIN 神经伦理路线图](https://www.braininitiative.nih.gov/vision/nih-brain-initiative-reports/brain-20-neuroethics-enabling-and-enhancing-neuroscience) 支持把神经伦理作为横贯研究责任。

原生物学目录中的稳定 ID `neuroscience` 已迁移为本领域入口，没有复制第二个同义节点。20 个公共父节点归纳为五组：

- 领域入口、细胞与分子、神经信号与突触、神经回路、发育和可塑性，6 个节点。
- 系统、感觉、运动、内感受与稳态、睡眠与昼夜、行为神经科学与神经行为学，6 个节点。
- 认知、情感与动机、社会神经科学，3 个节点。
- 计算神经科学与网络神经科学，2 个节点。
- 神经科学研究方法、神经数据科学与神经伦理，3 个节点。

疾病诊断、治疗、药物剂量、神经外科、康复、临床神经学和临床精神病学不进入本目录。成像、电生理和因果扰动只按研究方法组织。认知神经科学描述认知过程的神经实现，认知科学目录则拥有功能、表征、行为和计算解释层；两者通过共享模型连接而不互相复制。

## 认知科学

认知科学目录使用 [Cognitive Science Society](https://cognitivesciencesociety.org/about/) 的跨学科范围确认人工智能、语言学、人类学、心理学、神经科学、哲学和教育之间的共同领域；[Yale Cognitive Science](https://cogsci.yale.edu/about-us) 用感知、推理、记忆、注意、语言、意象、运动控制和问题求解检查核心认知过程；MIT 的脑与认知科学课程进一步用于校准行为、计算与神经解释的分工。

19 个公共父节点归纳为五组：

- 认知科学入口、心智与表征理论、认知研究方法、计算认知建模，4 个节点。
- 感觉与知觉、注意、学习、记忆，4 个节点。
- 语言与认知、概念与语义、推理与问题求解、判断与决策、认知控制、元认知，6 个节点。
- 认知发展、社会与文化认知、具身与情境认知，3 个节点。
- 意识、情绪与动机，2 个节点。

心理物理、工作记忆、视觉知觉、启发式、语言理解等更细主题进入相应子域，不再作为公共主节点铺平显示。人工智能、自然语言处理、计算机视觉和强化学习保留原有计算机科学身份，通过共享模型或类比与认知节点相连。

## 计算机科学

计算机科学目录位于 `src/knowledge/space3d/catalog/computerScience.ts`，从计算思维与编程基础展开，连接软件、硬件、系统、数据、智能及计算技术的社会责任。数学目录已经收录的算法、理论计算机科学、机器学习和现代密码学作为共享基础或推荐前置保留；本目录使用更具体的计算机系统与工程节点，避免复制相同稳定 ID。

按目录中的 46 个实际节点归纳为六个分支簇：

- 计算思维、编程、数据结构、算法、自动机与复杂性，8 个节点。
- 软件工程、软件架构、测试、程序语言、编译、形式验证、Web 与人机交互，8 个节点。
- 数字逻辑、体系结构、操作系统、网络、分布式与高性能计算，6 个节点。
- 数据库、数据密集型与云计算、嵌入式、物联网、安全和应用密码，7 个节点。
- 人工智能、知识表示、机器学习系统、深度学习、语言、视觉、强化学习、多智能体与数据分析，11 个节点。
- 图形学、机器人、科学计算、量子计算、隐私保护和计算伦理，6 个节点。

移动计算、区块链、边缘计算、可访问性工程和专用芯片可在后续作为子节点或跨领域应用补充。

面向对象和函数式编程仍各自具备可展开的范式边界，因而不合并。程序设计语言研究语法、语义、类型系统与求值策略，只严格依赖程序设计基础；面向对象、函数式编程和自动机与形式语言均为建议背景，不再虚构为必须依次完成的课程链。

## 地球与环境科学

地球与环境科学目录使用 [AGU 学术分部](https://www.agu.org/Learn-About-AGU/About-AGU/Governance/Sections) 校准专业边界。AGU 分别设置地磁与古地磁、空间物理与高层大气方向，并把火山学、地球化学和岩石学列为稳定研究分部；目录据此避免把地球内部磁场、近地空间环境和火山过程压进其他节点。规范数据位于 `src/knowledge/space3d/catalog/earthEnvironmental.ts`，以地球系统为入口，把固体地球、大气、海洋、水文、冰冻圈、生物地球化学、气候、环境风险和可持续性组织为一张相互耦合的图。大量节点同时归属于物理、化学、生物或数学，用于表达地球过程依赖的跨学科机制。

按目录中的 49 个实际节点归纳为六个分支簇：

- 地球系统、野外与空间观测、地球历史和行星比较，5 个节点。
- 矿物岩石、火山、沉积地层、构造地貌、古生物、古生态、资源与土壤，12 个节点。
- 地球物理、地震、内部动力、地磁、空间天气、大地测量、地球化学与生物地球化学，9 个节点。
- 大气、大气动力与化学、天气、海洋、物理海洋和海洋生物地球化学，7 个节点。
- 水文、地下水、流域、冰冻圈、气候系统、古气候、气候建模与影响，8 个节点。
- 环境科学、监测、污染修复、健康风险、景观保护、灾害风险和可持续资源系统，8 个节点。

海岸科学、城市气候、环境经济与治理可以在后续作为子节点扩展；新增时应继续连接实际依赖的物理、化学、生物、数学和计算节点。

“古生物学与古生态学”拆为研究化石、埋藏和生命演化的“古生物学”，以及重建古群落、食物网和环境的“古生态学”；旧 ID `paleontology-paleoecology` 由古生物学继承。“地磁学与空间天气”拆为研究地磁场及岩石记录的“地磁学与古地磁学”，以及研究太阳风、磁层、电离层和技术影响的“空间物理与空间天气”；旧 ID `geomagnetism-space-weather` 由地磁学与古地磁学继承。火山学从岩石学和板块构造中独立出来，拥有岩浆上升、喷发动力、火山产物、监测与灾害等内部主题。“构造地质学”收窄为“构造地质与岩石变形”，板块运动的统一理论继续由“板块构造”拥有。

## 关系与层级规则

严格前置只记录稳定的学习依赖，并参与最长前置深度、基础性半径和环检测。可并行学习、高校间存在顺序差异或只能提高理解效率的关系记录为推荐前置。严格与推荐前置、应用、共享模型、类比和历史关系均按类型与强度参与关系亲和度；标签相似和领域相似只提供较弱的聚集先验。三维子域使用同一语义区分，但不提供历史关系类型；认知科学中的竞争理论、跨模态类比和计算模型共享不得误写为严格学习顺序。完整布局规则见 [ADR-003：关系驱动语义布局](../architecture/ADR-003-relationship-driven-semantic-layout.md)。

领域总览节点可以与专业分支同时存在。典型组合包括凝聚态物理与固体物理，有机化学与有机反应机理，生态学与种群、群落、生态系统生态学。总览节点提供领域入口，专业节点提供后续钻取锚点。
